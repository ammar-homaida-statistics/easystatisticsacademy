<section class="section" id="lesson">

  <h2>Learning objective</h2>
  <p>
    By the end of this lesson, you should understand how statistical modeling
    connects to machine learning and how they differ in focus.
  </p>

  <div class="card">
    <h3>Key idea</h3>
    <p>
      Machine learning extends statistical modeling,
      emphasizing prediction, automation, and performance.
    </p>
  </div>

  <h2>1) What you already know</h2>
  <div class="card">
    <p>
      From this unit, you already understand:
    </p>
    <ul>
      <li>Models describe relationships</li>
      <li>Parameters quantify effects</li>
      <li>Fit and generalization matter</li>
      <li>Model selection is critical</li>
    </ul>
  </div>

  <h2>2) What machine learning focuses on</h2>
  <div class="card">
    <ul>
      <li>Prediction accuracy</li>
      <li>Generalization to new data</li>
      <li>Handling large datasets</li>
      <li>Algorithmic optimization</li>
    </ul>
  </div>

  <h2>3) Key difference in mindset</h2>
  <div class="card">
    <ul>
      <li>Statistical modeling → explanation and inference</li>
      <li>Machine learning → prediction and performance</li>
    </ul>
  </div>

  <h2>4) Not completely different</h2>
  <div class="card">
    <p>
      Many machine learning methods are built on statistical principles.
    </p>
  </div>

  <h2>5) Examples</h2>
  <div class="card">
    <ul>
      <li>Linear regression → basic predictive model</li>
      <li>Logistic regression → classification model</li>
    </ul>
  </div>

  <h2>6) What changes</h2>
  <div class="card">
    <ul>
      <li>More complex models</li>
      <li>Less emphasis on interpretation</li>
      <li>More emphasis on performance</li>
    </ul>
  </div>

  <h2>7) What stays the same</h2>
  <div class="card">
    <ul>
      <li>Data → model → prediction</li>
      <li>Evaluation of performance</li>
      <li>Importance of generalization</li>
    </ul>
  </div>

  <h2>8) Examples of ML models</h2>
  <div class="card">
    <ul>
      <li>Decision trees</li>
      <li>Random forests</li>
      <li>Neural networks</li>
    </ul>
  </div>

  <h2>9) Why this matters</h2>
  <div class="card">
    <p>
      Understanding statistical modeling provides the foundation
      for learning machine learning correctly.
    </p>
  </div>

  <h2>10) Big picture</h2>
  <div class="card">
    <p>
      Statistical modeling and machine learning are part of the same continuum.
    </p>
  </div>

  <div class="card">
    <h3>Outcome of this lesson</h3>
    <ul>
      <li>Understand the connection to machine learning</li>
      <li>Recognize differences in goals</li>
      <li>Identify shared principles</li>
      <li>Prepare for advanced topics</li>
      <li>Complete the modeling unit</li>
    </ul>
  </div>
