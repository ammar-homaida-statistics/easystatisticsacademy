1 Learning objectives

By the end of this lesson you will be able to:

  1. state and prove the Frisch–Waugh–Lovell theorem, and use it to explain what a partial coefficient measures;
  2. draw and read an added-variable plot;
  3. derive the omitted-variable bias formula, both as an exact sample identity and in expectation, and predict the direction of the bias;
  4. prove \(\operatorname{Var}(\hat\beta_j) = \sigma^2/[(1 - R_j^2)S_{jj}]\) and interpret the variance inflation factor;
  5. explain the trade-off between omitting a relevant predictor (bias) and including a correlated one (variance).

2 Motivation

Lesson 2.1 said that \(\beta_j\) compares units “with the same values of the other predictors”, and showed with two predictors that a slope changes when a correlated predictor is added. This lesson makes both statements precise for any number of predictors. The Auto MPG data give a sharp example: in a model with weight and horsepower, horsepower has a slope of \(-4.73\) mpg per 100 hp; add model year, and the slope becomes \(-0.50\) with a standard error of \(0.94\). Which number describes horsepower? The tools of this lesson answer that question.

3 Notation for this lesson

Symbol Meaning
\(\mathbf{X} = [\mathbf{X}_1, \mathbf{X}_2]\) partition of the columns into two groups (\(\mathbf{X}_1\) contains the intercept)
\(\mathbf{H}_1\), \(\mathbf{M}_1 = \mathbf{I} - \mathbf{H}_1\) hat and residual-maker matrices of \(\mathbf{X}_1\) alone
\(\mathbf{x}_j\), \(\mathbf{X}_{-j}\) column \(j\) of \(\mathbf{X}\), and \(\mathbf{X}\) without that column
\(R_j^2\) \(R^2\) from regressing \(\mathbf{x}_j\) on the other predictors (with intercept)
\(\mathrm{VIF}_j = 1/(1 - R_j^2)\) variance inflation factor of predictor \(j\)
\(\tilde{\boldsymbol\beta}_1\) estimate from the short model that omits \(\mathbf{X}_2\)
\(\hat{\boldsymbol\Delta} = (\mathbf{X}_1^\top\mathbf{X}_1)^{-1}\mathbf{X}_1^\top\mathbf{X}_2\) coefficients from regressing each omitted column on \(\mathbf{X}_1\)

Assumptions used in this lesson

The model is \(\mathbf{y} = \mathbf{X}\boldsymbol\beta + \boldsymbol\varepsilon\) (Lesson 2.2), with

  • A0 (Full rank). \(\mathbf{X}\) is fixed with \(\operatorname{rank}(\mathbf{X}) = p + 1\).
  • A1 (Correct mean function). \(E(\boldsymbol\varepsilon) = \mathbf{0}\).
  • A2–A3 (Constant variance, uncorrelated errors). \(\operatorname{Cov}(\boldsymbol\varepsilon) = \sigma^2\mathbf{I}_n\).
  • A4 (Normality). \(\boldsymbol\varepsilon \sim N_n(\mathbf{0}, \sigma^2\mathbf{I}_n)\).

The algebraic results (Theorem 2.5.1 and Theorem 2.5.2a) need only A0; each other result names what it uses. What each assumption means: Lesson 1.1, Assumptions.

4 Theory

4.1 The Frisch–Waugh–Lovell theorem

Theorem 2.5.1 (Frisch–Waugh–Lovell) — uses A0

Partition \(\mathbf{X} = [\mathbf{X}_1, \mathbf{X}_2]\) and \(\hat{\boldsymbol\beta} = (\hat{\boldsymbol\beta}_1^\top, \hat{\boldsymbol\beta}_2^\top)^\top\) accordingly. Then \[ \hat{\boldsymbol\beta}_2 = \bigl[(\mathbf{M}_1\mathbf{X}_2)^\top(\mathbf{M}_1\mathbf{X}_2)\bigr]^{-1}(\mathbf{M}_1\mathbf{X}_2)^\top(\mathbf{M}_1\mathbf{y}), \] the least-squares coefficients from regressing the residuals \(\mathbf{M}_1\mathbf{y}\) on the residuals \(\mathbf{M}_1\mathbf{X}_2\). Moreover, the residuals of that regression equal the residuals \(\mathbf{e}\) of the full model.

Derivation

The normal equations of the full model are \(\mathbf{X}_1^\top\mathbf{X}_1\hat{\boldsymbol\beta}_1 + \mathbf{X}_1^\top\mathbf{X}_2\hat{\boldsymbol\beta}_2 = \mathbf{X}_1^\top\mathbf{y}\) and \(\mathbf{X}_2^\top\mathbf{X}_1\hat{\boldsymbol\beta}_1 + \mathbf{X}_2^\top\mathbf{X}_2\hat{\boldsymbol\beta}_2 = \mathbf{X}_2^\top\mathbf{y}\). The first gives \(\mathbf{X}_1\hat{\boldsymbol\beta}_1 = \mathbf{H}_1(\mathbf{y} - \mathbf{X}_2\hat{\boldsymbol\beta}_2)\). Substituting in the second, \(\mathbf{X}_2^\top(\mathbf{I} - \mathbf{H}_1)\mathbf{X}_2\hat{\boldsymbol\beta}_2 = \mathbf{X}_2^\top(\mathbf{I} - \mathbf{H}_1)\mathbf{y}\), i.e. \(\mathbf{X}_2^\top\mathbf{M}_1\mathbf{X}_2\,\hat{\boldsymbol\beta}_2 = \mathbf{X}_2^\top\mathbf{M}_1\mathbf{y}\). Because \(\mathbf{M}_1\) is symmetric and idempotent, \(\mathbf{X}_2^\top\mathbf{M}_1\mathbf{X}_2 = (\mathbf{M}_1\mathbf{X}_2)^\top(\mathbf{M}_1\mathbf{X}_2)\) and \(\mathbf{X}_2^\top\mathbf{M}_1\mathbf{y} = (\mathbf{M}_1\mathbf{X}_2)^\top(\mathbf{M}_1\mathbf{y})\). This matrix is invertible under A0: if \(\mathbf{M}_1\mathbf{X}_2\mathbf{c} = \mathbf{0}\), then \(\mathbf{X}_2\mathbf{c} \in \mathcal{C}(\mathbf{X}_1)\), which full rank allows only for \(\mathbf{c} = \mathbf{0}\).

For the residuals: \(\mathbf{e} = \mathbf{y} - \mathbf{X}_1\hat{\boldsymbol\beta}_1 - \mathbf{X}_2\hat{\boldsymbol\beta}_2 = (\mathbf{I} - \mathbf{H}_1)(\mathbf{y} - \mathbf{X}_2\hat{\boldsymbol\beta}_2) = \mathbf{M}_1\mathbf{y} - \mathbf{M}_1\mathbf{X}_2\hat{\boldsymbol\beta}_2\).

With \(\mathbf{X}_2 = \mathbf{x}_j\), a single column, the theorem says:

\(\hat\beta_j\) is the simple-regression slope of the part of \(y\) not explained by the other predictors on the part of \(x_j\) not explained by the other predictors.

This is the exact meaning of “holding the others fixed”: the other predictors are removed, linearly, from both \(y\) and \(x_j\), and only the remaining variation in \(x_j\) is used. If \(x_j\) is almost a linear function of the others, little of its variation remains, and \(\hat\beta_j\) is estimated from little information (Section 4.4).

4.2 Added-variable plots

The added-variable plot (also called partial regression plot) for predictor \(j\) plots \(\mathbf{M}_{-j}\mathbf{y}\) against \(\mathbf{M}_{-j}\mathbf{x}_j\), the residuals from regressing \(y\) and \(x_j\) on all other predictors. By Theorem 2.5.1:

  • the least-squares line through the plot has slope exactly \(\hat\beta_j\) and passes through the origin;
  • the vertical deviations from that line are exactly the residuals of the full model;
  • the horizontal spread shows how much independent variation in \(x_j\) the data contain.

An added-variable plot therefore shows a multiple-regression coefficient as a scatterplot, and it reveals observations that drive that coefficient, which a plot of \(y\) against \(x_j\) cannot do. Module 3 uses these plots for diagnostics.

4.3 Omitted-variable bias

Suppose the full model \(\mathbf{y} = \mathbf{X}_1\boldsymbol\beta_1 + \mathbf{X}_2\boldsymbol\beta_2 + \boldsymbol\varepsilon\) holds, but we fit the short model with \(\mathbf{X}_1\) only: \(\tilde{\boldsymbol\beta}_1 = (\mathbf{X}_1^\top\mathbf{X}_1)^{-1}\mathbf{X}_1^\top\mathbf{y}\).

Theorem 2.5.2 (Omitted variables)

  1. Exact sample identity (uses A0): \(\tilde{\boldsymbol\beta}_1 = \hat{\boldsymbol\beta}_1 + \hat{\boldsymbol\Delta}\hat{\boldsymbol\beta}_2\), where \((\hat{\boldsymbol\beta}_1, \hat{\boldsymbol\beta}_2)\) are the full-model estimates.
  2. Bias (uses A0, A1 for the full model): \(E(\tilde{\boldsymbol\beta}_1) = \boldsymbol\beta_1 + \hat{\boldsymbol\Delta}\boldsymbol\beta_2\). The short-model estimator is unbiased for \(\boldsymbol\beta_1\) if \(\boldsymbol\beta_2 = \mathbf{0}\) or \(\mathbf{X}_1^\top\mathbf{X}_2 = \mathbf{0}\).
  3. Precision (uses A0–A3): \(\operatorname{Cov}(\hat{\boldsymbol\beta}_1) - \operatorname{Cov}(\tilde{\boldsymbol\beta}_1) \succeq \mathbf{0}\): the short model’s estimator is never less precise.
Derivation
  1. Write \(\mathbf{y} = \mathbf{X}_1\hat{\boldsymbol\beta}_1 + \mathbf{X}_2\hat{\boldsymbol\beta}_2 + \mathbf{e}\) and apply \((\mathbf{X}_1^\top\mathbf{X}_1)^{-1}\mathbf{X}_1^\top\); the last term vanishes because \(\mathbf{X}_1^\top\mathbf{e} = \mathbf{0}\) (Theorem 2.3.3, Lesson 2.3). For two predictors this is Theorem 2.1.1 of Lesson 2.1.
  2. Apply the same matrix to \(\mathbf{y} = \mathbf{X}_1\boldsymbol\beta_1 + \mathbf{X}_2\boldsymbol\beta_2 + \boldsymbol\varepsilon\) and take expectations.
  3. \(\operatorname{Cov}(\tilde{\boldsymbol\beta}_1) = \sigma^2(\mathbf{X}_1^\top\mathbf{X}_1)^{-1}\). By Theorem 2.5.1 with the roles of the two blocks exchanged, \(\hat{\boldsymbol\beta}_1 = (\mathbf{X}_1^\top\mathbf{M}_2\mathbf{X}_1)^{-1}\mathbf{X}_1^\top\mathbf{M}_2\mathbf{y}\), so \(\operatorname{Cov}(\hat{\boldsymbol\beta}_1) = \sigma^2(\mathbf{X}_1^\top\mathbf{M}_2\mathbf{X}_1)^{-1}\). Since \(\mathbf{X}_1^\top\mathbf{X}_1 - \mathbf{X}_1^\top\mathbf{M}_2\mathbf{X}_1 = \mathbf{X}_1^\top\mathbf{H}_2\mathbf{X}_1 \succeq \mathbf{0}\), and \(\mathbf{A} \succeq \mathbf{B} \succ \mathbf{0}\) implies \(\mathbf{B}^{-1} \succeq \mathbf{A}^{-1}\), the result follows.

With one omitted predictor \(x_k\) and coefficient \(\beta_k\), the bias in \(\tilde\beta_j\) is \(\hat\delta_j\beta_k\), where \(\hat\delta_j\) is the coefficient of \(x_j\) when \(x_k\) is regressed on the included predictors. Its sign is the sign of \(\hat\delta_j\beta_k\): if the omitted predictor raises \(y\) (\(\beta_k > 0\)) and is positively related to \(x_j\) given the others (\(\hat\delta_j > 0\)), the short model overstates \(\beta_j\); and so on.

Parts (b) and (c) together are a bias–variance trade-off: leaving out a relevant, correlated predictor biases the estimates but makes them less variable. Lesson 2.11 and Module 4 return to it. Note also what (b) does not say: adding every available variable does not make a coefficient causal. A variable that is itself affected by \(x_j\) (a mediator), or a common effect of \(x_j\) and \(y\), changes the meaning of \(\beta_j\) when included. Which variables belong in the model is a question about the subject matter, not only about the data.

4.4 Precision and the variance inflation factor

Theorem 2.5.3 (Variance of a single coefficient) — uses A0–A3

For a predictor \(x_j\) (\(j \ge 1\)) in a model with an intercept, \[ \operatorname{Var}(\hat\beta_j) = \frac{\sigma^2}{\mathbf{x}_j^\top\mathbf{M}_{-j}\mathbf{x}_j} = \frac{\sigma^2}{(1 - R_j^2)\,S_{jj}} = \mathrm{VIF}_j\cdot\frac{\sigma^2}{S_{jj}}, \] where \(S_{jj} = \sum_i(x_{ij} - \bar x_j)^2\).

Derivation

By Theorem 2.5.1 with \(\mathbf{X}_2 = \mathbf{x}_j\), \(\hat\beta_j = \mathbf{r}_j^\top\mathbf{y}/(\mathbf{r}_j^\top\mathbf{r}_j)\) with \(\mathbf{r}_j = \mathbf{M}_{-j}\mathbf{x}_j\) (using \(\mathbf{r}_j^\top\mathbf{M}_{-j}\mathbf{y} = \mathbf{r}_j^\top\mathbf{y}\)). Hence \(\operatorname{Var}(\hat\beta_j) = \sigma^2\mathbf{r}_j^\top\mathbf{r}_j/(\mathbf{r}_j^\top\mathbf{r}_j)^2 = \sigma^2/(\mathbf{r}_j^\top\mathbf{r}_j)\). Now \(\mathbf{r}_j^\top\mathbf{r}_j\) is the residual sum of squares from regressing \(x_j\) on the others (with intercept), which equals \((1 - R_j^2)\) times its total sum of squares \(S_{jj}\).

The factor \(\sigma^2/S_{jj}\) is the variance the slope would have in a simple regression on \(x_j\) (with the same \(\sigma^2\)). The VIF says how many times larger the variance is because \(x_j\) is correlated with the other predictors. \(\mathrm{VIF}_j = 1\) when \(x_j\) is uncorrelated with them; \(\mathrm{VIF}_j \to \infty\) as \(R_j^2 \to 1\). Module 5 studies large VIFs (multicollinearity) and the estimators designed for them.

5 Worked example

We use the 392 cars with horsepower recorded and three predictors: weight (1000 lb), model year, horsepower (100 hp). Origin is added in Lesson 2.9.

Model year (per year) 1.230 0.749 (0.052) 1.22
Horsepower (per 100 hp) −15.784 −0.500 (0.944) 4.39

\(R^2 = 0.808\), \(\hat\sigma = 3.430\). Weight and horsepower are strongly correlated (\(r = 0.865\)); both are moderately correlated with model year (\(-0.309\) and \(-0.416\)). The large simple-regression slope of horsepower mostly reflects that powerful cars are heavy and old.

5.2 Frisch–Waugh–Lovell and added-variable plots

Regressing mpg on (intercept, year, horsepower) and weight on (intercept, year, horsepower), and then the first residuals on the second, gives the slope \(-6.4477\), identical to the full-model coefficient; the residuals agree with the full-model residuals to within \(10^{-11}\). The added-variable plots show both coefficients as scatterplots.

Python code 
import numpy as np
import pandas as pd
import matplotlib.pyplot as plt

cols = ["mpg", "cylinders", "displacement", "horsepower", "weight",
        "acceleration", "model_year", "origin", "car_name"]
auto = pd.read_csv("data/auto-mpg.data", sep=r"\s+", header=None,
                   names=cols, na_values="?", quotechar='"').dropna().reset_index(drop=True)
y = auto["mpg"].to_numpy()
w = auto["weight"].to_numpy() / 1000
yr = auto["model_year"].to_numpy().astype(float)
hp = auto["horsepower"].to_numpy() / 100
n = len(y)

def ls(v, *xs):
    """Least squares of v on an intercept and xs: returns (coefficients, residuals)."""
    X = np.column_stack([np.ones(len(v)), *xs])
    b = np.linalg.lstsq(X, v, rcond=None)[0]
    return b, v - X @ b

b, e = ls(y, w, yr, hp)
print("full model:", b.round(4))
_, ry = ls(y, yr, hp); _, rw = ls(w, yr, hp)              # Frisch-Waugh-Lovell for weight
print("FWL slope:", round((rw @ ry) / (rw @ rw), 4), " full coefficient:", round(b[1], 4))
print("max |residual difference|:", f"{np.abs((ry - b[1] * rw) - e).max():.1e}")

_, ryh = ls(y, w, yr); _, rh = ls(hp, w, yr)
fig, axes = plt.subplots(1, 2, figsize=(8, 3.6))
for ax, rx, ryy, slope, title, lab in ((axes[0], rw, ry, b[1], "Weight", "weight | others"),
                                       (axes[1], rh, ryh, b[3], "Horsepower", "horsepower | others")):
    ax.scatter(rx, ryy, s=10, alpha=0.35, color="black")
    g = np.linspace(rx.min(), rx.max(), 2)
    ax.plot(g, slope * g, linewidth=2)
    ax.set_title(title); ax.set_xlabel(lab); ax.set_ylabel("mpg | others")
plt.tight_layout()
plt.show()

5.3 Omitting model year

Dropping model year (the short model mpg ~ weight + horsepower of Lesson 2.1, Exercise C.2) changes the horsepower slope from \(-0.500\) to \(-4.730\) and the weight slope from \(-6.448\) to \(-5.794\). Regressing model year on (intercept, weight, horsepower) gives \(\hat{\boldsymbol\Delta} = (79.283, 0.873, -5.650)\): given weight, more powerful cars are older, by 5.65 years per 100 hp. Theorem 2.5.2(a) reproduces the short-model coefficients exactly: \[ -0.500 + (-5.650)(0.749) = -4.730, \qquad -6.448 + (0.873)(0.749) = -5.794 . \] The short model attributes to horsepower the fuel-economy progress of the later model years, in which cars of a given weight had less power.

5.4 Precision: the variance inflation factors

Theorem 2.5.3 reproduces each standard error from \(\hat\sigma\), \(S_{jj}\) and \(R_j^2\). For weight, \(\hat\sigma/\sqrt{(1 - 0.7506)\times282.10} = 0.4089\), the value in the table. In the weight + year model of Lesson 2.1 the weight slope had standard error \(0.215\) (392 cars: \(0.2146\)); adding horsepower nearly doubles it, because the VIF of weight rises from \(1.11\) to \(4.01\) and \(\sqrt{4.01/1.11} \approx 1.9\).

R code 
# Uses auto and fit from Section 5.2 (run that code first).
short <- lm(mpg ~ w + hp, data = auto)
Delta <- coef(lm(model_year ~ w + hp, data = auto))
b <- coef(fit)
rbind(short_model = coef(short),
      identity = b[c("(Intercept)", "w", "hp")] + Delta * b["model_year"])

vif <- sapply(c("w", "model_year", "hp"), function(v) {
  others <- setdiff(c("w", "model_year", "hp"), v)
  Rj2 <- summary(lm(reformulate(others, v), data = auto))$r.squared
  1 / (1 - Rj2)
})
Sjj <- sapply(auto[c("w", "model_year", "hp")], function(x) sum((x - mean(x))^2))
cbind(VIF = vif, se_formula = sigma(fit) * sqrt(vif / Sjj),
      se_lm = summary(fit)$coefficients[-1, 2])
Python code 
# Uses np, y, w, yr, hp, n, ls, b and e from Section 5.2 (run that code first).
b_short, _ = ls(y, w, hp)
Delta, _ = ls(yr, w, hp)
print("short model:     ", b_short.round(4))
print("identity:        ", (b[[0, 1, 3]] + Delta * b[2]).round(4))
print("Delta:           ", Delta.round(4))

X = np.column_stack([np.ones(n), w, yr, hp])
sigma_hat = np.sqrt(e @ e / (n - 4))
se_lm = sigma_hat * np.sqrt(np.diag(np.linalg.inv(X.T @ X)))
preds = {"weight": w, "year": yr, "horsepower": hp}
for j, (name, xj) in enumerate(preds.items(), start=1):
    others = [v for k, v in preds.items() if k != name]
    _, r = ls(xj, *others)
    Rj2 = 1 - (r @ r) / np.sum((xj - xj.mean())**2)
    Sjj = np.sum((xj - xj.mean())**2)
    print(f"{name:10s} VIF = {1 / (1 - Rj2):.3f}  se formula = {sigma_hat / np.sqrt((1 - Rj2) * Sjj):.4f}"
          f"  se = {se_lm[j]:.4f}")

5.5 Simulation: bias against variance

Keep the 392 observed predictor values, set the full-model coefficients to \(\boldsymbol\beta = (-13.7, -6.45, 0.749, -0.50)^\top\) and \(\sigma = 3.43\), and simulate 10,000 data sets. Fit the full model and the short model without model year each time. Theorem 2.5.2(b) predicts the short-model means \(-6.45 + 0.873 \times 0.749 = -5.796\) for weight and \(-0.50 + (-5.650)(0.749) = -4.732\) for horsepower. Results (Python, seed 2026):

Coefficient Full model: mean (SD) Short model: mean (SD) Root mean squared error, full / short
Weight (\(\beta = -6.45\)) −6.448 (0.407) −5.794 (0.405) 0.41 / 0.77
Horsepower (\(\beta = -0.50\)) −0.506 (0.942) −4.738 (0.895) 0.94 / 4.33

The full model is unbiased; the short model’s estimates are centred where Theorem 2.5.2(b) predicts. The short model is slightly less variable, as part (c) guarantees, but here its bias dominates and its mean squared error is much larger. Omitting a variable reduces variance only enough to matter when the omitted coefficient or the correlation is small.

R code 
# Self-contained: reads the 392 predictor rows and needs nothing from earlier sections.
cols <- c("mpg", "cylinders", "displacement", "horsepower", "weight",
          "acceleration", "model_year", "origin", "car_name")
auto <- na.omit(read.table("data/auto-mpg.data", col.names = cols, na.strings = "?"))
X  <- cbind(1, auto$weight / 1000, auto$model_year, auto$horsepower / 100)
X1 <- X[, c(1, 2, 4)]                                   # short model: no model year
n <- nrow(X); beta <- c(-13.7, -6.45, 0.749, -0.50); sigma <- 3.43; R <- 10000
A_full  <- solve(crossprod(X), t(X))
A_short <- solve(crossprod(X1), t(X1))
Delta <- drop(A_short %*% X[, 3])
set.seed(2026)
Y <- matrix(drop(X %*% beta), R, n, byrow = TRUE) + matrix(rnorm(R * n, 0, sigma), R, n)
B_full <- Y %*% t(A_full); B_short <- Y %*% t(A_short)
rmse <- function(est, truth) sqrt(mean((est - truth)^2))
data.frame(
  coef = c("weight", "horsepower"),
  truth = beta[c(2, 4)],
  predicted_short = beta[c(2, 4)] + Delta[2:3] * beta[3],
  full_mean = colMeans(B_full[, c(2, 4)]), full_sd = apply(B_full[, c(2, 4)], 2, sd),
  short_mean = colMeans(B_short[, 2:3]), short_sd = apply(B_short[, 2:3], 2, sd),
  rmse_full = c(rmse(B_full[, 2], beta[2]), rmse(B_full[, 4], beta[4])),
  rmse_short = c(rmse(B_short[, 2], beta[2]), rmse(B_short[, 3], beta[4])))

import pandas as pd

auto = pd.read_csv("data/auto-mpg.data", sep=r"\s+", header=None,
                   names=cols, na_values="?", quotechar='"').dropna()
X = np.column_stack([np.ones(len(auto)), auto["weight"] / 1000, auto["model_year"],
                     auto["horsepower"] / 100])
X1 = X[:, [0, 1, 3]]                                    # short model: no model year
n = len(X); beta = np.array([-13.7, -6.45, 0.749, -0.50]); sigma, R = 3.43, 10_000
A_full = np.linalg.solve(X.T @ X, X.T)
A_short = np.linalg.solve(X1.T @ X1, X1.T)
Delta = A_short @ X[:, 2]
rng = np.random.default_rng(2026)
Y = X @ beta + sigma * rng.standard_normal((R, n))
B_full, B_short = Y @ A_full.T, Y @ A_short.T
rmse = lambda est, truth: np.sqrt(np.mean((est - truth)**2))
print(pd.DataFrame({
    "truth": beta[[1, 3]],
    "predicted_short": beta[[1, 3]] + Delta[1:] * beta[2],
    "full_mean": B_full[:, [1, 3]].mean(axis=0), "full_sd": B_full[:, [1, 3]].std(axis=0, ddof=1),
    "short_mean": B_short[:, 1:].mean(axis=0), "short_sd": B_short[:, 1:].std(axis=0, ddof=1),
    "rmse_full": [rmse(B_full[:, 1], beta[1]), rmse(B_full[:, 3], beta[3])],
    "rmse_short": [rmse(B_short[:, 1], beta[1]), rmse(B_short[:, 2], beta[3])]},
    index=["weight", "horsepower"]).round(4).to_string())

6 Common misconceptions

Misconceptions

  1. “A non-significant coefficient means the variable is unrelated to \(y\).” — Horsepower is strongly related to mpg on its own; its coefficient is small given weight and model year, and imprecise because of a VIF of 4.4.
  2. “A plot of \(y\) against \(x_j\) shows the coefficient of \(x_j\).” — It shows the marginal relationship. The added-variable plot shows the partial one.
  3. “Including more variables always reduces bias.” — Only for variables that confound the relationship. Including a mediator or a consequence of \(y\) changes the meaning of the coefficient.
  4. “Omitting a variable always biases the other coefficients.” — Not if it is uncorrelated with the included predictors (in the sample) or has coefficient zero.
  5. “A high VIF means the model is wrong.” — It means the separate effects are hard to estimate from these data. Predictions within the data region can still be precise.

7 Key takeaways

  • Frisch–Waugh–Lovell: \(\hat\beta_j\) is the slope of \(y\)-residuals on \(x_j\)-residuals after removing the other predictors from both.
  • The added-variable plot displays that regression; its slope is \(\hat\beta_j\) and its residuals are the model residuals.
  • Omitting \(\mathbf{X}_2\) changes the coefficients by exactly \(\hat{\boldsymbol\Delta}\hat{\boldsymbol\beta}_2\); in expectation the bias is \(\hat{\boldsymbol\Delta}\boldsymbol\beta_2\).
  • \(\operatorname{Var}(\hat\beta_j) = \mathrm{VIF}_j\,\sigma^2/S_{jj}\): correlation with the other predictors inflates the variance.
  • Choosing predictors trades bias against variance, and the subject matter decides which variables should be held fixed.

8 Exercises

8.1 A. Conceptual

A.1 (★). In the horsepower added-variable plot of Section 5.2, what do the horizontal axis values measure? Why is the horizontal spread much narrower than the spread of horsepower itself?

Solution

They are the residuals from regressing horsepower on weight and model year: how much more (or less) powerful a car is than expected for its weight and year. Since weight and year explain \(R_j^2 = 77\%\) of the variation in horsepower, the residuals have only \(23\%\) of its variance, i.e. less than half its standard deviation (\(\sqrt{0.228} = 0.48\)).

A.2 (★★). A researcher regresses blood pressure on salt intake and wonders whether to add body weight, which is associated with both. Using Theorem 2.5.2, describe what will happen to the salt coefficient if (a) body weight affects blood pressure and is positively correlated with salt intake given the other predictors; (b) body weight is unrelated to salt intake. What subject-matter question should decide whether to include it?

Solution
  1. Without body weight, the salt coefficient absorbs \(\hat\delta\beta_{\text{weight}} > 0\); adding body weight lowers it. (b) It stays the same (and its standard error may fall, since \(\hat\sigma\) falls). The deciding question is causal: if salt intake affects body weight (weight is a mediator), adjusting for weight removes part of the effect of salt and estimates only the “direct” part; if weight is a common cause of both, it should be included.

8.2 B. Mathematical

B.1 (★★). Use Theorem 2.5.1 to show that, when \(\mathbf{X}_1 = \mathbf{1}\) (intercept only), \(\hat{\boldsymbol\beta}_2\) equals the slope vector obtained by regressing the centred \(y\) on the centred predictors without an intercept.

Solution

With \(\mathbf{X}_1 = \mathbf{1}\), \(\mathbf{H}_1 = \tfrac1n\mathbf{J}\) and \(\mathbf{M}_1 = \mathbf{C}\), the centring matrix of Lesson 2.2. So \(\mathbf{M}_1\mathbf{y}\) and \(\mathbf{M}_1\mathbf{X}_2\) are the centred response and predictors, and Theorem 2.5.1 gives \(\hat{\boldsymbol\beta}_2 = (\mathbf{X}_2^\top\mathbf{C}\mathbf{X}_2)^{-1}\mathbf{X}_2^\top\mathbf{C}\mathbf{y}\), the no-intercept regression of centred \(y\) on centred predictors. \(\mathbf{X}_2^\top\mathbf{C}\mathbf{X}_2\) is the matrix of centred cross-products used in Lesson 2.4, Exercise B.2.

B.2 (★★). Show that \(\mathbf{x}_j^\top\mathbf{M}_{-j}\mathbf{x}_j = (1 - R_j^2)S_{jj}\) when \(\mathbf{X}_{-j}\) contains the intercept, and deduce that \(\mathrm{VIF}_j \ge 1\).

Solution

\(\mathbf{M}_{-j}\mathbf{x}_j\) is the residual vector from regressing \(x_j\) on \(\mathbf{X}_{-j}\); its squared length is that regression’s SSE. With an intercept, \(\mathrm{SSE} = (1 - R_j^2)\,\mathrm{SST} = (1 - R_j^2)S_{jj}\) (Theorem 2.3.3b). Since \(0 \le R_j^2 < 1\) under A0, \(\mathrm{VIF}_j = 1/(1 - R_j^2) \ge 1\), with equality iff \(x_j\) is uncorrelated with every other predictor’s linear combination, i.e. \(R_j^2 = 0\).

B.3 (★★). In the model \(y = \beta_0 + \beta_1x_1 + \beta_2x_2 + \varepsilon\), express \(\mathrm{VIF}_1\) in terms of the sample correlation \(r_{12}\), and show that \(\operatorname{Var}(\hat\beta_1) = \sigma^2/[(1 - r_{12}^2)S_{11}]\). For the weight + year model of Lesson 2.1, compute the VIF.

Solution

With one other predictor, \(R_1^2 = r_{12}^2\), so \(\mathrm{VIF}_1 = 1/(1 - r_{12}^2)\) and the variance follows from Theorem 2.5.3. For weight and model year (398 cars), \(r = -0.3066\), so \(\mathrm{VIF} = 1/(1 - 0.0940) = 1.104\); with the 392 cars, \(r = -0.309\) and \(\mathrm{VIF} = 1.11\), the value used in Section 5.4.

8.3 C. Computational

C.1 (★). Draw the added-variable plot for model year in the three-predictor model and check that the slope through the origin is \(0.749\). Compare its horizontal spread with that of the weight and horsepower plots, and relate the comparison to the VIFs.

Solution

The slope is \(0.7487\). Model year has the smallest VIF (1.22): weight and horsepower explain only \(18\%\) of its variation, so its added-variable plot keeps most of the original spread (residual SD about \(0.90\) of the SD of model year), and its coefficient is estimated precisely (se \(0.052\)).

C.2 (★★). Add displacement (100 cubic inches) and cylinders to the three-predictor model. Compute all five VIFs and compare the standard error of the weight coefficient with Section 5.1.

Solution

VIFs: weight 8.23, model year 1.24, horsepower 5.63, displacement 19.4, cylinders 10.6. The weight coefficient becomes \(-6.525\) with standard error \(0.587\) (against \(0.409\) with three predictors), while \(R^2\) barely changes. Displacement and cylinders carry almost no information beyond weight and horsepower. This is the multicollinearity problem of Module 5, which is why the running example keeps these two variables out until then.

C.3 (★★). Repeat the simulation of Section 5.5, but replace model year by a variable with the same mean and standard deviation that is uncorrelated with weight and horsepower in the sample (for example, the residuals of model year on weight and horsepower, shifted and rescaled). Predict and then verify the bias of the short model.

Solution

If the new variable \(z\) is orthogonal to the slope columns of \(\mathbf{X}_1\) (the residuals of model year on \(\mathbf{X}_1\) are; shifting by a constant only affects the intercept), then \(\hat{\boldsymbol\Delta}\) has zero slope entries and Theorem 2.5.2 predicts no bias in the weight and horsepower slopes. In fact part (a) says more: the short-model slopes are then identical to the full-model slopes in every data set, so they also have the same variance (part (c) holds with equality). Only the intercept is shifted, by \(\hat\Delta_0\beta_z\).

import numpy as np, pandas as pd
cols = ["mpg", "cylinders", "displacement", "horsepower", "weight",
        "acceleration", "model_year", "origin", "car_name"]
auto = pd.read_csv("data/auto-mpg.data", sep=r"\s+", header=None,
                   names=cols, na_values="?", quotechar='"').dropna()
X1 = np.column_stack([np.ones(len(auto)), auto["weight"] / 1000, auto["horsepower"] / 100])
yr = auto["model_year"].to_numpy().astype(float)
r = yr - X1 @ np.linalg.lstsq(X1, yr, rcond=None)[0]          # orthogonal to X1
z = yr.mean() + yr.std() * r / r.std()                        # same mean and SD as model year
X = np.column_stack([X1[:, 0], X1[:, 1], z, X1[:, 2]])
n = len(X); beta = np.array([-13.7, -6.45, 0.749, -0.50]); sigma, R = 3.43, 10_000
A_full = np.linalg.solve(X.T @ X, X.T); A_short = np.linalg.solve(X1.T @ X1, X1.T)
print("Delta (slopes should be 0):", (A_short @ z).round(6))
rng = np.random.default_rng(2026)
Y = X @ beta + sigma * rng.standard_normal((R, n))
Bf, Bs = Y @ A_full.T, Y @ A_short.T
print("full  slopes mean:", Bf[:, [1, 3]].mean(axis=0).round(4), " sd:", Bf[:, [1, 3]].std(axis=0, ddof=1).round(4))
print("short slopes mean:", Bs[:, 1:].mean(axis=0).round(4), " sd:", Bs[:, 1:].std(axis=0, ddof=1).round(4))

Output: \(\hat{\boldsymbol\Delta} = (75.98, 0, 0)\); full and short slopes both average \((-6.4475, -0.5057)\) with standard deviations \((0.4046, 0.8949)\), identical in every replication. Compare Section 5.5, where the omitted variable was correlated with the predictors.
