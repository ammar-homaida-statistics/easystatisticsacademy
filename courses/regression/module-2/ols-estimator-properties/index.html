1 Learning objectives

By the end of this lesson you will be able to:

  1. prove that \(\hat{\boldsymbol\beta}\) is unbiased and derive \(\operatorname{Cov}(\hat{\boldsymbol\beta}) = \sigma^2(\mathbf{X}^\top\mathbf{X})^{-1}\), naming the assumptions each result uses;
  2. state and prove the Gauss–Markov theorem in matrix form;
  3. prove that \(\hat\sigma^2 = \mathrm{SSE}/(n - p - 1)\) is unbiased, using the trace;
  4. prove, under normal errors, that \(\hat{\boldsymbol\beta}\) is multivariate normal, \(\mathrm{SSE}/\sigma^2 \sim \chi^2_{n-p-1}\), and \(\hat{\boldsymbol\beta}\) and SSE are independent, and deduce the \(t\)-distribution used for inference;
  5. compute and interpret the estimated covariance matrix of \(\hat{\boldsymbol\beta}\) and standard errors of linear combinations \(\mathbf{a}^\top\hat{\boldsymbol\beta}\).

2 Motivation

Lesson 1.4 derived the properties of the slope and intercept with scalar algebra, and Lesson 1.7 used the fact that SSE is independent of the estimates without proving it for every case. With the tools of Lesson 2.2 and the hat matrix of Lesson 2.3, all of these results take a few lines each, for any number of predictors, and the missing proof can be completed. This lesson is the theoretical core of Module 2: every test and interval in Lessons 2.6–2.8 rests on it.

3 Notation for this lesson

Symbol Meaning
\(\mathbf{A} = (\mathbf{X}^\top\mathbf{X})^{-1}\mathbf{X}^\top\) the matrix with \(\hat{\boldsymbol\beta} = \mathbf{A}\mathbf{y}\)
\(\mathbf{M} = \mathbf{I}_n - \mathbf{H}\) residual-maker matrix: \(\mathbf{e} = \mathbf{M}\mathbf{y} = \mathbf{M}\boldsymbol\varepsilon\)
\(\hat\sigma^2 = \mathrm{MS_{Res}} = \mathrm{SSE}/(n-p-1)\) unbiased estimator of \(\sigma^2\)
\(\widehat{\operatorname{Cov}}(\hat{\boldsymbol\beta}) = \hat\sigma^2(\mathbf{X}^\top\mathbf{X})^{-1}\) estimated covariance matrix
\(\operatorname{se}(\hat\beta_j) = \hat\sigma\sqrt{c_{jj}}\) standard error; \(c_{jj}\) is the \(j\)-th diagonal element of \((\mathbf{X}^\top\mathbf{X})^{-1}\)
\(\mathbf{B} \succeq \mathbf{0}\) \(\mathbf{B}\) is positive semidefinite

Indices run \(j = 0, 1, \dots, p\), matching \(\boldsymbol\beta = (\beta_0, \dots, \beta_p)^\top\).

Assumptions used in this lesson

The model is \(\mathbf{y} = \mathbf{X}\boldsymbol\beta + \boldsymbol\varepsilon\) (Lesson 2.2), with

  • A0 (Full rank). \(\mathbf{X}\) is fixed with \(\operatorname{rank}(\mathbf{X}) = p + 1\).
  • A1 (Correct mean function). \(E(\boldsymbol\varepsilon) = \mathbf{0}\).
  • A2–A3 (Constant variance, uncorrelated errors). \(\operatorname{Cov}(\boldsymbol\varepsilon) = \sigma^2\mathbf{I}_n\).
  • A4 (Normality). \(\boldsymbol\varepsilon \sim N_n(\mathbf{0}, \sigma^2\mathbf{I}_n)\).

Each theorem below names the assumptions it uses. What each assumption means: Lesson 1.1, Assumptions.

4 Theory

4.1 The estimator as a linear function of the errors

Under A0, \(\hat{\boldsymbol\beta} = \mathbf{A}\mathbf{y}\) with \(\mathbf{A} = (\mathbf{X}^\top\mathbf{X})^{-1}\mathbf{X}^\top\), and \(\mathbf{A}\mathbf{X} = \mathbf{I}_{p+1}\). Substituting \(\mathbf{y} = \mathbf{X}\boldsymbol\beta + \boldsymbol\varepsilon\): \[ \hat{\boldsymbol\beta} = \boldsymbol\beta + \mathbf{A}\boldsymbol\varepsilon, \qquad \mathbf{e} = \mathbf{M}\boldsymbol\varepsilon \quad (\text{Theorem 2.3.3c, Lesson 2.3}). \] Every property below follows from these two linear representations and the rules for random vectors in Lesson 2.2 (Theorems 2.2.1–2.2.3).

4.2 Mean and covariance

Theorem 2.4.1 (Unbiasedness) — uses A0, A1

\(E(\hat{\boldsymbol\beta}) = \boldsymbol\beta\), and \(E(\mathbf{a}^\top\hat{\boldsymbol\beta}) = \mathbf{a}^\top\boldsymbol\beta\) for every fixed \(\mathbf{a}\).

Derivation

\(E(\hat{\boldsymbol\beta}) = \boldsymbol\beta + \mathbf{A}E(\boldsymbol\varepsilon) = \boldsymbol\beta\) by A1; the second statement is linearity of expectation.

Theorem 2.4.2 (Covariance matrices) — uses A0–A3

  1. \(\operatorname{Cov}(\hat{\boldsymbol\beta}) = \sigma^2(\mathbf{X}^\top\mathbf{X})^{-1}\); in particular \(\operatorname{Var}(\hat\beta_j) = \sigma^2c_{jj}\) and \(\operatorname{Var}(\mathbf{a}^\top\hat{\boldsymbol\beta}) = \sigma^2\mathbf{a}^\top(\mathbf{X}^\top\mathbf{X})^{-1}\mathbf{a}\).
  2. \(\operatorname{Cov}(\hat{\mathbf{y}}) = \sigma^2\mathbf{H}\) and \(\operatorname{Cov}(\mathbf{e}) = \sigma^2(\mathbf{I}_n - \mathbf{H})\); so \(\operatorname{Var}(e_i) = \sigma^2(1 - h_{ii})\).
  3. \(\operatorname{Cov}(\hat{\boldsymbol\beta}, \mathbf{e}) = \mathbf{0}\).
Derivation
  1. By Theorem 2.2.1, \(\operatorname{Cov}(\mathbf{A}\boldsymbol\varepsilon) = \mathbf{A}(\sigma^2\mathbf{I})\mathbf{A}^\top = \sigma^2(\mathbf{X}^\top\mathbf{X})^{-1}\mathbf{X}^\top\mathbf{X}(\mathbf{X}^\top\mathbf{X})^{-1} = \sigma^2(\mathbf{X}^\top\mathbf{X})^{-1}\).
  2. \(\hat{\mathbf{y}} = \mathbf{H}\mathbf{y}\) and \(\mathbf{e} = \mathbf{M}\boldsymbol\varepsilon\), with \(\mathbf{H}\) and \(\mathbf{M}\) symmetric and idempotent: \(\sigma^2\mathbf{H}\mathbf{H}^\top = \sigma^2\mathbf{H}\) and \(\sigma^2\mathbf{M}\mathbf{M}^\top = \sigma^2\mathbf{M}\).
  3. \(\operatorname{Cov}(\mathbf{A}\boldsymbol\varepsilon, \mathbf{M}\boldsymbol\varepsilon) = \sigma^2\mathbf{A}\mathbf{M}^\top = \sigma^2(\mathbf{X}^\top\mathbf{X})^{-1}\mathbf{X}^\top(\mathbf{I} - \mathbf{H}) = \mathbf{0}\), because \(\mathbf{X}^\top(\mathbf{I} - \mathbf{H}) = [(\mathbf{I} - \mathbf{H})\mathbf{X}]^\top = \mathbf{0}\).

Part (b) has a practical consequence: even when the errors have constant variance, the residuals do not. Observations with high leverage have residuals with smaller variance, because the fit is pulled towards them. Module 3 corrects for this with standardised and studentised residuals. For \(p = 1\), part (a) reproduces Theorem 1.4.2, Lesson 1.4 via \((\mathbf{X}^\top\mathbf{X})^{-1}\) from Lesson 2.3.

4.3 The Gauss–Markov theorem

Theorem 2.4.3 (Gauss–Markov) — uses A0–A3

Let \(\tilde{\boldsymbol\beta} = \mathbf{C}\mathbf{y}\) be any linear estimator that is unbiased for \(\boldsymbol\beta\) for every value of \(\boldsymbol\beta\). Then \[ \operatorname{Cov}(\tilde{\boldsymbol\beta}) - \operatorname{Cov}(\hat{\boldsymbol\beta}) \succeq \mathbf{0}. \] Consequently, for every fixed \(\mathbf{a}\), \(\operatorname{Var}(\mathbf{a}^\top\tilde{\boldsymbol\beta}) \ge \operatorname{Var}(\mathbf{a}^\top\hat{\boldsymbol\beta})\): \(\mathbf{a}^\top\hat{\boldsymbol\beta}\) is the best linear unbiased estimator (BLUE) of \(\mathbf{a}^\top\boldsymbol\beta\).

Derivation

Write \(\mathbf{C} = \mathbf{A} + \mathbf{D}\). Unbiasedness for every \(\boldsymbol\beta\) requires \(E(\mathbf{C}\mathbf{y}) = \mathbf{C}\mathbf{X}\boldsymbol\beta = \boldsymbol\beta\) for all \(\boldsymbol\beta\), i.e. \(\mathbf{C}\mathbf{X} = \mathbf{I}\). Since \(\mathbf{A}\mathbf{X} = \mathbf{I}\), this means \(\mathbf{D}\mathbf{X} = \mathbf{0}\). Then \[ \operatorname{Cov}(\tilde{\boldsymbol\beta}) = \sigma^2(\mathbf{A} + \mathbf{D})(\mathbf{A} + \mathbf{D})^\top = \sigma^2\bigl(\mathbf{A}\mathbf{A}^\top + \mathbf{A}\mathbf{D}^\top + \mathbf{D}\mathbf{A}^\top + \mathbf{D}\mathbf{D}^\top\bigr). \] Here \(\mathbf{A}\mathbf{A}^\top = (\mathbf{X}^\top\mathbf{X})^{-1}\) and \(\mathbf{D}\mathbf{A}^\top = \mathbf{D}\mathbf{X}(\mathbf{X}^\top\mathbf{X})^{-1} = \mathbf{0}\) (and its transpose \(\mathbf{A}\mathbf{D}^\top = \mathbf{0}\)). Hence \(\operatorname{Cov}(\tilde{\boldsymbol\beta}) - \operatorname{Cov}(\hat{\boldsymbol\beta}) = \sigma^2\mathbf{D}\mathbf{D}^\top\), which is positive semidefinite since \(\mathbf{a}^\top\mathbf{D}\mathbf{D}^\top\mathbf{a} = \lVert\mathbf{D}^\top\mathbf{a}\rVert^2 \ge 0\). Applying this with \(\mathbf{a}\) gives the scalar statement. Equality for all \(\mathbf{a}\) holds only if \(\mathbf{D} = \mathbf{0}\).

Two limits of the theorem matter later. It compares only linear unbiased estimators: a biased estimator, such as ridge regression in Module 5, can have smaller mean squared error. And it needs A2–A3: with unequal variances or correlated errors, generalised least squares is better (Module 3).

4.4 Estimating \(\sigma^2\)

Theorem 2.4.4 (Unbiased estimator of \(\sigma^2\)) — uses A0–A3

\(E(\mathrm{SSE}) = (n - p - 1)\sigma^2\), so \(\hat\sigma^2 = \mathrm{SSE}/(n - p - 1)\) is unbiased for \(\sigma^2\).

Derivation

\(\mathrm{SSE} = \mathbf{e}^\top\mathbf{e} = \boldsymbol\varepsilon^\top\mathbf{M}^\top\mathbf{M}\boldsymbol\varepsilon = \boldsymbol\varepsilon^\top\mathbf{M}\boldsymbol\varepsilon\). By Theorem 2.2.2, Lesson 2.2 with mean \(\mathbf{0}\) and covariance \(\sigma^2\mathbf{I}\), \(E(\boldsymbol\varepsilon^\top\mathbf{M}\boldsymbol\varepsilon) = \operatorname{tr}(\mathbf{M}\sigma^2\mathbf{I}) = \sigma^2\operatorname{tr}(\mathbf{I} - \mathbf{H}) = \sigma^2(n - p - 1)\) (Theorem 2.3.2c). No normality is used.

The divisor \(n - p - 1\) is the residual degrees of freedom: the residual vector lives in the \((n - p - 1)\)-dimensional orthogonal complement of \(\mathcal{C}(\mathbf{X})\). For \(p = 1\) it is the \(n - 2\) of Lesson 1.4.

4.5 Distribution theory under normal errors

Theorem 2.4.5 (Sampling distributions) — uses A0–A4

  1. \(\hat{\boldsymbol\beta} \sim N_{p+1}\bigl(\boldsymbol\beta, \sigma^2(\mathbf{X}^\top\mathbf{X})^{-1}\bigr)\).
  2. \(\mathrm{SSE}/\sigma^2 \sim \chi^2_{n-p-1}\).
  3. \(\hat{\boldsymbol\beta}\) and SSE are independent.
  4. For every fixed \(\mathbf{a} \ne \mathbf{0}\), \[ T = \frac{\mathbf{a}^\top\hat{\boldsymbol\beta} - \mathbf{a}^\top\boldsymbol\beta}{\hat\sigma\sqrt{\mathbf{a}^\top(\mathbf{X}^\top\mathbf{X})^{-1}\mathbf{a}}} \sim t_{n-p-1}; \qquad \text{in particular}\quad \frac{\hat\beta_j - \beta_j}{\operatorname{se}(\hat\beta_j)} \sim t_{n-p-1}. \]
Derivation

  1. \(\hat{\boldsymbol\beta} = \boldsymbol\beta + \mathbf{A}\boldsymbol\varepsilon\) is a linear transformation of a normal vector; Theorem 2.2.3(a) of Lesson 2.2 and Theorem 2.4.2(a) give the result.

  2. \(\mathbf{M}\) is symmetric and idempotent with rank \(m = n - p - 1\), so its eigenvalues are \(m\) ones and \(p + 1\) zeros, and \(\mathbf{M} = \mathbf{P}\mathbf{P}^\top\) where \(\mathbf{P}\) (\(n\times m\)) holds the orthonormal eigenvectors for eigenvalue 1, so \(\mathbf{P}^\top\mathbf{P} = \mathbf{I}_m\). Then \(\mathrm{SSE} = \boldsymbol\varepsilon^\top\mathbf{P}\mathbf{P}^\top\boldsymbol\varepsilon = \lVert\mathbf{z}\rVert^2\) with \(\mathbf{z} = \mathbf{P}^\top\boldsymbol\varepsilon \sim N_m(\mathbf{0}, \sigma^2\mathbf{P}^\top\mathbf{P}) = N_m(\mathbf{0}, \sigma^2\mathbf{I}_m)\). The \(m\) entries of \(\mathbf{z}/\sigma\) are independent \(N(0,1)\), so \(\mathrm{SSE}/\sigma^2 = \sum_{k=1}^m (z_k/\sigma)^2 \sim \chi^2_m\).

  3. \(\hat{\boldsymbol\beta} - \boldsymbol\beta = \mathbf{A}\boldsymbol\varepsilon\) and \(\mathbf{e} = \mathbf{M}\boldsymbol\varepsilon\) are linear transformations of the same normal vector, hence jointly normal, with cross-covariance \(\sigma^2\mathbf{A}\mathbf{M} = \mathbf{0}\) (Theorem 2.4.2c). By Theorem 2.2.3(c) they are independent. \(\mathrm{SSE} = \mathbf{e}^\top\mathbf{e}\) is a function of \(\mathbf{e}\) alone, so it is independent of \(\hat{\boldsymbol\beta}\).

  4. \(Z = (\mathbf{a}^\top\hat{\boldsymbol\beta} - \mathbf{a}^\top\boldsymbol\beta)/\bigl(\sigma\sqrt{\mathbf{a}^\top(\mathbf{X}^\top\mathbf{X})^{-1}\mathbf{a}}\bigr) \sim N(0, 1)\) by (a), and it is independent of \(W = \mathrm{SSE}/\sigma^2 \sim \chi^2_m\) by (b)–(c). Then \(T = Z/\sqrt{W/m}\), because \(\hat\sigma/\sigma = \sqrt{W/m}\); by definition \(T \sim t_m\).

Completing Module 1

For \(p = 1\), Theorem 2.4.5 is Theorem 1.7.1, Lesson 1.7, now with a complete proof of the \(\chi^2\) distribution and of the independence of SSE and the estimates. The same argument works for any \(p\), which is why the inference of Lessons 2.6–2.8 needs no new distribution theory.

Which parts need normality? Parts (a)–(d) do, exactly. But the means and covariances (Theorems 2.4.1–2.4.4) do not, and for large \(n\) the central limit theorem makes \(\hat{\boldsymbol\beta}\) approximately normal under A1–A3 with mild conditions on \(\mathbf{X}\), so the \(t\)-intervals remain approximately valid. Part (b) is different: the variance of SSE depends on the tails of the error distribution. For independent errors with variance \(\sigma^2\) and kurtosis \(\kappa = E(\varepsilon_i^4)/\sigma^4\), \[ \operatorname{Var}(\mathrm{SSE}/\sigma^2) = 2(n - p - 1) + (\kappa - 3)\sum_{i=1}^n (1 - h_{ii})^2 \] (a standard result on quadratic forms; Seber and Lee, 2003, Chapter 1), which equals the \(\chi^2\) variance \(2(n-p-1)\) only when \(\kappa = 3\). Intervals for \(\sigma^2\) are therefore not robust to non-normality, even for large \(n\). The simulation in Section 5.3 shows both effects.

4.6 Maximum likelihood

Under A4 the log-likelihood is \(\ell(\boldsymbol\beta, \sigma^2) = -\tfrac n2\log(2\pi\sigma^2) - S(\boldsymbol\beta)/(2\sigma^2)\). For any \(\sigma^2\) it is maximised over \(\boldsymbol\beta\) by minimising \(S(\boldsymbol\beta)\), so the ML estimator of \(\boldsymbol\beta\) is \(\hat{\boldsymbol\beta}\). Maximising over \(\sigma^2\) then gives \(\tilde\sigma^2 = \mathrm{SSE}/n\), which is biased: \(E(\tilde\sigma^2) = (n - p - 1)\sigma^2/n\) (Exercise B.3). The bias matters when \(p\) is not small relative to \(n\).

5 Worked example

The model is mpg on weight (1000 lb) and model year for all \(n = 398\) cars (\(p = 2\), residual df \(= 395\)).

5.1 The estimated covariance matrix

\(\mathrm{SSE} = 4659.84\), so \(\hat\sigma^2 = 4659.84/395 = 11.797\) and \(\hat\sigma = 3.435\). The estimated covariance matrix \(\hat\sigma^2(\mathbf{X}^\top\mathbf{X})^{-1}\) is

Intercept Weight Model year
Intercept 15.7425 −0.37992 −0.191874
Weight −0.37992 0.045734 0.003211
Model year −0.191874 0.003211 0.002399

Its square-rooted diagonal gives the standard errors reported in Lesson 2.1: \(3.968\), \(0.2139\) and \(0.04898\). The off-diagonal elements are used just as much. The estimated correlation between \(\hat\beta_{\text{weight}}\) and \(\hat\beta_{\text{year}}\) is \(+0.307\), exactly the negative of the correlation between weight and model year (\(-0.307\); Exercise B.2 proves this for \(p = 2\)). The intercept estimate is correlated \(-0.987\) with the year slope, because model year is recorded far from zero (70–82): the intercept is an extrapolation to the year 1900, tied to the slope.

5.2 Standard errors of linear combinations

Two quantities a reader of Lesson 2.1 might ask about:

  • Mean fuel economy of 3000-lb cars from 1976, \(\mathbf{a} = (1, 3, 76)^\top\): estimate \(\mathbf{a}^\top\hat{\boldsymbol\beta} = 23.310\), standard error \(\hat\sigma\sqrt{\mathbf{a}^\top(\mathbf{X}^\top\mathbf{X})^{-1}\mathbf{a}} = 0.172\). This is exactly the centred intercept and its standard error from Lesson 2.1: centring only changes which linear combination the software calls “intercept”. It is also \(\hat\sigma\sqrt{h_{00}}\) with \(h_{00} = 0.0025\) from Lesson 2.3.
  • Ten model years of progress at fixed weight, \(\mathbf{a} = (0, 0, 10)^\top\): estimate \(7.57\) mpg, standard error \(0.490\); with \(t_{395;\,0.975} = 1.966\), a 95% confidence interval is \((6.60, 8.53)\) mpg.

Neither needs a new fit: one covariance matrix answers every question about linear combinations.

R code 
cols <- c("mpg", "cylinders", "displacement", "horsepower", "weight",
          "acceleration", "model_year", "origin", "car_name")
auto <- read.table("data/auto-mpg.data", col.names = cols, na.strings = "?")
auto$w <- auto$weight / 1000
fit <- lm(mpg ~ w + model_year, data = auto)
X <- model.matrix(fit)
n <- nrow(X); df_res <- df.residual(fit)               # 395
SSE <- sum(residuals(fit)^2); s2 <- SSE / df_res
c(SSE = SSE, sigma2_hat = s2, sigma_hat = sqrt(s2))
V <- s2 * solve(crossprod(X))                          # same as vcov(fit)
V; max(abs(V - vcov(fit)))
sqrt(diag(V))                                          # standard errors
cov2cor(V)                                             # correlations of the estimates
cor(auto$w, auto$model_year)

lin_comb <- function(a, level = 0.95) {
  est <- sum(a * coef(fit)); se <- sqrt(drop(t(a) %*% V %*% a))
  q <- qt(1 - (1 - level) / 2, df_res)
  c(estimate = est, se = se, lower = est - q * se, upper = est + q * se)
}
rbind(mean_3000lb_1976 = lin_comb(c(1, 3, 76)),
      ten_years = lin_comb(c(0, 0, 10)))
Python code 
import numpy as np
import pandas as pd
from scipy import stats

cols = ["mpg", "cylinders", "displacement", "horsepower", "weight",
        "acceleration", "model_year", "origin", "car_name"]
auto = pd.read_csv("data/auto-mpg.data", sep=r"\s+", header=None,
                   names=cols, na_values="?", quotechar='"')
y = auto["mpg"].to_numpy()
X = np.column_stack([np.ones(len(y)), auto["weight"] / 1000, auto["model_year"]])
n, k = X.shape; df_res = n - k                          # 395
XtX_inv = np.linalg.inv(X.T @ X)
b = XtX_inv @ X.T @ y
e = y - X @ b
SSE = e @ e; s2 = SSE / df_res
print(f"SSE = {SSE:.2f}, sigma2_hat = {s2:.4f}, sigma_hat = {np.sqrt(s2):.4f}")
V = s2 * XtX_inv
print("estimated Cov(beta_hat):\n", V.round(6))
se = np.sqrt(np.diag(V)); print("standard errors:", se.round(5))
print("correlations of the estimates:\n", (V / np.outer(se, se)).round(4))
print("corr(weight, year):", round(np.corrcoef(X[:, 1], X[:, 2])[0, 1], 4))

def lin_comb(a, level=0.95):
    a = np.asarray(a, dtype=float)
    est = a @ b; s = np.sqrt(a @ V @ a); q = stats.t.ppf(1 - (1 - level) / 2, df_res)
    return np.round([est, s, est - q * s, est + q * s], 4)
print("mean at 3000 lb, 1976 (est, se, lower, upper):", lin_comb([1, 3, 76]))
print("ten model years at fixed weight:             ", lin_comb([0, 0, 10]))

5.3 Simulation: which properties need normality?

Keep the 398 observed (weight, year) pairs fixed, set \(\boldsymbol\beta = (-14.2, -6.66, 0.757)^\top\) and \(\sigma = 3.43\), and generate 10,000 data sets twice: with normal errors, and with skewed errors (a centred exponential distribution scaled to the same \(\sigma\), kurtosis \(\kappa = 9\)). Results (Python, seed 2026):

Quantity Normal errors Skewed errors Theory
Mean of \(\hat\beta_{\text{weight}}\) −6.662 −6.660 −6.66 (Thm 2.4.1)
SD of \(\hat\beta_{\text{weight}}\) 0.2135 0.2155 0.2136 (Thm 2.4.2)
Mean of \(\hat\sigma^2\) 11.766 11.761 11.765 (Thm 2.4.4)

Unbiasedness, the covariance formula and the unbiasedness of \(\hat\sigma^2\) hold under both error distributions, as the theory says they need no normality. With \(n = 398\) the \(t\)-interval for the slope also keeps its coverage under skewed errors. But the variance of SSE is four times the \(\chi^2_{395}\) value, as predicted by the kurtosis formula: a \(\chi^2\)-based interval for \(\sigma^2\) would be far too narrow. R uses a different random-number generator, so its simulated values differ slightly while agreeing with theory.

simulate <- function(E) {                               # E: R x n matrix of errors

  B <- Y %*% t(A)                                       # R x 3 estimates
  S <- rowSums((Y - B %*% t(X))^2)                      # SSE
  q <- qt(0.975, m); se_w <- sqrt(S / m * XtX_inv[2, 2])

       summary = c(mean_bw = mean(B[, 2]), sd_bw = sd(B[, 2]), mean_s2 = mean(S / m),

import pandas as pd
from scipy import stats
import matplotlib.pyplot as plt

cols = ["mpg", "cylinders", "displacement", "horsepower", "weight",
        "acceleration", "model_year", "origin", "car_name"]
auto = pd.read_csv("data/auto-mpg.data", sep=r"\s+", header=None,
                   names=cols, na_values="?", quotechar='"')
X = np.column_stack([np.ones(len(auto)), auto["weight"] / 1000, auto["model_year"]])
n, k = X.shape; m = n - k
XtX_inv = np.linalg.inv(X.T @ X); A = XtX_inv @ X.T
beta, sigma, R = np.array([-14.2, -6.66, 0.757]), 3.43, 10_000
rng = np.random.default_rng(2026)

def simulate(E):                                        # E: R x n matrix of errors
    Y = X @ beta + E
    B = Y @ A.T                                         # R x 3 estimates
    S = ((Y - B @ X.T)**2).sum(axis=1)                  # SSE
    q = stats.t.ppf(0.975, m); se_w = np.sqrt(S / m * XtX_inv[1, 1])
    summary = dict(mean_bw=B[:, 1].mean(), sd_bw=B[:, 1].std(ddof=1), mean_s2=(S / m).mean(),
                   mean_Q=(S / sigma**2).mean(), var_Q=(S / sigma**2).var(ddof=1),
                   cor_bw_SSE=np.corrcoef(B[:, 1], S)[0, 1],
                   coverage=np.mean(np.abs(B[:, 1] - beta[1]) <= q * se_w))
    return S, summary

S_norm, norm = simulate(sigma * rng.standard_normal((R, n)))
S_skew, skew = simulate(sigma * (rng.exponential(1.0, (R, n)) - 1.0))
h = np.einsum("ij,jk,ik->i", X, XtX_inv, X)
theory = dict(mean_bw=beta[1], sd_bw=sigma * np.sqrt(XtX_inv[1, 1]), mean_s2=sigma**2,
              mean_Q=m, var_Q=2 * m, cor_bw_SSE=0.0, coverage=0.95)
print(pd.DataFrame({"normal": norm, "skewed": skew, "theory": theory}).round(4))
print("Var(SSE/sigma^2) predicted for kappa = 9:", round(2 * m + 6 * np.sum((1 - h)**2), 1))

grid = np.linspace(200, 600, 400)
fig, axes = plt.subplots(1, 2, figsize=(8, 3.4), sharey=True)
for ax, S, title in zip(axes, (S_norm, S_skew), ("Normal errors", "Skewed errors")):
    ax.hist(S / sigma**2, bins=50, density=True, color="lightgray", edgecolor="white")
    ax.plot(grid, stats.chi2.pdf(grid, m), linewidth=2)
    ax.set_title(title); ax.set_xlabel("SSE / sigma^2"); ax.set_xlim(200, 600)
axes[0].set_ylabel("Density")
plt.tight_layout()
plt.show()

6 Common misconceptions

Misconceptions

  1. “OLS is unbiased only if the errors are normal.” — Unbiasedness needs A0 and A1 only (Theorem 2.4.1).
  2. “Gauss–Markov says OLS is the best estimator.” — Best among linear unbiased estimators, under A0–A3. Biased estimators (Module 5) can have smaller mean squared error.
  3. “The residuals have the same variance as the errors.” — \(\operatorname{Var}(e_i) = \sigma^2(1 - h_{ii})\): smaller, and unequal across observations.
  4. “With a large sample, every normal-theory procedure is robust.” — Intervals for coefficients become approximately valid; intervals and tests for \(\sigma^2\) do not, because the variance of SSE depends on the kurtosis.
  5. “The coefficient estimates are independent if the standard errors are reported separately.” — The estimates are correlated through \((\mathbf{X}^\top\mathbf{X})^{-1}\); standard errors of sums or differences need the covariances.

7 Key takeaways

  • \(\hat{\boldsymbol\beta} = \boldsymbol\beta + (\mathbf{X}^\top\mathbf{X})^{-1}\mathbf{X}^\top\boldsymbol\varepsilon\) and \(\mathbf{e} = (\mathbf{I} - \mathbf{H})\boldsymbol\varepsilon\) drive every result.
  • A0–A1: unbiased. A0–A3: \(\operatorname{Cov}(\hat{\boldsymbol\beta}) = \sigma^2(\mathbf{X}^\top\mathbf{X})^{-1}\), Gauss–Markov, and \(E(\mathrm{SSE}) = (n - p - 1)\sigma^2\).
  • A0–A4: \(\hat{\boldsymbol\beta}\) is normal, \(\mathrm{SSE}/\sigma^2 \sim \chi^2_{n-p-1}\), the two are independent, and \(t\)-statistics have \(n - p - 1\) degrees of freedom.
  • The estimated covariance matrix gives standard errors for any linear combination \(\mathbf{a}^\top\hat{\boldsymbol\beta}\).
  • Coefficient inference is approximately robust to non-normality in large samples; inference about \(\sigma^2\) is not.

8 Exercises

8.1 A. Conceptual

A.1 (★). Which of A0–A4 are needed for each statement? (a) \(E(\hat{\boldsymbol\beta}) = \boldsymbol\beta\); (b) \(\operatorname{Cov}(\hat{\boldsymbol\beta}) = \sigma^2(\mathbf{X}^\top\mathbf{X})^{-1}\); (c) \(\mathbf{a}^\top\hat{\boldsymbol\beta}\) is BLUE; (d) \(E(\hat\sigma^2) = \sigma^2\); (e) \(\hat{\boldsymbol\beta}\) and SSE are independent; (f) \(\hat{\boldsymbol\beta}\) can be computed.

Solution
  1. A0, A1. (b) A0–A3. (c) A0–A3. (d) A0–A3. (e) A0–A4 (uncorrelatedness, \(\operatorname{Cov}(\hat{\boldsymbol\beta}, \mathbf{e}) = \mathbf{0}\), needs only A0–A3; independence needs joint normality). (f) A0 only.

A.2 (★). A report gives \(\hat\beta_{\text{weight}} = -6.664\) (se 0.214) and \(\hat\beta_{\text{year}} = 0.757\) (se 0.049) and computes the standard error of \(\hat\beta_{\text{weight}} + \hat\beta_{\text{year}}\) as \(\sqrt{0.214^2 + 0.049^2}\). What is wrong, and what is the correct value?

Solution

The formula ignores the covariance. Correctly, \(\operatorname{Var} = 0.045734 + 0.002399 + 2(0.003211) = 0.054555\), so se \(= 0.2336\), against \(0.2194\) from the incorrect formula. (Whether this sum is a meaningful quantity is a separate question: it adds effects measured in different units.)

8.2 B. Mathematical

B.1 (★★). Show that \(\operatorname{Var}(e_i) = \sigma^2(1 - h_{ii})\) and \(\operatorname{Cov}(e_i, e_k) = -\sigma^2h_{ik}\) for \(i \ne k\). Explain why the residuals are correlated even when the errors are not.

Solution

Read the entries of \(\operatorname{Cov}(\mathbf{e}) = \sigma^2(\mathbf{I} - \mathbf{H})\) (Theorem 2.4.2b). The residuals are correlated because they satisfy \(p + 1\) linear constraints, \(\mathbf{X}^\top\mathbf{e} = \mathbf{0}\): they live in an \((n - p - 1)\)-dimensional subspace, so they cannot vary independently in all \(n\) directions.

B.2 (★★). Let \(p = 2\) with an intercept. Show that the correlation between \(\hat\beta_1\) and \(\hat\beta_2\) is \(-r_{12}\), where \(r_{12}\) is the sample correlation of \(x_1\) and \(x_2\). Hint: the slope block of \((\mathbf{X}^\top\mathbf{X})^{-1}\) is the inverse of the centred cross-product matrix \(\begin{pmatrix} S_{11} & S_{12}\\ S_{12} & S_{22}\end{pmatrix}\).

Solution

Inverting the \(2\times2\) matrix gives the slope block \(\frac{1}{S_{11}S_{22} - S_{12}^2}\begin{pmatrix} S_{22} & -S_{12}\\ -S_{12} & S_{11}\end{pmatrix}\). Multiplying by \(\sigma^2\) gives the covariance matrix of \((\hat\beta_1, \hat\beta_2)\); the correlation is \(-S_{12}/\sqrt{S_{11}S_{22}} = -r_{12}\). (The hint follows from inverting \(\mathbf{X}^\top\mathbf{X}\) in partitioned form, or from Exercise B.3 of Lesson 2.3 with mean-centred columns, which leaves the slopes and their covariance unchanged and makes the intercept uncorrelated with them.) In the worked example, \(r_{12} = -0.307\) and the estimated correlation of the slopes is \(+0.307\).

B.3 (★★). Under A0–A4, show that the ML estimator of \(\sigma^2\) is \(\tilde\sigma^2 = \mathrm{SSE}/n\) and that its bias is \(-(p+1)\sigma^2/n\). For the worked example, compute \(\tilde\sigma^2\) and compare it with \(\hat\sigma^2\).

Solution

At \(\boldsymbol\beta = \hat{\boldsymbol\beta}\), \(\partial\ell/\partial\sigma^2 = -n/(2\sigma^2) + \mathrm{SSE}/(2\sigma^4) = 0\) gives \(\tilde\sigma^2 = \mathrm{SSE}/n\), and the second derivative there is negative. \(E(\tilde\sigma^2) = (n - p - 1)\sigma^2/n\), so the bias is \(-(p+1)\sigma^2/n\). Here \(\tilde\sigma^2 = 4659.84/398 = 11.708\) against \(\hat\sigma^2 = 11.797\); with \(p + 1 = 3\) and \(n = 398\) the difference is under 1%.

B.4 (★★★). Ridge regression (Module 5) uses \(\tilde{\boldsymbol\beta}_k = (\mathbf{X}^\top\mathbf{X} + k\mathbf{I})^{-1}\mathbf{X}^\top\mathbf{y}\) with \(k > 0\). Show that it is linear in \(\mathbf{y}\) but biased, so Theorem 2.4.3 says nothing about it. Compute its bias.

Solution

It is \(\mathbf{C}\mathbf{y}\) with \(\mathbf{C} = (\mathbf{X}^\top\mathbf{X} + k\mathbf{I})^{-1}\mathbf{X}^\top\). Then \(\mathbf{C}\mathbf{X} = (\mathbf{X}^\top\mathbf{X} + k\mathbf{I})^{-1}\mathbf{X}^\top\mathbf{X} \ne \mathbf{I}\) for \(k > 0\), so \(E(\tilde{\boldsymbol\beta}_k) = \mathbf{C}\mathbf{X}\boldsymbol\beta \ne \boldsymbol\beta\) in general. Using \(\mathbf{C}\mathbf{X} = \mathbf{I} - k(\mathbf{X}^\top\mathbf{X} + k\mathbf{I})^{-1}\), the bias is \(-k(\mathbf{X}^\top\mathbf{X} + k\mathbf{I})^{-1}\boldsymbol\beta\). Gauss–Markov compares only unbiased linear estimators, so it does not rule out that ridge has smaller mean squared error; Module 5 shows when it does.

8.3 C. Computational

C.1 (★). For the 392 cars with horsepower recorded, fit mpg on weight (1000 lb) and horsepower (100 hp). Compute \(\hat\sigma^2\), the standard errors and the correlation between the two slope estimates. Relate the correlation to Exercise B.2.

Solution

\(\hat\sigma^2 = 17.979\); standard errors \(0.793\) (intercept), \(0.502\) (weight), \(1.109\) (horsepower). The slope estimates have correlation \(-0.865\), the negative of \(r(\text{weight}, \text{horsepower}) = 0.865\). Strongly correlated predictors produce strongly (negatively) correlated slope estimates: data with a heavier car usually also have a more powerful one, so the data cannot easily separate the two effects. This is the mechanism behind the large standard errors studied in Module 5.

C.2 (★★). Refit the weight + year model with both predictors centred at their means (2.970 thousand lb, 1976.01). Compare the correlation matrix of the estimates with that of the uncentred fit. Which correlations change, and why?

Solution

Uncentred: corr(intercept, weight slope) \(= -0.448\), corr(intercept, year slope) \(= -0.987\), corr(weight slope, year slope) \(= 0.307\). Mean-centred: the intercept becomes \(23.515\) (se \(0.172\)) and is uncorrelated with both slopes; the correlation of the slopes stays \(0.307\) and their standard errors are unchanged. Centring at the means makes the intercept column orthogonal to the other columns, so \(\mathbf{X}^\top\mathbf{X}\) becomes block diagonal; the slopes and their covariance are unaffected (Lesson 2.3, Exercise B.3).

C.3 (★★★). Repeat the simulation of Section 5.3 with uniform errors on \((-\sqrt3\,\sigma, \sqrt3\,\sigma)\), which have standard deviation \(\sigma = 3.43\) and kurtosis \(\kappa = 1.8\) (lighter tails than the normal). Before simulating, use the kurtosis formula of Section 4.5 to predict the variance of \(\mathrm{SSE}/\sigma^2\); then check the prediction with 50,000 data sets, and check the coverage of the 95% \(t\)-interval for \(\beta_{\text{weight}}\).

Solution (Python) 
import numpy as np, pandas as pd
from scipy import stats
cols = ["mpg", "cylinders", "displacement", "horsepower", "weight",
        "acceleration", "model_year", "origin", "car_name"]
auto = pd.read_csv("data/auto-mpg.data", sep=r"\s+", header=None,
                   names=cols, na_values="?", quotechar='"')
X = np.column_stack([np.ones(len(auto)), auto["weight"] / 1000, auto["model_year"]])
n, k = X.shape; m = n - k
XtX_inv = np.linalg.inv(X.T @ X); A = XtX_inv @ X.T
h = np.einsum("ij,jk,ik->i", X, XtX_inv, X)
beta, sigma, R = np.array([-14.2, -6.66, 0.757]), 3.43, 50_000
print("predicted Var(SSE/sigma^2):", round(2 * m + (1.8 - 3) * np.sum((1 - h)**2), 1))
rng = np.random.default_rng(2026)
E = rng.uniform(-np.sqrt(3) * sigma, np.sqrt(3) * sigma, (R, n))   # sd sigma, kappa = 1.8
Y = X @ beta + E; B = Y @ A.T; S = ((Y - B @ X.T)**2).sum(axis=1)
se_w = np.sqrt(S / m * XtX_inv[1, 1]); q = stats.t.ppf(0.975, m)
print("mean SSE/sigma^2:", round((S / sigma**2).mean(), 1), " var:", round((S / sigma**2).var(ddof=1), 1))
print("coverage:", np.mean(np.abs(B[:, 1] - beta[1]) <= q * se_w))
Qs = S / sigma**2; v = Qs.var(ddof=1)
print("Monte Carlo se of the variance:", round(np.sqrt(np.mean((Qs - Qs.mean())**4) - v**2) / np.sqrt(R), 1))

Prediction: \(2(395) + (1.8 - 3)(392.03) = 319.6\), well below the \(\chi^2_{395}\) value of 790. Simulation (seed 2026): mean of \(\mathrm{SSE}/\sigma^2\) = 395.0, variance 323.5 with Monte Carlo standard error 2.0, so within two standard errors of the prediction; coverage of the \(t\)-interval 0.951. With light-tailed errors a \(\chi^2\)-based interval for \(\sigma^2\) is too wide (conservative); with heavy-tailed errors it is too narrow. Either way it is wrong, while the interval for the slope is fine.
