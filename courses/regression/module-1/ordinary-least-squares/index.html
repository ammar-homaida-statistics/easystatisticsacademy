1 Learning objectives

By the end of this lesson you will be able to:

  1. state the least-squares criterion and explain why it is a choice of loss function, not a consequence of the model;
  2. derive the OLS estimators \(\hat\beta_0\) and \(\hat\beta_1\) from the normal equations and prove that they give the unique global minimum whenever \(S_{xx} > 0\);
  3. prove and interpret the algebraic properties of the fitted line;
  4. interpret least squares geometrically as an orthogonal projection;
  5. compute the estimates by hand from summary statistics and reproduce them in R and Python.

2 Motivation

Heavier cars use more fuel. For the 398 cars in the Auto MPG data, a scatterplot of fuel economy (mpg) against weight shows a clear downward trend. Lesson 1.1 described this with the model \[ y_i = \beta_0 + \beta_1 x_i + \varepsilon_i, \qquad i = 1,\dots,n, \] but \(\beta_0\) and \(\beta_1\) are unknown. Infinitely many lines can be drawn through the cloud of points. Which line should we choose, and why? This lesson answers the question with the method of least squares and establishes exactly what the resulting line does — and does not — guarantee.

3 Notation for this lesson

Symbol Meaning
\(x_i, y_i\) predictor and response for observation \(i\)
\(\bar x, \bar y\) sample means
\(S_{xx} = \sum (x_i-\bar x)^2\) corrected sum of squares of \(x\)
\(S_{xy} = \sum (x_i-\bar x)(y_i-\bar y)\) corrected sum of cross-products
\(b_0, b_1\) a candidate intercept and slope (any line)
\(\hat\beta_0, \hat\beta_1\) the least-squares estimates
\(\hat y_i = \hat\beta_0 + \hat\beta_1 x_i\) fitted value
\(e_i = y_i - \hat y_i\) residual (observable) — not the error \(\varepsilon_i\) (unobservable)
\(\mathrm{SSE} = \sum e_i^2\) error (residual) sum of squares

All notation follows the course notation standard.

Assumptions used in this lesson

The simple linear regression model is \(y_i = \beta_0 + \beta_1 x_i + \varepsilon_i\), \(i = 1, \dots, n\), with the \(x_i\) treated as fixed and

  • A1 (Correct mean function). \(E(\varepsilon_i) = 0\) for all \(i\), i.e. \(E(y_i) = \beta_0 + \beta_1 x_i\).
  • A2 (Constant variance). \(\operatorname{Var}(\varepsilon_i) = \sigma^2\) for all \(i\).
  • A3 (Uncorrelated errors). \(\operatorname{Cov}(\varepsilon_i, \varepsilon_j) = 0\) for \(i \ne j\).
  • A4 (Normality). \(\varepsilon_i \sim N(0, \sigma^2)\); together with A1–A3 this makes the errors independent.

Each result below states which of A1–A4 it uses. Why these assumptions, and what each one is needed for: Lesson 1.1, Assumptions.

4 Theory

4.1 The least-squares criterion

Definition 1.3.1 (Least-squares criterion)

For any candidate line \(b_0 + b_1 x\), define \[ S(b_0, b_1) = \sum_{i=1}^{n} \bigl(y_i - b_0 - b_1 x_i\bigr)^2 . \] The ordinary least squares (OLS) estimates \((\hat\beta_0, \hat\beta_1)\) are the values of \((b_0, b_1)\) that minimise \(S\).

Three remarks set the scope of this definition.

  • Vertical distances. \(S\) measures discrepancies in the \(y\)-direction only, because the purpose is to predict \(y\) from \(x\). Minimising perpendicular distances gives a different line (orthogonal regression), and regressing \(x\) on \(y\) gives yet another.
  • Squares are a choice. Absolute deviations (least absolute deviations) or other losses are also legitimate. Squared loss is chosen because it is differentiable, gives closed-form estimators, has a clean geometric interpretation (Section 4.6), and — under the assumptions of Lesson 1.4 — yields estimators with optimal properties.
  • No distributional assumption is needed. The OLS estimates are defined for any data set with at least two distinct \(x\) values. Assumptions about \(\varepsilon_i\) matter only when we ask about the statistical properties of the estimates (Lessons 1.4 and 1.7).

4.2 The normal equations

Setting the partial derivatives of \(S\) to zero: \[ \frac{\partial S}{\partial b_0} = -2\sum_{i=1}^n (y_i - b_0 - b_1 x_i) = 0, \qquad \frac{\partial S}{\partial b_1} = -2\sum_{i=1}^n x_i\,(y_i - b_0 - b_1 x_i) = 0 . \] Rearranging gives the normal equations \[ n\,b_0 + b_1 \sum x_i = \sum y_i, \qquad b_0 \sum x_i + b_1 \sum x_i^2 = \sum x_i y_i . \tag{1.3.1} \]

Theorem 1.3.1 (OLS estimators)

If \(S_{xx} > 0\) (that is, the \(x_i\) are not all equal), the normal equations have the unique solution \[ \hat\beta_1 = \frac{S_{xy}}{S_{xx}}, \qquad \hat\beta_0 = \bar y - \hat\beta_1 \bar x , \] and \((\hat\beta_0, \hat\beta_1)\) is the unique global minimiser of \(S(b_0, b_1)\).

Derivation — solving the normal equations

Divide the first equation in (1.3.1) by \(n\): \(b_0 = \bar y - b_1 \bar x\). Substitute into the second: \[ (\bar y - b_1 \bar x)\, n\bar x + b_1 \sum x_i^2 = \sum x_i y_i \;\Longrightarrow\; b_1\Bigl(\sum x_i^2 - n\bar x^2\Bigr) = \sum x_i y_i - n\bar x\bar y . \] Since \(\sum x_i^2 - n\bar x^2 = S_{xx}\) and \(\sum x_i y_i - n \bar x \bar y = S_{xy}\), we obtain \(b_1 = S_{xy}/S_{xx}\), which is well defined exactly when \(S_{xx} > 0\). Then \(b_0 = \bar y - b_1\bar x\).

Derivation — why this is the unique global minimum

A stationary point need not be a minimum, so we prove minimality directly. For any \((b_0, b_1)\) write \(y_i - b_0 - b_1x_i = e_i + d_i\), where \(d_i = (\hat\beta_0 - b_0) + (\hat\beta_1 - b_1)x_i\). Then \[ S(b_0,b_1) = \sum e_i^2 + 2\sum e_i d_i + \sum d_i^2 . \] The cross term vanishes because \(\sum e_i = 0\) and \(\sum x_i e_i = 0\) (these are the normal equations evaluated at \(\hat\beta\); see Theorem 1.3.2). Hence \[ S(b_0,b_1) = \mathrm{SSE} + \sum_{i=1}^n \bigl[(\hat\beta_0 - b_0) + (\hat\beta_1 - b_1)x_i\bigr]^2 \;\ge\; \mathrm{SSE}. \] Expanding the second term around \(\bar x\), \[ \sum d_i^2 = n\bigl[(\hat\beta_0 - b_0) + (\hat\beta_1 - b_1)\bar x\bigr]^2 + (\hat\beta_1 - b_1)^2 S_{xx}, \] which is zero only if \(b_1 = \hat\beta_1\) (because \(S_{xx} > 0\)) and then \(b_0 = \hat\beta_0\). So the minimum is attained at \((\hat\beta_0,\hat\beta_1)\) and nowhere else.

Alternative argument. The Hessian of \(S\) is \(2\begin{pmatrix} n & \sum x_i \\ \sum x_i & \sum x_i^2\end{pmatrix}\), with determinant \(4nS_{xx}\). It is positive definite when \(S_{xx} > 0\), so \(S\) is strictly convex and its stationary point is the unique global minimum.

Two equivalent forms of the slope are useful later: \[ \hat\beta_1 = \frac{\sum (x_i - \bar x)\,y_i}{S_{xx}} = \sum_{i=1}^n k_i\,y_i, \qquad k_i = \frac{x_i - \bar x}{S_{xx}} . \] The slope is therefore a linear function of the responses with fixed weights \(k_i\) satisfying \(\sum k_i = 0\) and \(\sum k_i x_i = 1\). Lesson 1.4 uses this representation to derive the mean and variance of \(\hat\beta_1\).

4.3 Assumptions used so far

Assumption check

Theorem 1.3.1 requires only \(S_{xx} > 0\). Linearity, constant variance, independence and normality of the errors are not used. They become necessary in Lesson 1.4 (unbiasedness, variance, Gauss–Markov) and Lesson 1.7 (exact \(t\) and \(F\) inference).

4.4 Algebraic properties of the fitted line

Theorem 1.3.2 (Properties of the OLS fit)

For a model with an intercept and \(S_{xx} > 0\):

  1. \(\sum_{i=1}^n e_i = 0\);
  2. \(\sum_{i=1}^n x_i e_i = 0\);
  3. \(\sum_{i=1}^n \hat y_i e_i = 0\);
  4. \(\sum_{i=1}^n \hat y_i = \sum_{i=1}^n y_i\), so the fitted values have mean \(\bar y\);
  5. the fitted line passes through \((\bar x, \bar y)\).
Derivation
  1. and (b) are the two normal equations evaluated at \((\hat\beta_0, \hat\beta_1)\).
  2. \(\sum \hat y_i e_i = \hat\beta_0 \sum e_i + \hat\beta_1 \sum x_i e_i = 0\) by (a) and (b).
  3. follows from (a): \(\sum y_i - \sum \hat y_i = \sum e_i = 0\).
  4. \(\hat\beta_0 + \hat\beta_1 \bar x = (\bar y - \hat\beta_1 \bar x) + \hat\beta_1 \bar x = \bar y\).

These are identities, not evidence of a good fit

Properties (a)–(e) hold for every data set, whatever its shape — including data for which a straight line is a poor description. In particular, \(\sum e_i = 0\) says nothing about how well the line fits. Property (a) also depends on the intercept: in regression through the origin it generally fails (Exercise B.2).

4.5 Interpretation

  • \(\hat\beta_1\) is the slope of the line that best fits the data in the squared-vertical-distance sense. It summarises the average change in \(y\) associated with a one-unit increase in \(x\) in these data; whether it estimates a causal effect is a question of study design, not of least squares.
  • \(\hat\beta_0\) is the fitted value at \(x = 0\). It is required to place the line, but it is only interpretable if \(x = 0\) is meaningful and lies within (or near) the observed range of \(x\) (Lesson 1.5).
  • Property (e) shows that the line is “anchored” at the centre of the data; only its slope is determined by how \(x\) and \(y\) co-vary.

4.6 Geometric view

Collect the data in vectors \(\mathbf y = (y_1,\dots,y_n)^\top\), \(\mathbf 1 = (1,\dots,1)^\top\) and \(\mathbf x = (x_1,\dots,x_n)^\top\). Every candidate line produces a vector \(b_0\mathbf 1 + b_1\mathbf x\) in the two-dimensional subspace spanned by \(\mathbf 1\) and \(\mathbf x\), and \(S(b_0,b_1) = \lVert \mathbf y - b_0\mathbf 1 - b_1\mathbf x \rVert^2\) is the squared Euclidean distance from \(\mathbf y\) to that vector.

Least squares therefore chooses the point \(\hat{\mathbf y}\) in the subspace closest to \(\mathbf y\). The closest point is the orthogonal projection of \(\mathbf y\) onto the subspace, which means the residual vector \(\mathbf e = \mathbf y - \hat{\mathbf y}\) is orthogonal to both spanning vectors: \[ \mathbf 1^\top \mathbf e = 0, \qquad \mathbf x^\top \mathbf e = 0 . \] These two orthogonality conditions are the normal equations (Theorem 1.3.2 (a)–(b)), and property (c) says \(\mathbf e \perp \hat{\mathbf y}\). Module 2 develops this view in matrix form, where it leads to the hat matrix \(\mathbf H\).

5 Worked example: fuel economy and weight

5.1 Data

We use the Auto MPG data (Quinlan, 1993; UCI Machine Learning Repository; CC BY 4.0): \(n = 398\) cars from model years 1970–1982. The response is fuel economy \(y\) (miles per gallon) and the predictor is weight \(x\), measured in thousands of pounds so that the slope is on a readable scale. Weight and mpg have no missing values (horsepower has six, but it is not used here).

5.2 By hand, from summary statistics

The data give

\[ \bar x = 2.970425, \quad \bar y = 23.514573, \quad S_{xx} = 284.704973, \quad S_{xy} = -2185.569063 . \]

Then \[ \hat\beta_1 = \frac{S_{xy}}{S_{xx}} = \frac{-2185.569063}{284.704973} = -7.676610, \qquad \hat\beta_0 = \bar y - \hat\beta_1 \bar x = 23.514573 + 7.676610 \times 2.970425 = 46.317364 . \]

The fitted line is \[ \widehat{\text{mpg}} = 46.317 - 7.677 \times \text{weight (1000 lb)} . \]

Rounding

Round only the final answer. Rounding the summary statistics to four significant figures first (\(\bar x = 2.970\), \(\bar y = 23.51\), \(S_{xx} = 284.7\), \(S_{xy} = -2186\)) gives \(\hat\beta_1 = -7.678\) and \(\hat\beta_0 = 46.314\) instead of \(-7.677\) and \(46.317\): the rounding errors in \(\hat\beta_1\) and \(\bar y\) carry into \(\hat\beta_0\).

5.3 In R and Python

R code 
cols <- c("mpg", "cylinders", "displacement", "horsepower", "weight",
          "acceleration", "model_year", "origin", "car_name")
auto <- read.table("data/auto-mpg.data", col.names = cols, na.strings = "?")
auto$weight_k <- auto$weight / 1000            # weight in 1000 lb

# From the formulas
x <- auto$weight_k; y <- auto$mpg
Sxx <- sum((x - mean(x))^2)
Sxy <- sum((x - mean(x)) * (y - mean(y)))
b1  <- Sxy / Sxx
b0  <- mean(y) - b1 * mean(x)
c(n = length(y), b0 = b0, b1 = b1)

# The same fit with lm()
fit <- lm(mpg ~ weight_k, data = auto)
coef(fit)

# Theorem 1.3.2: the identities hold up to floating-point error
e <- resid(fit)
c(sum_e = sum(e), sum_xe = sum(x * e), sum_yhat_e = sum(fitted(fit) * e))
Python code 
import numpy as np
import pandas as pd

cols = ["mpg", "cylinders", "displacement", "horsepower", "weight",
        "acceleration", "model_year", "origin", "car_name"]
auto = pd.read_csv("data/auto-mpg.data", sep=r"\s+", header=None,
                   names=cols, na_values="?", quotechar='"')
x = auto["weight"].to_numpy() / 1000          # weight in 1000 lb
y = auto["mpg"].to_numpy()

# From the formulas
Sxx = np.sum((x - x.mean())**2)
Sxy = np.sum((x - x.mean()) * (y - y.mean()))
b1 = Sxy / Sxx
b0 = y.mean() - b1 * x.mean()
print(f"n = {len(y)}, b0 = {b0:.6f}, b1 = {b1:.6f}")

# The same fit by solving the least-squares problem directly
X = np.column_stack([np.ones_like(x), x])
coef, *_ = np.linalg.lstsq(X, y, rcond=None)
print("lstsq:", coef)

# Theorem 1.3.2: the identities hold up to floating-point error
yhat = X @ coef
e = y - yhat
print(f"sum e = {e.sum():.2e}, sum x*e = {(x*e).sum():.2e}, sum yhat*e = {(yhat*e).sum():.2e}")

Output 

n = 398, b0 = 46.317364, b1 = -7.676610
lstsq: [46.31736442 -7.67661006]
sum e = 1.27e-11, sum x*e = 3.74e-11, sum yhat*e = 2.93e-10

Both programs return \(n = 398\), \(\hat\beta_0 = 46.317364\) and \(\hat\beta_1 = -7.676610\), matching the hand calculation. The sums in Theorem 1.3.2 are of order \(10^{-10}\) or smaller (the exact values depend on the software): zero up to floating-point error.

5.5 Interpretation in context

  • Slope. Among these cars, each additional 1000 lb of weight is associated with fuel economy about 7.7 mpg lower, on average.
  • Intercept. \(\hat\beta_0 = 46.3\) mpg is the fitted value for a car weighing 0 lb. No such car exists, and the observed weights run from 1.613 to 5.140 thousand lb, so the intercept has no practical interpretation here; it only positions the line.
  • Point of means. The line passes through \((\bar x, \bar y) = (2.970, 23.515)\), as Theorem 1.3.2(e) requires.

What this result does not say

  • It does not say that adding weight causes lower mpg: these are observational data, and heavier cars also tend to have larger engines.
  • It does not say that a straight line is the right description. The figure suggests curvature and a spread that decreases with weight; Lesson 1.9 and Module 3 examine this.
  • It says nothing yet about uncertainty: standard errors and intervals require the assumptions introduced in Lessons 1.4 and 1.7.

6 Common misconceptions

Misconceptions

  1. “OLS assumes normally distributed errors.” — No. The estimates are defined and computed without any distributional assumption. Normality is used only for exact small-sample inference (Lesson 1.7).
  2. “Residuals summing to zero shows the line fits well.” — No. \(\sum e_i = 0\) holds by construction in any model with an intercept, however poor the fit.
  3. “Regressing \(x\) on \(y\) gives the same line.” — No. It minimises horizontal distances and gives slope \(S_{xy}/S_{yy}\) in the \(x\)-on-\(y\) scale, which is not the reciprocal of \(\hat\beta_1\) unless \(|r| = 1\) (Lesson 1.2).
  4. “Residuals are the errors.” — No. \(e_i\) is observable and depends on the estimates; \(\varepsilon_i\) is unobservable. The residuals satisfy two linear constraints (Theorem 1.3.2 (a)–(b)); the errors do not.

7 Key takeaways

  • OLS chooses the line minimising the sum of squared vertical deviations; this is a choice of loss, not a property of the model.
  • \(\hat\beta_1 = S_{xy}/S_{xx}\) and \(\hat\beta_0 = \bar y - \hat\beta_1\bar x\) give the unique minimum whenever \(S_{xx} > 0\).
  • The fitted line passes through \((\bar x,\bar y)\), and the residuals are orthogonal to \(\mathbf 1\), \(\mathbf x\) and \(\hat{\mathbf y}\) — by construction, for every data set.
  • Geometrically, \(\hat{\mathbf y}\) is the orthogonal projection of \(\mathbf y\) onto the span of \(\mathbf 1\) and \(\mathbf x\).
  • No distributional assumption has been used; that comes next.

8 Exercises

8.1 A. Conceptual

A.1 (★). A classmate says: “Our residuals sum to exactly zero, so the model has no bias.” Explain what is wrong with this statement.

Hint

Ask whether the sum could ever be non-zero for an OLS fit with an intercept.

Solution

\(\sum e_i = 0\) is the first normal equation evaluated at the OLS estimates (Theorem 1.3.2(a)). It holds for every OLS fit with an intercept, whatever the data, so it carries no information about bias or fit. For instance, fitting a straight line to points on a parabola still gives residuals summing to zero, although the residuals are systematically positive at the ends and negative in the middle. Bias concerns \(E(\hat\beta)\) under a model and is studied in Lesson 1.4.

A.2 (★). Why does OLS minimise vertical rather than perpendicular distances? Give a situation in which minimising perpendicular distances would be more appropriate.

Solution

The aim of regression is to predict or explain \(y\) given \(x\); the \(x\) values are treated as fixed (or conditioned on) and the errors are in \(y\). Vertical distances are the prediction errors for \(y\). Perpendicular (orthogonal) distances treat \(x\) and \(y\) symmetrically and are more appropriate when both variables are measured with error and neither is to be predicted from the other — for example, comparing two measurement instruments, where errors-in-variables methods such as orthogonal (Deming) regression are used.

8.2 B. Mathematical

B.1 (★★). Show that if every \(x_i\) is replaced by \(x_i^* = x_i - c\) for a constant \(c\), the OLS slope is unchanged and the intercept becomes \(\hat\beta_0^* = \hat\beta_0 + \hat\beta_1 c\). What is the intercept when \(c = \bar x\)?

Solution

\(x_i^* - \bar x^* = x_i - \bar x\), so \(S_{x^*x^*} = S_{xx}\) and \(S_{x^*y} = S_{xy}\); hence \(\hat\beta_1^* = \hat\beta_1\). Then \(\hat\beta_0^* = \bar y - \hat\beta_1(\bar x - c) = \hat\beta_0 + \hat\beta_1 c\). With \(c = \bar x\), \(\hat\beta_0^* = \bar y\): after centring, the intercept is the mean response. For the Auto MPG fit, centring weight gives intercept \(23.514573\).

B.2 (★★). Regression through the origin. For the model \(y_i = \beta x_i + \varepsilon_i\), derive the OLS estimator \(\hat\beta\). Show that \(\sum x_i e_i = 0\) but that \(\sum e_i\) need not be zero.

Hint

There is only one normal equation. For the counterexample, use the data in Exercise C.1.

Solution

\(S(b) = \sum (y_i - b x_i)^2\), \(S'(b) = -2\sum x_i(y_i - b x_i) = 0\) gives \(\hat\beta = \sum x_i y_i / \sum x_i^2\) (provided not all \(x_i = 0\)); \(S''(b) = 2\sum x_i^2 > 0\), so this is the minimum. The single normal equation is \(\sum x_i e_i = 0\); there is no equation forcing \(\sum e_i = 0\). With the C1 data, \(\sum x_i y_i = 93\) and \(\sum x_i^2 = 55\), so \(\hat\beta = 93/55 = 1.690909\) and \(\sum e_i = 27 - 1.690909 \times 15 = 1.636364 \neq 0\).

B.3 (★★★). Prove that for any \((b_0, b_1)\), \[ S(b_0, b_1) = \mathrm{SSE} + n\bigl[(\hat\beta_0 - b_0) + (\hat\beta_1 - b_1)\bar x\bigr]^2 + (\hat\beta_1 - b_1)^2 S_{xx}, \] and use it to explain why the OLS line is unique if and only if \(S_{xx} > 0\).

Solution

See the derivation following Theorem 1.3.1: write \(y_i - b_0 - b_1 x_i = e_i + d_i\) with \(d_i = a + c\,x_i\), \(a = \hat\beta_0 - b_0\), \(c = \hat\beta_1 - b_1\). The cross term \(2\sum e_i d_i = 2a\sum e_i + 2c\sum x_i e_i = 0\). Finally \(\sum (a + c x_i)^2 = \sum [ (a + c\bar x) + c(x_i - \bar x)]^2 = n(a + c\bar x)^2 + c^2 S_{xx}\), since \(\sum (x_i - \bar x) = 0\).

If \(S_{xx} > 0\), the extra terms vanish only when \(c = 0\) and \(a = 0\), so the minimiser is unique. If \(S_{xx} = 0\) (all \(x_i\) equal to \(\bar x\)), the last term is always zero and every \((b_0, b_1)\) with \(b_0 + b_1\bar x = \hat\beta_0 + \hat\beta_1\bar x = \bar y\) attains the minimum: infinitely many lines through \((\bar x, \bar y)\) fit equally well, so the slope is not identifiable.

8.3 C. Computational

C.1 (★). For the illustrative data below, compute \(\hat\beta_0\) and \(\hat\beta_1\) by hand, list the fitted values and residuals, and verify Theorem 1.3.2 (a) and (b).

\(x\) 1 2 3 4 5
\(y\) 3 5 4 7 8
Solution

\(\bar x = 3\), \(\bar y = 5.4\), \(S_{xx} = 10\), \(S_{xy} = 12\), so \(\hat\beta_1 = 1.2\) and \(\hat\beta_0 = 5.4 - 1.2 \times 3 = 1.8\). Fitted values: \(3.0, 4.2, 5.4, 6.6, 7.8\). Residuals: \(0, 0.8, -1.4, 0.4, 0.2\). \(\sum e_i = 0\) and \(\sum x_i e_i = 0 + 1.6 - 4.2 + 1.6 + 1.0 = 0\). \(\mathrm{SSE} = 2.8\).

C.2 (★★). Using the Auto MPG data, fit the OLS line of mpg on horsepower (use the 392 cars with horsepower recorded). Report \(\hat\beta_0\) and \(\hat\beta_1\), interpret the slope, and verify Theorem 1.3.2 numerically.

Solution

With \(n = 392\): \(\hat\beta_0 = 39.9359\) and \(\hat\beta_1 = -0.157845\) mpg per horsepower; each additional 10 horsepower is associated with about 1.6 mpg lower fuel economy, on average. In R: lm(mpg ~ horsepower, data = auto) (rows with missing horsepower are dropped automatically). In Python, drop missing rows first, e.g. auto.dropna(subset=["horsepower"]). The sums \(\sum e_i\) and \(\sum x_i e_i\) are zero up to floating-point error. Note that the sample differs from the weight analysis (\(n = 392\) vs \(398\)); state this when comparing the two fits.

C.3 (★★). Write a function ols_slr(x, y) in R or Python that returns \(\hat\beta_0\), \(\hat\beta_1\), the fitted values and the residuals, and that stops with an informative error if \(S_{xx} = 0\). Test it on C1 and on a vector \(x\) whose entries are all equal.

Solution (Python) 
import numpy as np

def ols_slr(x, y):
    x = np.asarray(x, dtype=float); y = np.asarray(y, dtype=float)
    if x.shape != y.shape or x.ndim != 1:
        raise ValueError("x and y must be 1-D arrays of equal length")
    sxx = np.sum((x - x.mean())**2)
    if sxx == 0:
        raise ValueError("S_xx = 0: all x values are equal, slope not identifiable")
    b1 = np.sum((x - x.mean()) * (y - y.mean())) / sxx
    b0 = y.mean() - b1 * x.mean()
    fitted = b0 + b1 * x
    return {"b0": b0, "b1": b1, "fitted": fitted, "resid": y - fitted}

print(ols_slr([1, 2, 3, 4, 5], [3, 5, 4, 7, 8]))   # b0 = 1.8, b1 = 1.2

Calling ols_slr([2, 2, 2], [1, 2, 3]) raises the error. (In floating point, prefer a tolerance such as sxx < 1e-12 * len(x) to an exact comparison.)
