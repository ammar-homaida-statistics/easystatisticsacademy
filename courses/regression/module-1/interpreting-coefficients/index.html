Lesson 1.5 — Interpreting the Coefficients

“Each additional 1000 lb is associated with 7.7 fewer mpg.” Every part of that sentence carries meaning. This lesson makes the interpretation precise and shows what changes — and what does not — when units change.

1 Learning objectives

By the end of this lesson you will be able to:

  1. interpret the slope as a change in the mean response, in the correct units and with the correct scope;
  2. decide when the intercept has a meaningful interpretation, and use centring to make it meaningful;
  3. derive exactly how linear changes of units in \(x\) and \(y\) affect the estimates, standard errors, \(t\)-statistics and \(R^2\);
  4. recognise when a change of units is not linear, so that the model must be refitted;
  5. interpret a slope when the response is on the log scale.

2 Motivation

“Each additional 1000 lb is associated with 7.7 fewer mpg.” This sentence is short, but every part of it carries meaning: each additional (a difference in \(x\)), 1000 lb (the unit), associated with (not causes), fewer mpg (on average, not for every car). Students and researchers routinely get one of these parts wrong, and reviewers notice. This lesson makes the interpretation precise, shows what happens to every number in the output when units change, and marks the limits beyond which a fitted line says nothing.

3 Notation for this lesson

Symbol Meaning
\(\hat\beta_0, \hat\beta_1\) estimates for \(y\) on \(x\) in the original units
\(x^* = a + b\,x\), \(y^* = c + d\,y\) linearly transformed variables (\(b, d \ne 0\))
\(\hat\beta_0^*, \hat\beta_1^*\) estimates for \(y^*\) on \(x^*\)
\(t_1 = \hat\beta_1/\operatorname{se}(\hat\beta_1)\) \(t\)-statistic for the slope (used formally in Lesson 1.7)

All notation follows the course notation standard.

Assumptions used in this lesson

The simple linear regression model is \(y_i = \beta_0 + \beta_1 x_i + \varepsilon_i\), \(i = 1, \dots, n\), with the \(x_i\) treated as fixed and

  • A1 (Correct mean function). \(E(\varepsilon_i) = 0\) for all \(i\), i.e. \(E(y_i) = \beta_0 + \beta_1 x_i\).
  • A2 (Constant variance). \(\operatorname{Var}(\varepsilon_i) = \sigma^2\) for all \(i\).
  • A3 (Uncorrelated errors). \(\operatorname{Cov}(\varepsilon_i, \varepsilon_j) = 0\) for \(i \ne j\).
  • A4 (Normality). \(\varepsilon_i \sim N(0, \sigma^2)\); together with A1–A3 this makes the errors independent.

Each result below states which of A1–A4 it uses. Why these assumptions, and what each one is needed for: Lesson 1.1, Assumptions.

4 Theory

4.1 Interpreting the slope

Under the model \(E(y \mid x) = \beta_0 + \beta_1 x\), \[ \beta_1 = E(y \mid x + 1) - E(y \mid x)\quad\text{for every } x . \]

Template for a correct slope statement

“Among [population/sample], a difference of [one unit, with unit name] in [x] is associated with a difference of [\(\hat\beta_1\), with unit name] in the average [y], [within the observed range of x].”

Each element guards against a specific error:

  • “Average” — \(\beta_1\) describes the conditional mean, not every unit. Individual cars scatter around the line (Lesson 1.1).
  • “Associated with” — with observational data, \(\beta_1\) is not a causal effect; units differing in \(x\) may differ in other ways (Lesson 1.1).
  • “A difference of” — the comparison is between units with different \(x\), not a change within one unit over time.
  • Units — the number \(\hat\beta_1\) is meaningless without the units of \(y\) per unit of \(x\).
  • Range — the data say nothing about \(E(y \mid x)\) outside the observed \(x\) values.

Changing the increment is a matter of multiplication: the association for a difference of \(\Delta\) units of \(x\) is \(\Delta\cdot\beta_1\).

4.2 Interpreting the intercept

\(\beta_0 = E(y \mid x = 0)\). It has a substantive interpretation only if

  1. \(x = 0\) is a meaningful value of the predictor, and
  2. \(x = 0\) lies within, or very close to, the range of the observed \(x\) values.

Otherwise \(\hat\beta_0\) is an extrapolation and is needed only to position the line. A common remedy is centring: replace \(x\) by \(x - c\) for a meaningful value \(c\) inside the data range. The slope is unchanged (Lesson 1.3, Exercise B.1), and the new intercept is the estimated mean response at \(x = c\).

4.3 Changes of units: linear transformations

Theorem 1.5.1 (Linear transformations)

Let \(x_i^* = a + b\,x_i\) and \(y_i^* = c + d\,y_i\) with \(b \ne 0\), \(d \ne 0\). Then for the least-squares fit of \(y^*\) on \(x^*\):

  1. \(\hat\beta_1^* = \dfrac{d}{b}\,\hat\beta_1\), and \(\hat\beta_0^* = c + d\,\hat\beta_0 - \dfrac{a\,d}{b}\,\hat\beta_1\);
  2. \(\hat y_i^* = c + d\,\hat y_i\) and \(e_i^* = d\,e_i\), so \(\mathrm{SSE}^* = d^2\,\mathrm{SSE}\) and \(\hat\sigma^* = |d|\,\hat\sigma\);
  3. \(\operatorname{se}(\hat\beta_1^*) = \left|\dfrac{d}{b}\right|\operatorname{se}(\hat\beta_1)\), so \(t_1^* = \operatorname{sign}(bd)\, t_1\);
  4. \(R^{2*} = R^2\) and \(r^* = \operatorname{sign}(bd)\,r\).
Derivation

  1. \(x_i^* - \bar x^* = b(x_i - \bar x)\) and \(y_i^* - \bar y^* = d(y_i - \bar y)\), so \(S_{x^*y^*} = bd\,S_{xy}\) and \(S_{x^*x^*} = b^2 S_{xx}\); hence \(\hat\beta_1^* = (d/b)\hat\beta_1\). Then \(\hat\beta_0^* = \bar y^* - \hat\beta_1^*\bar x^* = c + d\bar y - (d/b)\hat\beta_1(a + b\bar x) = c + d(\bar y - \hat\beta_1\bar x) - (ad/b)\hat\beta_1\).

  2. \(\hat y_i^* = \hat\beta_0^* + \hat\beta_1^* x_i^* = c + d\hat\beta_0 - (ad/b)\hat\beta_1 + (d/b)\hat\beta_1(a + bx_i) = c + d(\hat\beta_0 + \hat\beta_1 x_i) = c + d\,\hat y_i\), so \(e_i^* = y_i^* - \hat y_i^* = d\,e_i\). The degrees of freedom \(n - 2\) are unchanged.

  3. \(\operatorname{se}(\hat\beta_1^*) = \hat\sigma^*/\sqrt{S_{x^*x^*}} = |d|\hat\sigma/(|b|\sqrt{S_{xx}})\). Dividing, \(t_1^* = (d/b)\hat\beta_1 \big/ (|d/b|\operatorname{se}(\hat\beta_1)) = \operatorname{sign}(bd)\,t_1\).

  4. \(R^{2*} = 1 - \mathrm{SSE}^*/S_{y^*y^*} = 1 - d^2\mathrm{SSE}/(d^2 S_{yy}) = R^2\); the result for \(r\) is Theorem 1.2.2, Lesson 1.2.

The practical message: changing units changes the coefficients and their standard errors, but not the evidence. The \(t\)-statistic, the \(p\)-value and \(R^2\) are unaffected, so a choice of units can make a coefficient look large or small without changing anything substantive.

The intercept’s standard error is not simply rescaled when \(a \neq 0\) (Exercise B.2): shifting \(x\) changes which mean response the intercept estimates.

4.4 Non-linear changes of scale

Theorem 1.5.1 applies only to linear transformations. Converting fuel economy (mpg) to fuel consumption in litres per 100 km uses \[ \text{L/100 km} = \frac{235.215}{\text{mpg}}, \] which is not linear. A straight line in mpg is then a curve in L/100 km, and vice versa. The slope for L/100 km cannot be obtained by rescaling the slope for mpg; the model must be refitted, and the two models make different assumptions about which scale is linear.

4.5 A first look at a log-scale response

When the response is modelled on the log scale, \(E(\log y \mid x) = \beta_0 + \beta_1 x\), the slope has a multiplicative interpretation. A difference of one unit in \(x\) is associated with multiplying the geometric mean (and, if the errors are symmetric on the log scale, the median) of \(y\) by \(e^{\beta_1}\), that is, a change of \[ 100\,(e^{\beta_1} - 1)\ \% . \] For small \(|\beta_1|\), \(100\,(e^{\beta_1}-1) \approx 100\,\beta_1\). Module 3 discusses when and why to transform the response; here we only interpret.

5 Worked example

5.1 The same fit in different units

The Auto MPG fit of mpg on weight (\(n = 398\)) in five versions of the weight variable:

Weight variable \(\hat\beta_0\) \(\hat\beta_1\) \(\operatorname{se}(\hat\beta_1)\) \(t_1\) \(R^2\)
pounds 46.3174 −0.007677 per lb 0.000257 −29.81 0.6918
hundreds of pounds 46.3174 −0.7677 per 100 lb 0.02575 −29.81 0.6918
thousands of pounds 46.3174 −7.6766 per 1000 lb 0.2575 −29.81 0.6918
thousands of kilograms 46.3174 −16.9240 per 1000 kg 0.5677 −29.81 0.6918
thousands of pounds, centred at 3000 lb 23.2875 −7.6766 per 1000 lb 0.2575 −29.81 0.6918

As Theorem 1.5.1 predicts, the slope and its standard error change by the same factor, while \(t_1\) and \(R^2\) do not change. Centring changes only the intercept: \(\hat\beta_0 = 23.29\) mpg is the estimated mean fuel economy of 3000-lb cars, a value well inside the data, with standard error \(0.218\) instead of \(0.795\).

Converting the response linearly from mpg to km/L (\(d = 0.425144\)) multiplies \(\hat\beta_0\), \(\hat\beta_1\), their standard errors and \(\hat\sigma\) by 0.425144 and again leaves \(t_1\) and \(R^2\) unchanged (Exercise C.1).

R code 
cols <- c("mpg", "cylinders", "displacement", "horsepower", "weight",
          "acceleration", "model_year", "origin", "car_name")
auto <- read.table("data/auto-mpg.data", col.names = cols, na.strings = "?")

summarise_fit <- function(x, y) {
  s <- summary(lm(y ~ x))
  c(b0 = coef(s)[1, 1], b1 = coef(s)[2, 1], se_b0 = coef(s)[1, 2],
    se_b1 = coef(s)[2, 2], t_b1 = coef(s)[2, 3], R2 = s$r.squared)
}
versions <- list(
  pounds           = auto$weight,
  hundreds_lb      = auto$weight / 100,
  thousands_lb     = auto$weight / 1000,
  thousands_kg     = auto$weight * 0.45359237 / 1000,
  centred_3000lb   = (auto$weight - 3000) / 1000)
round(t(sapply(versions, summarise_fit, y = auto$mpg)), 6)
Python code 
import numpy as np
import pandas as pd

cols = ["mpg", "cylinders", "displacement", "horsepower", "weight",
        "acceleration", "model_year", "origin", "car_name"]
auto = pd.read_csv("data/auto-mpg.data", sep=r"\s+", header=None,
                   names=cols, na_values="?", quotechar='"')

def summarise_fit(x, y):
    n = len(y)
    Sxx = np.sum((x - x.mean())**2)
    b1 = np.sum((x - x.mean()) * (y - y.mean())) / Sxx
    b0 = y.mean() - b1 * x.mean()
    e = y - b0 - b1 * x
    s = np.sqrt(e @ e / (n - 2))
    se1 = s / np.sqrt(Sxx)
    se0 = s * np.sqrt(1 / n + x.mean()**2 / Sxx)
    R2 = 1 - (e @ e) / np.sum((y - y.mean())**2)
    return dict(b0=b0, b1=b1, se_b0=se0, se_b1=se1, t_b1=b1 / se1, R2=R2)

w, y = auto["weight"].to_numpy(), auto["mpg"].to_numpy()
versions = {
    "pounds": w,
    "hundreds_lb": w / 100,
    "thousands_lb": w / 1000,
    "thousands_kg": w * 0.45359237 / 1000,
    "centred_3000lb": (w - 3000) / 1000,
}
table = pd.DataFrame({k: summarise_fit(v, y) for k, v in versions.items()}).T
print(table.round(6))

5.2 Extrapolation

The observed weights run from 1613 to 5140 lb. The fitted line gives

  • 38.6 mpg for a 1000-lb car — below the lightest car in the data;
  • 0.26 mpg for a 6000-lb car — above the heaviest car, and physically implausible.

Neither prediction is supported by the data. The second also shows the consequence of the curvature seen in Lesson 1.1: the straight line keeps falling where the conditional mean flattens.

5.3 Fuel consumption instead of fuel economy

Refitting with the response in litres per 100 km (a non-linear transformation of mpg) gives \[ \widehat{\text{L/100 km}} = -0.903 + 4.079 \times \text{weight (1000 lb)}, \qquad R^2 = 0.784 . \] Each additional 1000 lb is associated with about 4.1 more litres per 100 km on average. This \(R^2\) differs from 0.692 because the two models assume linearity on different scales; it cannot be obtained from the mpg fit by any rescaling.

5.4 Log scale

Fitting \(\log(\text{mpg})\) on weight (1000 lb) gives \(\hat\beta_1 = -0.3512\). Hence each additional 1000 lb is associated with a change of \[ 100\,(e^{-0.3512} - 1) = -29.6\% \] in the geometric mean of mpg, or about \(100\,(e^{-0.03512} - 1) = -3.5\%\) per additional 100 lb. Here the approximation \(100\,\hat\beta_1 = -35.1\%\) per 1000 lb would be poor, because \(|\hat\beta_1|\) is not small.

5.5 Interpretation in context

A complete, defensible statement for the original fit:

Among the 398 cars in the Auto MPG data (model years 1970–1982), a difference of 1000 lb in weight is associated with a difference of about 7.7 mpg in average fuel economy (95% confidence interval in Lesson 1.7), over the observed weight range of roughly 1600 to 5100 lb. Because the data are observational and the relationship flattens for heavy cars, this is a description of an average association, not the effect of changing a car’s weight.

6 Common misconceptions

Misconceptions

  1. “The slope for weight in pounds (\(-0.0077\)) shows weight hardly matters.” — The size of a coefficient depends on the units. The \(t\)-statistic and \(R^2\) are the same in every unit.
  2. “The intercept is the mpg of a weightless car.” — Only formally. \(x = 0\) is far outside the data, so the intercept has no practical meaning here.
  3. “Each car loses 7.7 mpg for every extra 1000 lb.” — The slope describes average differences between cars, not what happens to one car.
  4. “To get the slope for L/100 km, just convert the mpg slope.” — Not possible: the conversion is non-linear, so the model must be refitted.
  5. “On the log scale, the slope times 100 is the percentage change.” — Only approximately, and only for small slopes; the exact change is \(100(e^{\beta_1} - 1)\%\).

7 Key takeaways

  • The slope is the difference in the mean response per unit difference in \(x\): state units, “average”, “associated with”, and the range.
  • The intercept is meaningful only if \(x = 0\) is meaningful and within the data; centring makes it the mean response at a chosen value.
  • Linear changes of units rescale coefficients and standard errors but leave \(t\), \(p\)-values and \(R^2\) unchanged.
  • Non-linear changes of scale require refitting; they change the model.
  • On the log scale, slopes are percentage changes: \(100(e^{\beta_1} - 1)\%\).

8 Exercises

8.1 A. Conceptual

A.1 (★). For the fit \(\widehat{\text{mpg}} = 46.3 - 7.68 \times \text{weight (1000 lb)}\), say whether each statement is correct, and fix the incorrect ones. (a) “A car that gains 1000 lb will lose 7.68 mpg.” (b) “Cars that weigh 1000 lb more have, on average, 7.68 mpg lower fuel economy.” (c) “A car weighing nothing would get 46.3 mpg.” (d) “Because −7.68 is much larger in magnitude than −0.0077, the model in thousands of pounds shows a stronger relationship than the model in pounds.”

Solution
  1. Incorrect: causal and about one car. Correct form: (b). (b) Correct, if “within the observed weight range” and “associated with” are understood (observational data). (c) Incorrect: extrapolation far outside the data; the intercept only positions the line. (d) Incorrect: the two fits are the same model in different units; \(t\) and \(R^2\) are identical (Theorem 1.5.1).

A.2 (★). In a regression of systolic blood pressure (mmHg) on age (years) for adults aged 30–70, the intercept is 95. Is it meaningful? Propose a reparametrisation that gives the intercept a useful meaning.

Solution

No: age 0 is far outside the 30–70 range (and the population is adults), so 95 mmHg is an extrapolation. Centre age, e.g. at 50 years: in the model with \(x - 50\) the intercept is the estimated mean blood pressure of 50-year-olds, a value inside the data. The slope is unchanged.

8.2 B. Mathematical

B.1 (★★). Prove Theorem 1.5.1 (a) and (c) for the special case \(a = c = 0\) (pure rescaling).

Solution

With \(x^* = bx\), \(y^* = dy\): \(S_{x^*y^*} = bd\,S_{xy}\), \(S_{x^*x^*} = b^2S_{xx}\), so \(\hat\beta_1^* = (d/b)\hat\beta_1\); \(\hat\beta_0^* = d\bar y - (d/b)\hat\beta_1\,b\bar x = d\hat\beta_0\). Residuals are multiplied by \(d\), so \(\hat\sigma^* = |d|\hat\sigma\) and \(\operatorname{se}(\hat\beta_1^*) = |d|\hat\sigma/(|b|\sqrt{S_{xx}}) = |d/b|\operatorname{se}(\hat\beta_1)\); the ratio gives \(t_1^* = \operatorname{sign}(bd)\,t_1\).

B.2 (★★). For \(x^* = x - c\) (centring at \(c\)), show that \(\operatorname{se}(\hat\beta_0^*) = \hat\sigma\sqrt{1/n + (\bar x - c)^2/S_{xx}}\). When is it smallest? Check the value \(0.2179\) in the worked example.

Solution

By Lesson 1.4, \(\operatorname{se}(\hat\beta_0^*) = \hat\sigma\sqrt{1/n + \bar x^{*2}/S_{x^*x^*}}\) with \(\bar x^* = \bar x - c\) and \(S_{x^*x^*} = S_{xx}\), giving the formula. It is smallest, \(\hat\sigma/\sqrt n\), at \(c = \bar x\). For Auto MPG (weight in 1000 lb): \(\hat\sigma = 4.344628\), \(n = 398\), \(\bar x = 2.970425\), \(c = 3\), \(S_{xx} = 284.704973\), so \(\operatorname{se} = 4.344628\sqrt{1/398 + 0.029575^2/284.705} = 0.2179\).

B.3 (★★). Show that if the response is multiplied by \(-1\) (\(d = -1\)), the slope, intercept and \(t\)-statistic change sign, while \(R^2\) and \(\hat\sigma\) do not. Give a practical example.

Solution

From Theorem 1.5.1 with \(b = 1\), \(a = c = 0\), \(d = -1\): \(\hat\beta_1^* = -\hat\beta_1\), \(\hat\beta_0^* = -\hat\beta_0\), \(t_1^* = -t_1\), \(\hat\sigma^* = \hat\sigma\), \(R^{2*} = R^2\). Example: recoding a score so that higher means worse instead of better.

8.3 C. Computational

C.1 (★). Refit the Auto MPG model with the response in km/L (\(\text{km/L} = 0.425144 \times \text{mpg}\)) and weight in 1000 lb. Verify Theorem 1.5.1 numerically.

Solution

\(\hat\beta_0 = 19.692\), \(\hat\beta_1 = -3.2637\) km/L per 1000 lb, \(\operatorname{se}(\hat\beta_1) = 0.1095\), \(\hat\sigma = 1.8471\), \(t_1 = -29.81\), \(R^2 = 0.6918\). Each of \(\hat\beta_0\), \(\hat\beta_1\), \(\operatorname{se}(\hat\beta_1)\) and \(\hat\sigma\) is \(0.425144\) times its mpg value (\(46.3174\), \(-7.6766\), \(0.2575\), \(4.3446\)), and \(t_1\) and \(R^2\) are unchanged.

C.2 (★★). Fit mpg on horsepower for the 392 cars with horsepower recorded, first with horsepower as recorded and then centred at 100 hp. Interpret both intercepts and the slope (per 10 hp).

Solution

Uncentred: \(\hat\beta_0 = 39.936\), \(\hat\beta_1 = -0.1578\) mpg per hp. The intercept (a car with 0 hp) has no practical meaning; observed horsepower runs from 46 to 230. Centred at 100 hp: \(\hat\beta_0 = 24.151\) (se 0.249), the estimated mean fuel economy of 100-hp cars; the slope is unchanged. Per 10 hp: about \(-1.58\) mpg on average. (Module 3 shows that this relationship is clearly curved, so a single slope is a rough summary.)

C.3 (★★). Fit \(\log(\text{mpg})\) on weight (1000 lb). Report the exact and approximate percentage change per 1000 lb and per 100 lb, and explain why the approximation is better for 100 lb.

Solution

\(\hat\beta_1 = -0.3512\). Per 1000 lb: exact \(100(e^{-0.3512} - 1) = -29.6\%\), approximate \(-35.1\%\). Per 100 lb: exact \(100(e^{-0.03512} - 1) = -3.45\%\), approximate \(-3.51\%\). The approximation \(e^{u} - 1 \approx u\) has error of order \(u^2/2\), which is small when \(|u|\) is small (0.035) and large when it is not (0.35).
