Lesson 1.7 — Inference for the Regression Parameters

1 Learning objectives

By the end of this lesson you will be able to:

  1. derive the \(t\)-distribution of the standardised slope and intercept under the normal error model;
  2. construct and interpret confidence intervals and hypothesis tests for \(\beta_0\) and \(\beta_1\), including tests of non-zero values;
  3. construct a confidence interval for \(\sigma^2\);
  4. derive the ANOVA \(F\)-test and prove \(F = t^2\); show that the test of \(\rho = 0\) gives the same statistic;
  5. distinguish statistical from practical significance, and explain what happens to these procedures when the assumptions fail.

2 Motivation

Lesson 1.4 showed that \(\hat\beta_1\) varies from sample to sample with standard deviation \(\sigma/\sqrt{S_{xx}}\). To turn this into a statement about the unknown \(\beta_1\) — an interval of plausible values, or a test of a hypothesis — we need the distribution of \(\hat\beta_1\), not only its mean and variance, and we must replace the unknown \(\sigma\) by \(\hat\sigma\). This lesson does both, first on data that satisfy the assumptions by construction, then on the Auto MPG data, where they do not.

Assumptions used in this lesson

The simple linear regression model is \(y_i = \beta_0 + \beta_1 x_i + \varepsilon_i\), \(i = 1, \dots, n\), with the \(x_i\) treated as fixed and

  • A1 (Correct mean function). \(E(\varepsilon_i) = 0\) for all \(i\), i.e. \(E(y_i) = \beta_0 + \beta_1 x_i\).
  • A2 (Constant variance). \(\operatorname{Var}(\varepsilon_i) = \sigma^2\) for all \(i\).
  • A3 (Uncorrelated errors). \(\operatorname{Cov}(\varepsilon_i, \varepsilon_j) = 0\) for \(i \ne j\).
  • A4 (Normality). \(\varepsilon_i \sim N(0, \sigma^2)\); together with A1–A3 this makes the errors independent.

Each result below states which of A1–A4 it uses. Why these assumptions, and what each one is needed for: Lesson 1.1, Assumptions.

4 Theory

Throughout, assumptions A1–A4 hold: \(y_i = \beta_0 + \beta_1 x_i + \varepsilon_i\) with \(\varepsilon_i\) independent \(N(0, \sigma^2)\), and the \(x_i\) fixed with \(S_{xx} > 0\).

4.1 Sampling distributions

Theorem 1.7.1 (Sampling distributions) — uses A1–A4

  1. \(\hat\beta_1 \sim N\bigl(\beta_1, \sigma^2/S_{xx}\bigr)\) and \(\hat\beta_0 \sim N\bigl(\beta_0, \sigma^2(1/n + \bar x^2/S_{xx})\bigr)\).
  2. \(\mathrm{SSE}/\sigma^2 \sim \chi^2_{n-2}\).
  3. \(\mathrm{SSE}\) is independent of \((\hat\beta_0, \hat\beta_1)\).
  4. Consequently \[ T_1 = \frac{\hat\beta_1 - \beta_1}{\operatorname{se}(\hat\beta_1)} \sim t_{n-2}, \qquad T_0 = \frac{\hat\beta_0 - \beta_0}{\operatorname{se}(\hat\beta_0)} \sim t_{n-2}. \]
Derivation

  1. Lesson 1.4: linear combinations of independent normals, with the stated means and variances.

  2. Under normality \((\hat\beta_0, \hat\beta_1, e_1, \dots, e_n)\) are jointly normal (all linear in \(\mathbf y\)), so zero covariance implies independence. Using \(\operatorname{Cov}(y_i, \hat\beta_1) = \sigma^2 k_i\), \(\operatorname{Cov}(\bar y, \hat\beta_1) = 0\) and \(e_i = y_i - \bar y - \hat\beta_1(x_i - \bar x)\): \[ \operatorname{Cov}(e_i, \hat\beta_1) = \sigma^2 k_i - 0 - (x_i - \bar x)\frac{\sigma^2}{S_{xx}} = 0, \qquad \operatorname{Cov}(e_i, \bar y) = \frac{\sigma^2}{n} - \frac{\sigma^2}{n} - (x_i - \bar x)\cdot 0 = 0 . \] So every residual is independent of \((\bar y, \hat\beta_1)\), hence of \((\hat\beta_0, \hat\beta_1)\); and \(\mathrm{SSE} = \sum e_i^2\) is a function of the residuals.

  3. is stated here; the proof uses the idempotent matrix \(\mathbf I - \mathbf H\) of rank \(n-2\) and is given in Module 2. It is consistent with Lesson 1.4: \(E(\mathrm{SSE}/\sigma^2) = n - 2\), the mean of \(\chi^2_{n-2}\).

  4. \(T_1 = \dfrac{(\hat\beta_1 - \beta_1)/(\sigma/\sqrt{S_{xx}})}{\sqrt{(\mathrm{SSE}/\sigma^2)/(n-2)}}\) is a standard normal divided by the square root of an independent \(\chi^2_{n-2}\) over its degrees of freedom: the definition of \(t_{n-2}\). The same argument applies to \(T_0\).

4.2 Confidence intervals

Inverting Theorem 1.7.1(d) and (b) gives exact \(100(1-\alpha)\%\) intervals: \[ \hat\beta_1 \pm t_{n-2;\,1-\alpha/2}\,\operatorname{se}(\hat\beta_1), \qquad \hat\beta_0 \pm t_{n-2;\,1-\alpha/2}\,\operatorname{se}(\hat\beta_0), \qquad \left[\frac{\mathrm{SSE}}{\chi^2_{n-2;\,1-\alpha/2}},\ \frac{\mathrm{SSE}}{\chi^2_{n-2;\,\alpha/2}}\right] \text{ for } \sigma^2 . \]

Interpreting a confidence interval

The probability statement is about the procedure: in repeated samples, 95% of intervals constructed this way contain \(\beta_1\). A particular computed interval either contains \(\beta_1\) or it does not. “There is a 95% probability that \(\beta_1\) lies in \([-11.5, -7.1]\)” is not a frequentist statement.

4.3 Hypothesis tests

To test \(H_0\!: \beta_1 = \beta_{10}\) use \[ t = \frac{\hat\beta_1 - \beta_{10}}{\operatorname{se}(\hat\beta_1)} \ \overset{H_0}{\sim}\ t_{n-2}, \] with \(p\)-value \(2P(t_{n-2} \ge |t|)\) for the two-sided alternative, or \(P(t_{n-2} \ge t)\) / \(P(t_{n-2} \le t)\) for one-sided alternatives. The default \(\beta_{10} = 0\) tests whether there is any linear association; other values test a specific claim (for example a slope predicted by theory or reported in an earlier study).

A two-sided test at level \(\alpha\) rejects \(H_0\!: \beta_1 = \beta_{10}\) exactly when \(\beta_{10}\) lies outside the \(100(1-\alpha)\%\) confidence interval: the interval is the set of values not rejected.

4.4 The ANOVA \(F\)-test

Theorem 1.7.2 (\(F\)-test and its equivalences) — uses A1–A4

Under \(H_0\!: \beta_1 = 0\), \[ F = \frac{\mathrm{MS}_{\text{Reg}}}{\mathrm{MS}_{\text{Res}}} = \frac{\mathrm{SSR}/1}{\mathrm{SSE}/(n-2)} \sim F_{1,\,n-2}, \] and \[ F = t^2 = \frac{(n-2)\,R^2}{1 - R^2}, \qquad t = \frac{\hat\beta_1}{\operatorname{se}(\hat\beta_1)} = \frac{r\sqrt{n-2}}{\sqrt{1 - r^2}} . \]

Derivation

By Lesson 1.6, \(\mathrm{SSR} = \hat\beta_1^2 S_{xx}\), so \(F = \hat\beta_1^2 S_{xx}/\hat\sigma^2 = \bigl(\hat\beta_1/\operatorname{se}(\hat\beta_1)\bigr)^2 = t^2\). The square of a \(t_{n-2}\) variable is \(F_{1,n-2}\). Next, \(\hat\sigma^2 = \mathrm{SSE}/(n-2) = S_{yy}(1 - r^2)/(n-2)\) and \(\hat\beta_1\sqrt{S_{xx}} = S_{xy}/\sqrt{S_{xx}} = r\sqrt{S_{yy}}\), so \(t = \hat\beta_1\sqrt{S_{xx}}/\hat\sigma = r\sqrt{n-2}/\sqrt{1 - r^2}\). Squaring and using \(R^2 = r^2\) gives \(F = (n-2)R^2/(1 - R^2)\).

The last form is the classical test of \(H_0\!: \rho = 0\) for a bivariate normal sample (Lesson 1.2): the regression \(t\)-test and the correlation test are the same test. In simple regression the \(F\)-test adds nothing new; in multiple regression (Module 2) it tests several coefficients at once.

4.5 Statistical and practical significance

A small \(p\)-value says the data are incompatible with \(\beta_1 = \beta_{10}\) under the model. It does not say the effect is large, important or causal. With large \(n\), slopes of negligible practical size become “significant”; with small \(n\), important slopes may not. Report the estimate with its confidence interval and interpret its size in context.

4.6 When the assumptions fail

Assumption violated Consequence for these procedures
A4 (normality), large \(n\) \(t\)-intervals and tests remain approximately valid (central limit theorem), provided A1–A3 hold.
A4, small \(n\), heavy tails or outliers Coverage and error rates can be poor.
A2 (constant variance) \(\operatorname{se}(\hat\beta_1)\) is wrong; coverage can be too high or too low depending on the pattern (worked example).
A3 (independence) Usually standard errors too small, intervals too narrow (time series; Module 3).
A1 (wrong mean function) The target \(\beta_1\) is itself only an approximation; inference about it may not answer the scientific question.

5 Worked example 1: data that satisfy the assumptions

To see the procedures work as intended, we use a simulated teaching data set of \(n = 25\) points generated from \[ y_i = 46 - 7.7\,x_i + \varepsilon_i, \qquad \varepsilon_i \sim N(0, 4^2), \qquad x_i \sim \text{Uniform}(1.6, 5.1), \] (seed 2026 in Python; values rounded to 3 and 2 decimals and listed in the code). Because we generated the data, we know the true values \(\beta_0 = 46\), \(\beta_1 = -7.7\) and \(\sigma^2 = 16\) — a check that real data never allow.

Python code 
import numpy as np
from scipy import stats

x = np.array([2.226, 3.84, 3.235, 2.897, 2.842, 4.367, 4.768, 2.221, 3.885, 2.644, 4.984, 4.819, 3.826,
              4.235, 3.403, 4.491, 3.169, 2.786, 2.573, 2.392, 3.44, 3.108, 3.921, 1.645, 3.167])
y = np.array([36.16, 13.58, 26.48, 18.77, 24.81, 7.7, 14.69, 32.24, 20.64, 22.1, 10.36, 6.81, 14.71,
              15.42, 23.3, 12.24, 19.08, 21.25, 31.97, 29.96, 22.39, 30.8, 12.54, 43.57, 34.22])

def slr_inference(x, y, beta10=0.0, level=0.95):
    n = len(y)
    Sxx = np.sum((x - x.mean())**2)
    b1 = np.sum((x - x.mean()) * (y - y.mean())) / Sxx
    b0 = y.mean() - b1 * x.mean()
    e = y - b0 - b1 * x
    SSE = e @ e; dfr = n - 2; s2 = SSE / dfr
    se1 = np.sqrt(s2 / Sxx); se0 = np.sqrt(s2 * (1 / n + x.mean()**2 / Sxx))
    q = stats.t.ppf(1 - (1 - level) / 2, dfr)
    t1 = (b1 - beta10) / se1
    SSR = np.sum((b0 + b1 * x - y.mean())**2)
    return dict(b0=b0, se0=se0, ci0=(b0 - q * se0, b0 + q * se0),
                b1=b1, se1=se1, ci1=(b1 - q * se1, b1 + q * se1),
                t1=t1, p1=2 * stats.t.sf(abs(t1), dfr),
                F=SSR / s2, pF=stats.f.sf(SSR / s2, 1, dfr), SSE=SSE, dfr=dfr,
                ci_sigma2=(SSE / stats.chi2.ppf(1 - (1 - level) / 2, dfr),
                           SSE / stats.chi2.ppf((1 - level) / 2, dfr)))

res = slr_inference(x, y)
print(f"b0 = {res['b0']:.4f} (se {res['se0']:.4f}), 95% CI ({res['ci0'][0]:.4f}, {res['ci0'][1]:.4f})")
print(f"b1 = {res['b1']:.4f} (se {res['se1']:.4f}), 95% CI ({res['ci1'][0]:.4f}, {res['ci1'][1]:.4f})")
print(f"H0: beta1 = 0:  t = {res['t1']:.4f}, p = {res['p1']:.2e};  F = {res['F']:.4f} = t^2 = {res['t1']**2:.4f}")
r7 = slr_inference(x, y, beta10=-7.7)
print(f"H0: beta1 = -7.7: t = {r7['t1']:.4f}, p = {r7['p1']:.4f}")
print(f"95% CI for sigma^2: ({res['ci_sigma2'][0]:.4f}, {res['ci_sigma2'][1]:.4f})")

Can we trust these intervals for Auto MPG?

Lessons 1.1 and 1.4 showed that the error variance decreases with weight and that the mean function is curved. The intervals above therefore rest on assumptions the data visibly violate. How much does that matter? A simulation keeps the 398 observed weights and the straight-line mean but lets the error standard deviation change with weight (10,000 data sets, seed 2026):

Error standard deviation Actual coverage of the “95%” interval for \(\beta_1\)
constant, \(\sigma = 4.34\) (A2 holds) 0.951
decreasing with weight, \(\max(9.5 - 1.5x, 1)\) — like the real data 0.968
increasing with weight, \(0.5 + 1.2(x - 1.6)\) 0.880

With the pattern seen in the real data the usual interval happens to be conservative (too wide); with the opposite pattern it would cover the true slope only 88% of the time. The direction of the error cannot be known without examining the data — which is why Module 3 introduces diagnostics and standard errors that do not rely on A2.

6.1 Interpretation in context

Among the 398 cars, each additional 1000 lb is associated with a mean fuel economy lower by 7.7 mpg (95% CI 7.2 to 8.2 mpg lower), assuming a straight-line mean and constant error variance. Because the variance clearly decreases with weight, this interval should be treated as approximate; the association itself is unambiguous (\(t = -29.8\)).

7 Common misconceptions

Misconceptions

  1. “\(p < 0.001\), so the effect is large.” — The \(p\)-value measures incompatibility with \(H_0\), not size. Report the interval.
  2. “\(p = 0.21\) for \(H_0\!: \beta_1 = -8\) proves that \(\beta_1 = -8\).” — Not rejecting \(H_0\) means the data are compatible with it — and with every other value in the confidence interval.
  3. “There is a 95% probability that \(\beta_1\) is in this interval.” — The 95% refers to the long-run behaviour of the procedure.
  4. “The \(t\)-test requires \(y\) to be normal.” — It requires normal errors (and only approximately, in large samples).
  5. “If the assumptions fail, the intervals are always too narrow.” — They can be too narrow or too wide; the direction depends on the pattern of the violation.

8 Key takeaways

  • Under A1–A4, \((\hat\beta_j - \beta_j)/\operatorname{se}(\hat\beta_j) \sim t_{n-2}\) because \(\hat\beta_j\) is normal and independent of \(\mathrm{SSE} \sim \sigma^2\chi^2_{n-2}\).
  • Confidence intervals are \(\hat\beta_j \pm t_{n-2;\,1-\alpha/2}\operatorname{se}(\hat\beta_j)\); they are the sets of values a two-sided test does not reject.
  • In simple regression, the \(F\)-test, the \(t\)-test of \(\beta_1 = 0\) and the test of \(\rho = 0\) coincide: \(F = t^2 = (n-2)R^2/(1-R^2)\).
  • Report estimates with intervals and interpret their size; significance is not importance.
  • Violations of A2 or A3 distort standard errors in either direction; check them (Module 3).

9 Exercises

9.1 A. Conceptual

A.1 (★). A study with \(n = 20\,000\) reports a slope of 0.002 kg per hour of television per week, \(p = 0.001\). Another with \(n = 30\) reports 1.5 kg per hour, \(p = 0.08\). Which result is more important? What would you ask each author to report?

Solution

Importance depends on size and precision, not on \(p\) alone. The first slope is precisely estimated but practically negligible; the second is large but imprecise, and its data are compatible with zero and with large effects. Ask both for the estimate with a confidence interval in meaningful units, and for the design (observational or experimental).

A.2 (★). Explain why rejecting \(H_0\!: \beta_1 = 0\) at the 5% level is equivalent to the 95% confidence interval for \(\beta_1\) excluding 0.

Solution

The test rejects iff \(|\hat\beta_1 - 0|/\operatorname{se}(\hat\beta_1) > t_{n-2;0.975}\), i.e. iff \(0 \notin [\hat\beta_1 - t_{n-2;0.975}\operatorname{se},\ \hat\beta_1 + t_{n-2;0.975}\operatorname{se}]\).

9.2 B. Mathematical

B.1 (★★). Show that \(\operatorname{Cov}(e_i, \hat\beta_1) = 0\) for every \(i\), and explain why, under normality, this implies independence of \(\mathrm{SSE}\) and \(\hat\beta_1\).

Solution

See the derivation of Theorem 1.7.1(c): \(\operatorname{Cov}(e_i, \hat\beta_1) = \operatorname{Cov}(y_i, \hat\beta_1) - \operatorname{Cov}(\bar y, \hat\beta_1) - (x_i - \bar x)\operatorname{Var}(\hat\beta_1) = \sigma^2 k_i - 0 - (x_i - \bar x)\sigma^2/S_{xx} = 0\). Under normality the vector \((e_1, \dots, e_n, \hat\beta_1)\) is multivariate normal, so zero covariances imply independence of \(\hat\beta_1\) and the whole residual vector, and hence of any function of the residuals, such as \(\mathrm{SSE}\).

B.2 (★★). Prove \(F = (n-2)R^2/(1 - R^2)\). For Auto MPG (\(n = 398\), \(R^2 = 0.691793\)), compute \(F\) and compare with the ANOVA table.

Solution

\(F = \mathrm{SSR}/(\mathrm{SSE}/(n-2)) = (n-2)(\mathrm{SSR}/\mathrm{SST})/(\mathrm{SSE}/\mathrm{SST}) = (n-2)R^2/(1-R^2)\). Numerically \(396 \times 0.691793/0.308207 = 888.85\), as in the ANOVA table.

B.3 (★★★). Show that a \(100(1-\alpha)\%\) confidence interval for \(\beta_1\) has expected length \(2\,t_{n-2;1-\alpha/2}\,E(\hat\sigma)/\sqrt{S_{xx}}\). How does the length depend on \(n\) and on the spread of \(x\)? (You may use \(E(\hat\sigma) < \sigma\) without computing it exactly.)

Solution

The length is \(2t_{n-2;1-\alpha/2}\hat\sigma/\sqrt{S_{xx}}\); only \(\hat\sigma\) is random, so the expected length is \(2t_{n-2;1-\alpha/2}E(\hat\sigma)/\sqrt{S_{xx}}\). As \(n\) grows, \(t_{n-2;1-\alpha/2}\) decreases towards \(z_{1-\alpha/2}\) and \(S_{xx}\) grows roughly in proportion to \(n\) (for a fixed spread of \(x\)), so the length shrinks like \(1/\sqrt n\). A larger spread of \(x\) increases \(S_{xx}\) and shortens the interval, as in Lesson 1.4.

9.3 C. Computational

C.1 (★). For the teaching data set, compute 90% and 99% confidence intervals for \(\beta_1\). Which of them contain the true value \(-7.7\)?

Solution

With \(t_{23;0.95} = 1.7139\) and \(t_{23;0.995} = 2.8073\): 90% CI \((-11.134, -7.464)\); 99% CI \((-12.305, -6.293)\). The 99% interval contains \(-7.7\); the 90% interval does not. This is consistent with \(p = 0.149\) for \(H_0\!: \beta_1 = -7.7\): the hypothesis is rejected at the 15% level but not at 10%, 5% or 1%. (R: confint(fit, level = 0.90).)

C.2 (★★). Coverage by simulation. Fix the 25 \(x\) values of a design drawn from Uniform(1.6, 5.1) and simulate 10,000 data sets from \(y = 46 - 7.7x + \varepsilon\), \(\varepsilon \sim N(0, 16)\) (seed 2026). Estimate the coverage of the 95% interval for \(\beta_1\).

Solution (Python) 
import numpy as np
from scipy import stats
rng = np.random.default_rng(2026)
n, R = 25, 10_000
X = rng.uniform(1.6, 5.1, n)
Sxx = np.sum((X - X.mean())**2); k = (X - X.mean()) / Sxx
Y = 46 - 7.7 * X + rng.normal(0, 4, size=(R, n))
b1 = Y @ k; b0 = Y.mean(axis=1) - b1 * X.mean()
s2 = ((Y - b0[:, None] - b1[:, None] * X)**2).sum(axis=1) / (n - 2)
covered = np.abs(b1 + 7.7) <= stats.t.ppf(0.975, n - 2) * np.sqrt(s2 / Sxx)
print(round(covered.mean(), 4))

Output: 0.947. The estimated coverage agrees with the nominal 95% to within simulation error (the standard error of a proportion near 0.95 from 10,000 replications is about 0.002).

C.3 (★★). For the Auto MPG data, test \(H_0\!: \beta_1 = -8\) against \(H_1\!: \beta_1 > -8\) (heavier cars lose less than 8 mpg per 1000 lb). Report the one-sided \(p\)-value and state the conclusion in words.

Solution

\(t = (-7.67661 + 8)/0.257487 = 1.256\) with 396 d.f.; one-sided \(p = P(t_{396} \ge 1.256) = 0.105\). The data do not provide convincing evidence that the decrease is smaller than 8 mpg per 1000 lb (under the model assumptions, which Lesson 1.4 showed are only approximate here).
