Lesson 1.4 — Statistical Properties of the OLS Estimators

How far can a slope estimate be from the truth, and is there a better estimator? This lesson treats the estimates as random variables and derives their properties, naming exactly which assumptions each result needs.

1 Learning objectives

By the end of this lesson you will be able to:

  1. write \(\hat\beta_0\) and \(\hat\beta_1\) as linear combinations of the responses and prove that they are unbiased under assumption A1;
  2. derive \(\operatorname{Var}(\hat\beta_1)\), \(\operatorname{Var}(\hat\beta_0)\) and \(\operatorname{Cov}(\hat\beta_0, \hat\beta_1)\) under A1–A3;
  3. state and prove the Gauss–Markov theorem for the slope;
  4. prove that \(\hat\sigma^2 = \mathrm{SSE}/(n-2)\) is unbiased for \(\sigma^2\), and explain why the divisor is \(n-2\);
  5. show that, under normal errors, OLS is maximum likelihood for \((\beta_0, \beta_1)\), and that the ML estimator of \(\sigma^2\) is biased.

2 Motivation

Lesson 1.3 found \(\hat\beta_1 = -7.677\) mpg per 1000 lb for the Auto MPG data. A different sample of cars would give a different value. How far can \(\hat\beta_1\) be from the true slope, and is there a better estimator? This lesson treats \(\hat\beta_0\), \(\hat\beta_1\) and \(\hat\sigma^2\) as random variables and derives their means and variances. It is also the first lesson in which the assumptions of Lesson 1.1 do real work: each result below names exactly the assumptions it uses.

3 Notation for this lesson

Symbol Meaning
\(k_i = (x_i - \bar x)/S_{xx}\) weights such that \(\hat\beta_1 = \sum k_i y_i\)
\(\sigma^2\) error variance (assumption A2)
\(\hat\sigma^2 = \mathrm{MS}_{\text{Res}} = \mathrm{SSE}/(n-2)\) unbiased estimator of \(\sigma^2\)
\(\tilde\sigma^2 = \mathrm{SSE}/n\) maximum likelihood estimator of \(\sigma^2\)
\(\operatorname{se}(\hat\beta_1)\) estimated standard error, \(\hat\sigma/\sqrt{S_{xx}}\)

Throughout, the \(x_i\) are treated as fixed constants (or the analysis is conditional on them), and \(S_{xx} > 0\). Assumptions A1–A4 are those of Lesson 1.1.

4 Theory

4.1 The estimators as linear combinations of the responses

From Lesson 1.3, \[ \hat\beta_1 = \sum_{i=1}^n k_i\, y_i, \qquad k_i = \frac{x_i - \bar x}{S_{xx}}, \qquad \hat\beta_0 = \bar y - \hat\beta_1 \bar x = \sum_{i=1}^n \Bigl(\frac{1}{n} - \bar x\, k_i\Bigr) y_i . \] The weights satisfy three identities used repeatedly below: \[ \sum k_i = 0, \qquad \sum k_i x_i = 1, \qquad \sum k_i^2 = \frac{1}{S_{xx}} . \tag{1.4.1} \]

Derivation of (1.4.1)

\(\sum k_i = \sum (x_i - \bar x)/S_{xx} = 0\). \(\sum k_i x_i = \sum (x_i - \bar x)x_i / S_{xx} = \sum (x_i - \bar x)^2/S_{xx} = 1\), because \(\sum (x_i - \bar x)\bar x = 0\). \(\sum k_i^2 = \sum (x_i - \bar x)^2/S_{xx}^2 = 1/S_{xx}\).

4.2 Unbiasedness

Theorem 1.4.1 (Unbiasedness) — uses A1

If \(E(y_i) = \beta_0 + \beta_1 x_i\) for all \(i\), then \(E(\hat\beta_1) = \beta_1\) and \(E(\hat\beta_0) = \beta_0\).

Derivation

By linearity of expectation and (1.4.1), \(E(\hat\beta_1) = \sum k_i(\beta_0 + \beta_1 x_i) = \beta_0\sum k_i + \beta_1\sum k_i x_i = \beta_1\). Then \(E(\bar y) = \beta_0 + \beta_1\bar x\), so \(E(\hat\beta_0) = \beta_0 + \beta_1\bar x - \beta_1\bar x = \beta_0\).

Unbiasedness needs only A1. It does not need constant variance, uncorrelated errors or normality. It does need the mean function to be correct: if \(E(y \mid x)\) is curved, as for the Auto MPG data, then \(\hat\beta_1\) is an unbiased estimator of the slope of a straight line that is itself only an approximation.

4.3 Variances and covariance

Theorem 1.4.2 (Variances and covariance) — uses A1–A3

\[ \operatorname{Var}(\hat\beta_1) = \frac{\sigma^2}{S_{xx}}, \qquad \operatorname{Var}(\hat\beta_0) = \sigma^2\Bigl(\frac{1}{n} + \frac{\bar x^2}{S_{xx}}\Bigr), \qquad \operatorname{Cov}(\hat\beta_0, \hat\beta_1) = -\frac{\bar x\,\sigma^2}{S_{xx}} . \]

Derivation

Under A2–A3 the \(y_i\) are uncorrelated with common variance \(\sigma^2\), so for constants \(a_i, c_i\): \(\operatorname{Var}(\sum a_i y_i) = \sigma^2\sum a_i^2\) and \(\operatorname{Cov}(\sum a_i y_i, \sum c_i y_i) = \sigma^2 \sum a_i c_i\).

  • \(\operatorname{Var}(\hat\beta_1) = \sigma^2 \sum k_i^2 = \sigma^2/S_{xx}\).
  • \(\operatorname{Cov}(\bar y, \hat\beta_1) = \sigma^2\sum \tfrac{1}{n}k_i = 0\).
  • \(\operatorname{Var}(\hat\beta_0) = \operatorname{Var}(\bar y) + \bar x^2\operatorname{Var}(\hat\beta_1) - 2\bar x\operatorname{Cov}(\bar y, \hat\beta_1) = \sigma^2/n + \bar x^2\sigma^2/S_{xx}\).
  • \(\operatorname{Cov}(\hat\beta_0, \hat\beta_1) = \operatorname{Cov}(\bar y - \bar x\hat\beta_1, \hat\beta_1) = 0 - \bar x\,\sigma^2/S_{xx}\).

Three consequences matter in practice.

  • Design. \(\operatorname{Var}(\hat\beta_1)\) decreases as \(S_{xx}\) increases: spreading the \(x\) values out, or collecting more data, estimates the slope more precisely.
  • Centring. If \(\bar x = 0\) the intercept and slope estimators are uncorrelated. When \(\bar x\) is large relative to the spread of \(x\), they are strongly correlated (negatively if \(\bar x > 0\)).
  • Assumptions. These formulas need A2 and A3. If the error variance is not constant, \(\hat\beta_1\) is still unbiased, but \(\sigma^2/S_{xx}\) is no longer its variance (Exercise C3).

4.4 The Gauss–Markov theorem

Call \(\tilde\beta_1 = \sum c_i y_i\) a linear unbiased estimator of \(\beta_1\) if \(E(\tilde\beta_1) = \beta_1\) for all values of \(\beta_0\) and \(\beta_1\).

Theorem 1.4.3 (Gauss–Markov, simple regression) — uses A1–A3

Among all linear unbiased estimators of \(\beta_1\), the OLS estimator \(\hat\beta_1\) has the smallest variance, and it is the unique estimator with this property. \(\hat\beta_1\) is the best linear unbiased estimator (BLUE) of \(\beta_1\).

Derivation

Unbiasedness constraints. \(E(\sum c_i y_i) = \beta_0\sum c_i + \beta_1 \sum c_i x_i\) equals \(\beta_1\) for all \(\beta_0, \beta_1\) iff \(\sum c_i = 0\) and \(\sum c_i x_i = 1\).

Decomposition. Write \(c_i = k_i + d_i\). Since the \(k_i\) satisfy the same two constraints, \(\sum d_i = 0\) and \(\sum d_i x_i = 0\). Hence \[ \sum k_i d_i = \frac{1}{S_{xx}}\sum (x_i - \bar x)d_i = \frac{1}{S_{xx}}\Bigl(\sum x_i d_i - \bar x \sum d_i\Bigr) = 0 . \] Variance. By A2–A3, \[ \operatorname{Var}(\tilde\beta_1) = \sigma^2\sum c_i^2 = \sigma^2\Bigl(\sum k_i^2 + 2\sum k_i d_i + \sum d_i^2\Bigr) = \operatorname{Var}(\hat\beta_1) + \sigma^2\sum d_i^2 \ \ge\ \operatorname{Var}(\hat\beta_1), \] with equality iff every \(d_i = 0\), i.e. \(\tilde\beta_1 = \hat\beta_1\).

What Gauss–Markov does and does not say

  • It compares OLS only with linear and unbiased estimators. A biased estimator can have smaller mean squared error — the starting point for ridge and Liu estimation in Module 5.
  • It needs no normality. Under normal errors a stronger result holds: OLS has minimum variance among all unbiased estimators.
  • If A2 or A3 fails, OLS is still unbiased (under A1) but no longer BLUE; weighted or generalised least squares can do better (Module 3).

4.5 Estimating \(\sigma^2\)

Theorem 1.4.4 (Unbiased estimator of \(\sigma^2\)) — uses A1–A3

\(E(\mathrm{SSE}) = (n-2)\sigma^2\). Hence \[ \hat\sigma^2 = \mathrm{MS}_{\text{Res}} = \frac{\mathrm{SSE}}{n-2} \] is an unbiased estimator of \(\sigma^2\) (for \(n \ge 3\)).

Derivation

From Lesson 1.2, \(\mathrm{SSE} = S_{yy} - \hat\beta_1^2 S_{xx}\).

First term. \(y_i - \bar y = \beta_1(x_i - \bar x) + (\varepsilon_i - \bar\varepsilon)\), so \(E(S_{yy}) = \beta_1^2 S_{xx} + 2\beta_1\sum (x_i - \bar x)E(\varepsilon_i - \bar\varepsilon) + E\sum(\varepsilon_i - \bar\varepsilon)^2 = \beta_1^2 S_{xx} + (n-1)\sigma^2\), using A1 for the middle term and A2–A3 for the last (the usual sample-variance result).

Second term. \(E(\hat\beta_1^2) = \operatorname{Var}(\hat\beta_1) + [E(\hat\beta_1)]^2 = \sigma^2/S_{xx} + \beta_1^2\), so \(E(\hat\beta_1^2 S_{xx}) = \sigma^2 + \beta_1^2 S_{xx}\).

Subtracting, \(E(\mathrm{SSE}) = (n-1)\sigma^2 - \sigma^2 = (n-2)\sigma^2\).

The divisor \(n-2\) is the residual degrees of freedom: the \(n\) residuals satisfy the two linear constraints \(\sum e_i = 0\) and \(\sum x_i e_i = 0\) (Lesson 1.3), so only \(n-2\) of them are free. Replacing \(\sigma^2\) by \(\hat\sigma^2\) in Theorem 1.4.2 gives the estimated standard errors \[ \operatorname{se}(\hat\beta_1) = \frac{\hat\sigma}{\sqrt{S_{xx}}}, \qquad \operatorname{se}(\hat\beta_0) = \hat\sigma\sqrt{\frac{1}{n} + \frac{\bar x^2}{S_{xx}}} . \]

4.6 Normal errors: maximum likelihood

Theorem 1.4.5 (Maximum likelihood) — uses A1–A4

Under normal errors, the maximum likelihood estimators of \(\beta_0\) and \(\beta_1\) are the OLS estimators, and the maximum likelihood estimator of \(\sigma^2\) is \[ \tilde\sigma^2 = \frac{\mathrm{SSE}}{n}, \qquad E(\tilde\sigma^2) = \frac{n-2}{n}\,\sigma^2 < \sigma^2 . \] Moreover, \(\hat\beta_0\) and \(\hat\beta_1\) are exactly normally distributed, being linear combinations of independent normal variables.

Derivation

The log-likelihood is \[ \ell(\beta_0, \beta_1, \sigma^2) = -\frac{n}{2}\log(2\pi\sigma^2) - \frac{1}{2\sigma^2}\sum (y_i - \beta_0 - \beta_1 x_i)^2 . \] For any fixed \(\sigma^2\), \(\ell\) is maximised over \((\beta_0, \beta_1)\) by minimising the sum of squares, i.e. at the OLS estimates (Lesson 1.3). Substituting them, \(\partial\ell/\partial\sigma^2 = -n/(2\sigma^2) + \mathrm{SSE}/(2\sigma^4) = 0\) gives \(\tilde\sigma^2 = \mathrm{SSE}/n\), a maximum because \(\ell \to -\infty\) as \(\sigma^2 \to 0\) or \(\infty\). Its expectation follows from Theorem 1.4.4. Normality of \(\hat\beta_j\): a linear combination of independent normal variables is normal.

The bias of \(\tilde\sigma^2\) vanishes as \(n \to \infty\), but it matters in small samples: with \(n = 5\), \(E(\tilde\sigma^2) = 0.6\,\sigma^2\).

5 Worked example

5.1 Standard errors for the Auto MPG fit

For mpg on weight (1000 lb), \(n = 398\): \(\mathrm{SSE} = 7474.814\), so \[ \hat\sigma^2 = \frac{7474.814}{396} = 18.8758, \quad \hat\sigma = 4.3446, \quad \operatorname{se}(\hat\beta_1) = \frac{4.3446}{\sqrt{284.705}} = 0.2575, \quad \operatorname{se}(\hat\beta_0) = 0.7952 . \] The estimated covariance of \(\hat\beta_0\) and \(\hat\beta_1\) is \(-0.1969\), a correlation of \(-0.962\): because \(\bar x = 2.97\) is far from 0 relative to the spread of weight, an error in the slope is largely offset by an error in the intercept.

A caution that matters for this data set

These standard errors use Theorem 1.4.2, which assumes constant error variance (A2). Lesson 1.1 showed that the spread of mpg shrinks with weight, so these numbers should be treated as approximate. Exercise C3 shows by simulation how large the discrepancy can be; Module 3 gives standard errors that remain valid when A2 fails.

R code 
cols <- c("mpg", "cylinders", "displacement", "horsepower", "weight",
          "acceleration", "model_year", "origin", "car_name")
auto <- read.table("data/auto-mpg.data", col.names = cols, na.strings = "?")
x <- auto$weight / 1000; y <- auto$mpg; n <- length(y)

fit <- lm(y ~ x)
SSE <- sum(resid(fit)^2)
sigma2_hat <- SSE / (n - 2)
Sxx <- sum((x - mean(x))^2)
c(SSE = SSE, sigma2_hat = sigma2_hat, sigma_hat = sqrt(sigma2_hat),
  se_b1 = sqrt(sigma2_hat / Sxx),
  se_b0 = sqrt(sigma2_hat * (1 / n + mean(x)^2 / Sxx)),
  sigma2_ML = SSE / n)

summary(fit)$coefficients[, 1:2]   # lm() reports the same standard errors
vcov(fit)                           # estimated covariance matrix
Python code 
import numpy as np
import pandas as pd

cols = ["mpg", "cylinders", "displacement", "horsepower", "weight",
        "acceleration", "model_year", "origin", "car_name"]
auto = pd.read_csv("data/auto-mpg.data", sep=r"\s+", header=None,
                   names=cols, na_values="?", quotechar='"')
x = auto["weight"].to_numpy() / 1000
y = auto["mpg"].to_numpy()
n = len(y)

Sxx = np.sum((x - x.mean())**2)
b1 = np.sum((x - x.mean()) * (y - y.mean())) / Sxx
b0 = y.mean() - b1 * x.mean()
e = y - b0 - b1 * x
SSE = e @ e
s2 = SSE / (n - 2)
print(f"SSE = {SSE:.4f}, sigma2_hat = {s2:.4f}, sigma_hat = {np.sqrt(s2):.4f}")
print(f"se(b1) = {np.sqrt(s2 / Sxx):.4f}, se(b0) = {np.sqrt(s2 * (1/n + x.mean()**2 / Sxx)):.4f}")
print(f"Cov(b0, b1) estimate = {-x.mean() * s2 / Sxx:.4f}, "
      f"correlation = {-x.mean() / np.sqrt(Sxx / n + x.mean()**2):.4f}")
print(f"ML estimate SSE/n = {SSE / n:.4f}")

5.2 Simulation: the sampling distribution of \(\hat\beta_1\)

To see Theorems 1.4.1–1.4.4 at work, keep the 398 observed weights fixed and generate 10,000 artificial data sets from a model that satisfies A1–A4 by construction: \[ y_i = 46.3 - 7.7\,x_i + \varepsilon_i, \qquad \varepsilon_i \sim N(0, 4.34^2) . \]

R code 
set.seed(2026)
R <- 10000; beta0 <- 46.3; beta1 <- -7.7; sigma <- 4.34
k <- (x - mean(x)) / Sxx
sims <- replicate(R, {
  ysim <- beta0 + beta1 * x + rnorm(n, 0, sigma)
  b1s <- sum(k * ysim); b0s <- mean(ysim) - b1s * mean(x)
  c(b0 = b0s, b1 = b1s, s2 = sum((ysim - b0s - b1s * x)^2) / (n - 2))
})
c(mean_b1 = mean(sims["b1", ]), sd_b1 = sd(sims["b1", ]),
  theory_sd_b1 = sigma / sqrt(Sxx),
  mean_s2 = mean(sims["s2", ]), sigma2 = sigma^2)
hist(sims["b1", ], breaks = 50, freq = FALSE,
     main = "", xlab = "Simulated slope estimates")
curve(dnorm(x, beta1, sigma / sqrt(Sxx)), add = TRUE, lwd = 2)
abline(v = beta1, lty = 2)
Python code 
import matplotlib.pyplot as plt

rng = np.random.default_rng(2026)
R, beta0, beta1, sigma = 10_000, 46.3, -7.7, 4.34

Y = beta0 + beta1 * x + rng.normal(0, sigma, size=(R, n))
B1 = Y @ k
B0 = Y.mean(axis=1) - B1 * x.mean()
S2 = ((Y - B0[:, None] - B1[:, None] * x)**2).sum(axis=1) / (n - 2)
sd_theory = sigma / np.sqrt(Sxx)
print(f"mean b1 = {B1.mean():.4f}, sd b1 = {B1.std(ddof=1):.4f}, theory sd = {sd_theory:.4f}")
print(f"mean sigma2_hat = {S2.mean():.4f}, true sigma^2 = {sigma**2:.4f}")

grid = np.linspace(B1.min(), B1.max(), 200)
fig, ax = plt.subplots(figsize=(6, 4))
ax.hist(B1, bins=50, density=True, color="lightgray", edgecolor="white")

5.3 Interpretation

  • \(\operatorname{se}(\hat\beta_1) = 0.26\) mpg per 1000 lb: if the model assumptions held, slope estimates from repeated samples of this design would typically differ from the true slope by about a quarter of an mpg per 1000 lb. The slope is estimated precisely relative to its size (\(-7.68\)).
  • The intercept is estimated less precisely (\(0.80\)) because \(x = 0\) is far outside the data: Theorem 1.4.2 shows \(\operatorname{Var}(\hat\beta_0)\) grows with \(\bar x^2\).
  • None of this addresses whether a straight line is the right model; precision is not the same as correctness.

6 Common misconceptions

Misconceptions

  1. “OLS is unbiased only if the errors are normal.” — No. Unbiasedness needs only A1.
  2. “Gauss–Markov says OLS is the best estimator.” — Only among linear unbiased estimators, and only under A1–A3. Biased estimators can have smaller mean squared error.
  3. “\(\mathrm{SSE}/n\) is the natural estimate of \(\sigma^2\).” — It is the ML estimate but is biased downward; the unbiased estimator divides by the residual degrees of freedom, \(n - 2\).
  4. “A small standard error means the model is right.” — No. The standard error measures sampling variability under the model; it says nothing about whether the model is correctly specified.

7 Key takeaways

  • \(\hat\beta_0\) and \(\hat\beta_1\) are linear in the \(y_i\); this makes their moments easy to compute.
  • A1 gives unbiasedness; A1–A3 give \(\operatorname{Var}(\hat\beta_1) = \sigma^2/S_{xx}\) and the Gauss–Markov (BLUE) property.
  • \(\hat\sigma^2 = \mathrm{SSE}/(n-2)\) is unbiased; \(n-2\) is the residual degrees of freedom.
  • Under normal errors, OLS is maximum likelihood for \(\beta\) and the estimators are exactly normal; the ML estimator of \(\sigma^2\) divides by \(n\) and is biased.
  • Precision improves with more data and more spread in \(x\).

8 Exercises

8.1 A. Conceptual

A1 (★). Which of the assumptions A1–A4 are needed for each of: (a) \(E(\hat\beta_1) = \beta_1\); (b) \(\operatorname{Var}(\hat\beta_1) = \sigma^2/S_{xx}\); (c) \(\hat\beta_1\) is BLUE; (d) \(\hat\beta_1\) is exactly normal?

Solution
  1. A1. (b) A1–A3 (A1 only to make \(\beta_1\) the target; the variance formula itself uses A2–A3). (c) A1–A3. (d) A4 together with the linear-combination representation (A1–A4); without normality, \(\hat\beta_1\) is only approximately normal in large samples under regularity conditions.

A2 (★). An engineer can choose 20 settings of a dial \(x\) between 0 and 10 to estimate the slope of a straight-line relationship. Assuming the model is known to be linear on \([0, 10]\), which design minimises \(\operatorname{Var}(\hat\beta_1)\)? Why might a practitioner still not use it?

Solution

\(\operatorname{Var}(\hat\beta_1) = \sigma^2/S_{xx}\) is minimised by maximising \(S_{xx}\): put 10 observations at \(x = 0\) and 10 at \(x = 10\), giving \(S_{xx} = 20 \times 25 = 500\). However, with only two distinct \(x\) values it is impossible to check whether the relationship is really linear; designs usually include some intermediate points to detect curvature.

8.2 B. Mathematical

B1 (★★). Prove that \(\hat\beta_0\) is BLUE for \(\beta_0\), adapting the proof of Theorem 1.4.3.

Hint

A linear estimator \(\sum c_i y_i\) is unbiased for \(\beta_0\) iff \(\sum c_i = 1\) and \(\sum c_i x_i = 0\). Write \(c_i = a_i + d_i\) with \(a_i = 1/n - \bar x k_i\).

Solution

\(\hat\beta_0 = \sum a_i y_i\) with \(a_i = 1/n - \bar x k_i\); by (1.4.1), \(\sum a_i = 1\) and \(\sum a_i x_i = \bar x - \bar x = 0\). For any linear unbiased \(\sum c_i y_i\), \(d_i = c_i - a_i\) satisfies \(\sum d_i = 0\) and \(\sum d_i x_i = 0\). Then \(\sum a_i d_i = \frac{1}{n}\sum d_i - \bar x \sum k_i d_i = 0 - \bar x \cdot 0 = 0\) (as in the proof of Theorem 1.4.3, \(\sum k_i d_i = 0\)). Hence \(\sigma^2\sum c_i^2 = \sigma^2\sum a_i^2 + \sigma^2\sum d_i^2 \ge \operatorname{Var}(\hat\beta_0)\), with equality iff \(d = 0\).

B2 (★★). Show that \(\operatorname{Var}(\hat y_0) = \sigma^2\bigl(\frac{1}{n} + \frac{(x_0 - \bar x)^2}{S_{xx}}\bigr)\) for the fitted value \(\hat y_0 = \hat\beta_0 + \hat\beta_1 x_0\) at a fixed \(x_0\). Where is it smallest? (This result is used in Lesson 1.8.)

Solution

\(\hat y_0 = \bar y + \hat\beta_1(x_0 - \bar x)\). Since \(\operatorname{Cov}(\bar y, \hat\beta_1) = 0\), \(\operatorname{Var}(\hat y_0) = \sigma^2/n + (x_0 - \bar x)^2\sigma^2/S_{xx}\). It is smallest, \(\sigma^2/n\), at \(x_0 = \bar x\), and grows quadratically with the distance from \(\bar x\).

B3 (★★). Show that the “endpoint” estimator \(\tilde\beta_1 = (y_{(n)} - y_{(1)})/(x_{(n)} - x_{(1)})\), where \((1)\) and \((n)\) index the observations with the smallest and largest \(x\) (assumed unique), is linear and unbiased, and find its variance under A2–A3. For \(x = 1, 2, 3, 4, 5\), compare it with \(\operatorname{Var}(\hat\beta_1)\).

Solution

\(\tilde\beta_1 = \sum c_i y_i\) with \(c = 1/(x_{(n)} - x_{(1)})\) for the largest-\(x\) observation, \(-c\) for the smallest, and 0 otherwise: linear. \(E(\tilde\beta_1) = [\beta_1 (x_{(n)} - x_{(1)})]/(x_{(n)} - x_{(1)}) = \beta_1\): unbiased. \(\operatorname{Var}(\tilde\beta_1) = 2\sigma^2/(x_{(n)} - x_{(1)})^2\). For \(x = 1,\dots,5\): \(\operatorname{Var}(\tilde\beta_1) = 2\sigma^2/16 = 0.125\,\sigma^2\) versus \(\operatorname{Var}(\hat\beta_1) = \sigma^2/S_{xx} = \sigma^2/10 = 0.1\,\sigma^2\), as Gauss–Markov requires. A simulation with \(\sigma = 2\) and 10,000 replications (seed 2026, Python) gave variances 0.511 and 0.407, against the theoretical 0.500 and 0.400.

8.3 C. Computational

C1 (★). Reproduce the standard errors of the worked example and check them against summary(lm(...)) in R or by your own matrix computation in Python.

Solution

\(\operatorname{se}(\hat\beta_0) = 0.7952\) and \(\operatorname{se}(\hat\beta_1) = 0.2575\) (per 1000 lb). In R, summary(lm(mpg ~ I(weight/1000), data = auto)) reports the same values in the “Std. Error” column.

C2 (★★). Bias of the ML variance estimator. With \(x = 1, \dots, 5\), \(y_i = 1 + 2x_i + \varepsilon_i\) and \(\varepsilon_i \sim N(0, 2^2)\), simulate 10,000 data sets (seed 2026). Compare the average of \(\mathrm{SSE}/(n-2)\) and of \(\mathrm{SSE}/n\) with \(\sigma^2 = 4\).

Solution (Python) 
import numpy as np
rng = np.random.default_rng(2026)
x = np.arange(1, 6.0); n = 5; R = 10_000
Y = 1 + 2 * x + rng.normal(0, 2, size=(R, n))
k = (x - x.mean()) / np.sum((x - x.mean())**2)
b1 = Y @ k; b0 = Y.mean(axis=1) - b1 * x.mean()
SSE = ((Y - b0[:, None] - b1[:, None] * x)**2).sum(axis=1)
print(round((SSE / (n - 2)).mean(), 4), round((SSE / n).mean(), 4))

Output: 3.9730 and 2.3838. Theory: \(E[\mathrm{SSE}/(n-2)] = 4\) and \(E[\mathrm{SSE}/n] = (3/5)\times 4 = 2.4\). Dividing by \(n\) underestimates \(\sigma^2\) by 40% when \(n = 5\).

C3 (★★★). When A2 fails. Keep the 398 Auto MPG weights \(x\) (in 1000 lb). Generate \(y_i = 46.3 - 7.7x_i + \varepsilon_i\) with \(\varepsilon_i \sim N(0, \sigma_i^2)\) and \(\sigma_i = \max(9.5 - 1.5x_i,\ 1)\), so that the spread decreases with weight as in the real data. Over 10,000 replications (seed 2026), compare (i) the mean of \(\hat\beta_1\) with \(-7.7\), (ii) the standard deviation of \(\hat\beta_1\) with its exact value \(\sqrt{\sum k_i^2\sigma_i^2}\), and (iii) the average usual standard error \(\hat\sigma/\sqrt{S_{xx}}\).

Solution (Python) 
import numpy as np, pandas as pd
cols = ["mpg", "cylinders", "displacement", "horsepower", "weight",
        "acceleration", "model_year", "origin", "car_name"]
auto = pd.read_csv("data/auto-mpg.data", sep=r"\s+", header=None,
                   names=cols, na_values="?", quotechar='"')
x = auto["weight"].to_numpy() / 1000; n = len(x)
Sxx = np.sum((x - x.mean())**2); k = (x - x.mean()) / Sxx
sd = np.maximum(9.5 - 1.5 * x, 1.0)
rng = np.random.default_rng(2026)
Y = 46.3 - 7.7 * x + rng.normal(0, 1, size=(10_000, n)) * sd
b1 = Y @ k; b0 = Y.mean(axis=1) - b1 * x.mean()
s2 = ((Y - b0[:, None] - b1[:, None] * x)**2).sum(axis=1) / (n - 2)
print(round(b1.mean(), 4), round(b1.std(ddof=1), 4),
      round(np.sqrt(np.sum(k**2 * sd**2)), 4), round(np.sqrt(s2 / Sxx).mean(), 4))

Output: mean \(-7.7039\), simulated SD \(0.2809\), exact SD \(0.2794\), average usual SE \(0.3081\). The slope remains unbiased (A1 holds), but the usual standard error, which assumes constant variance, is about 10% too large here. With a different variance pattern it can be too small; the direction is not predictable in general. This is why Module 3 introduces standard errors that do not rely on A2.
