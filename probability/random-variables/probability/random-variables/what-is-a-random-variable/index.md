<h1>1. What Is a Random Variable?</h1>
<p class="lead">
A random variable is a function that assigns a real number to each outcome of a random experiment.
</p>

<a class="btn btn-outline" href="/probability/random-variables/">Back to Block 3</a>

<section class="section">
<h2>Learning objective</h2>
<ul class="bullets">
<li>Understand that a random variable is a function</li>
<li>Translate outcomes into numerical values</li>
<li>Recognize why this step is essential for modeling</li>
</ul>
</section>

<section class="section">
<h2>Key idea</h2>
<div class="callout">
<div class="callout-copy">
<p style="margin:0;"><strong>A random variable maps outcomes → numbers.</strong></p>
</div>
</div>
</section>

<section class="section">
<h2>Why this matters</h2>
<p>
Probability initially describes events.  
Statistics requires numbers.  
Random variables bridge that gap.
</p>
</section>
