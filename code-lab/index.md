<!-- HOW AN EXERCISE WORKS -->
<section class="section section-soft">
  <div class="section-head">
    <h2>How every exercise works</h2>
    <p>The same five steps, so you always know what to expect.</p>
  </div>

  <div class="grid grid-3">
    <div class="card">
      <h3>1 · Predict</h3>
      <p>Read a short piece of code and decide what it will return <em>before</em> running it. This is the core skill for reading code written by others, including AI tools.</p>
    </div>
    <div class="card">
      <h3>2 · Write</h3>
      <p>Solve a small, clearly stated task in R, Python, or both. Starter code is provided where it helps.</p>
    </div>
    <div class="card">
      <h3>3 · Hints, then solution</h3>
      <p>Hints open one at a time. The full solution, with output, stays hidden until you choose to see it.</p>
    </div>
    <div class="card">
      <h3>4 · Check yourself</h3>
      <p>Every exercise gives the exact expected result, so you can verify your own code instead of trusting that "it runs".</p>
    </div>
    <div class="card">
      <h3>5 · Why it matters</h3>
      <p>A short note on the statistical consequence of getting it wrong, and where the idea appears in real analyses.</p>
    </div>
  </div>
</section>
