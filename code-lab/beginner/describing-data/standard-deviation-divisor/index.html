1 Goal

By the end of this exercise you will be able to:

  1. predict the standard deviation returned by R, NumPy and pandas;
  2. explain the difference between dividing by n and by n − 1;
  3. make all three tools report the same, correctly labelled value.

2 Predict first

Before running anything: what does each line return?

R

x <- c(2, 4, 4, 4, 5, 5, 7, 9)
sd(x)

Python

import numpy as np
import pandas as pd
x = np.array([2, 4, 4, 4, 5, 5, 7, 9])
print(np.std(x))
print(pd.Series(x).std())
Show the answer

R divides by n − 1:

[1] 2.13809

NumPy divides by n; pandas divides by n − 1, like R:

2.0
2.138089935299395

3 The idea

For these data the mean is 5 and the sum of squared deviations is 32. Dividing by n = 8 gives the variance 4 and standard deviation 2: the SD of these eight numbers as a population. Dividing by n − 1 = 7 gives 32/7 ≈ 4.571 and SD ≈ 2.138: the usual estimate when the eight numbers are a sample (the n − 1 makes the variance estimator unbiased).

R's sd(), pandas' .std(), SPSS and Excel's STDEV.S use n − 1. NumPy's np.std() uses n unless you set ddof=1 ("delta degrees of freedom"). The difference shrinks as n grows, but in small samples it is noticeable.

5 Hints

Hint 1

NumPy: look at the ddof argument of np.std().

Hint 2

R: the population SD is the square root of the mean squared deviation, sqrt(mean((x - mean(x))^2)).

6 Solution

Show the solution

R

x <- c(2, 4, 4, 4, 5, 5, 7, 9)

round(sd(x), 5)                        # sample SD (n - 1)
sqrt(mean((x - mean(x))^2))            # population SD (n)

Output

[1] 2.13809
[1] 2

Python

import numpy as np
import pandas as pd
x = np.array([2, 4, 4, 4, 5, 5, 7, 9])

print(round(np.std(x, ddof=1), 5),     # sample SD (n - 1)
      round(pd.Series(x).std(), 5),
      round(np.std(x), 5))             # population SD (n)

Output

2.13809 2.13809 2.0

7 Check yourself

Your answer is correct if

  • the sample SD is 2.13809 in all three tools;
  • the population SD is exactly 2, and you can say which of the two your report uses.

8 Why it matters

Small samples, visible differences

With n = 8 the two versions differ by about 7%. Copy a NumPy result into a table next to R or SPSS results and the numbers will not match, and a reviewer may not know why. In simulation studies, where variances are compared across thousands of replications, mixing the two divisors biases every comparison.
