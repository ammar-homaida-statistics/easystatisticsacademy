1 Goal

By the end of this exercise you will be able to:

  1. explain why sample quantiles have several definitions;
  2. reproduce the quartiles of R, NumPy and SPSS;
  3. state which definition a report uses.

2 Predict first

Before running anything: what does each line return?

R

x <- 1:10
quantile(x, c(0.25, 0.75))

Python

import numpy as np
x = np.arange(1, 11)
print(np.quantile(x, [0.25, 0.75]))
Show the answer

R and NumPy agree, because both use the same default (Hyndman and Fan's type 7):

 25%  75% 
3.25 7.75 
[3.25 7.75]

SPSS reports 2.75 and 8.25 for the same data (type 6).

3 The idea

With 10 values, the 25th percentile falls between two observations, and there are several reasonable rules for where exactly. Hyndman and Fan (1996) list nine. Type 7 places the p-quantile at position 1 + p(n − 1) = 3.25 and interpolates (value 3.25). Type 6 uses position p(n + 1) = 2.75 (value 2.75).

R's quantile() defaults to type 7 and accepts type = 1 to 9. NumPy and pandas also default to type 7; NumPy's method="weibull" is type 6. SPSS and Excel's QUARTILE.EXC use type 6, Excel's QUARTILE.INC type 7. The differences vanish in large samples but matter in small ones, and in boxplots and IQR-based outlier rules.

5 Hints

Hint 1

R: quantile() has a type argument.

Hint 2

NumPy: np.quantile() has a method argument; the SPSS definition is called "weibull".

6 Solution

Show the solution

R

x <- 1:10

quantile(x, c(0.25, 0.75), type = 6)   # SPSS definition
IQR(x)                                 # type 7: 7.75 - 3.25
IQR(x, type = 6)                       # type 6: 8.25 - 2.75

Output

 25%  75% 
2.75 8.25 
[1] 4.5
[1] 5.5

Python

import numpy as np
x = np.arange(1, 11)

q6 = np.quantile(x, [0.25, 0.75], method="weibull")   # SPSS definition
q7 = np.quantile(x, [0.25, 0.75])                     # default (type 7)
print(q6)
print(q7[1] - q7[0], q6[1] - q6[0])

Output

[2.75 8.25]
4.5 5.5

7 Check yourself

Your answer is correct if

  • your SPSS-style quartiles are 2.75 and 8.25;
  • the IQR is 4.5 under the default definition and 5.5 under the SPSS definition.

8 Why it matters

Same data, different boxplot

An IQR of 4.5 versus 5.5 changes the 1.5 × IQR fences used to flag outliers, so a value can be an "outlier" in one program and not in another. When results must be reproduced across software, or compared with a published table, name the quantile definition (for example "type 7, Hyndman and Fan 1996").
