Exercise 1.1 — Recycling and Broadcasting: Centring a Data Matrix

1 Goal

By the end of this exercise you will be able to:

  1. predict what happens when R combines vectors of different lengths (recycling);
  2. predict when NumPy combines arrays of different shapes (broadcasting) and when it refuses;
  3. centre the columns of a data matrix correctly in both languages, and verify the result.

2 Predict first

Before running anything: what does each line return?

R

1:6 + c(10, 20)

Python

import numpy as np
np.arange(1, 7) + np.array([10, 20])
Show the answer

R repeats the shorter vector until it matches the longer one, so c(10, 20) becomes 10, 20, 10, 20, 10, 20:

[1] 11 22 13 24 15 26

NumPy refuses, because shapes (6,) and (2,) are not compatible:

ValueError: operands could not be broadcast together with shapes (6,) (2,)

R is permissive; NumPy is strict. Neither behaviour is "better", but you must know which one you are using.

3 The idea

Recycling (R). When two vectors have different lengths, R repeats the shorter one. If the longer length is a multiple of the shorter one, there is no warning. A matrix is a vector stored column by column, so recycling also runs down the columns.

Broadcasting (NumPy). NumPy compares shapes from the last dimension backwards. Two dimensions are compatible if they are equal or one of them is 1. A row of column means with shape (p,) therefore matches every row of an (n, p) matrix.

4 Your task

Centre the columns of this matrix

5 Hints

Hint 1

Write out the six numbers of X in the order R stores them (column by column), and write colMeans(X) repeated underneath. Which mean is subtracted from which number?

Hint 2

In R you need a function that applies a summary statistic across a chosen margin of a matrix. Look at the help page of sweep(); MARGIN = 2 means columns.

Hint 3 (Python)

X.mean(axis=0) has shape (2,). Compare it with the shape of X, starting from the last dimension.

6 Solution

Show the solution

R

X <- matrix(c(1, 2, 3,
              10, 20, 30), ncol = 2)

# Wrong: colMeans(X) = (2, 20) is recycled DOWN the columns
X - colMeans(X)

# Right: subtract the mean of each column from that column
Xc <- sweep(X, MARGIN = 2, STATS = colMeans(X))
Xc
colMeans(Xc)

Output

     [,1] [,2]
[1,]   -1  -10
[2,]  -18   18
[3,]    1   10

     [,1] [,2]
[1,]   -1  -10
[2,]    0    0
[3,]    1   10

[1] 0 0

The wrong version subtracts 2, 20, 2 from the first column and 20, 2, 20 from the second. Because 6 is a multiple of 2, R gives no warning. scale(X, scale = FALSE) also centres correctly (it adds a "scaled:center" attribute).

Python

import numpy as np
X = np.array([[1, 10],
              [2, 20],
              [3, 30]])

Xc = X - X.mean(axis=0)   # (3, 2) and (2,) broadcast row by row
print(Xc)
print(Xc.mean(axis=0))

Output

[[ -1. -10.]
 [  0.   0.]
 [  1.  10.]]
[0. 0.]

Here the natural line is correct, because broadcasting aligns the last dimension (2 columns) with the 2 means.

7 Check yourself

Your answer is correct if

  • the centred matrix is (-1, 0, 1) in the first column and (-10, 0, 10) in the second;
  • the column means of Xc are 0 0 (in larger data, zero up to about 1e-15: use all.equal() in R or np.allclose() in Python, not ==).

8 Why it matters

A silent statistical error

Centring is the first step of covariance matrices, principal components, ridge regression and many simulations. With X - colMeans(X) the code runs, the numbers look reasonable, and every result built on them is wrong. This line also appears in code produced by AI assistants, so it is worth recognising at a glance. The habit that protects you: after every transformation, check one property you know must hold — here, column means equal to zero.

9 Going further

  • R: run 1:5 + c(10, 20). What changes, and why is this case safer than the one above?
  • Python: try centring the rows with X - X.mean(axis=1). Explain the error, then fix it with keepdims=True.
  • Both: centre and scale the columns (z-scores) and check that each column has mean 0 and standard deviation 1. Note that R's sd() divides by n − 1 while NumPy's std() divides by n unless you set ddof=1.
