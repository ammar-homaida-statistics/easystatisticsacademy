Exercise 1.2 — Missing Values: Different Defaults in R, NumPy and pandas

1 Goal

By the end of this exercise you will be able to:

  1. predict how R, NumPy and pandas handle a missing value in a summary statistic;
  2. count missing values and test for them correctly (never with ==);
  3. compute a mean from the observed values and report how many values it uses.

2 Predict first

Before running anything: what does each line return?

R

x <- c(12, NA, 15, 9, NA, 14)
mean(x)
x == NA

Python

import numpy as np
import pandas as pd
x = np.array([12, np.nan, 15, 9, np.nan, 14])
print(np.mean(x))
print(pd.Series(x).mean())
Show the answer

R: the mean of something unknown is unknown, and comparing anything with an unknown value is also unknown:

[1] NA
[1] NA NA NA NA NA NA

Python: NumPy propagates the missing value, but pandas skips it by default:

nan
12.5

Same data, same word "mean", different defaults.

3 The idea

R marks a missing value as NA. Most summaries return NA unless you ask for the missing values to be removed with na.rm = TRUE. Because NA means "unknown", x == NA is unknown too; the test for missingness is is.na(x).

NumPy uses the floating-point value nan ("not a number"). Ordinary functions propagate it; the nan-functions (np.nanmean, np.nansum, …) ignore it. nan is not equal to anything, not even itself, so the test is np.isnan(x).

pandas chooses the opposite default: most summaries use skipna=True, so missing values are dropped without any message.

5 Hints

Hint 1

is.na(x) and np.isnan(x) return TRUE/FALSE values. What does sum() do with them?

Hint 2

6 Solution

Show the solution

R

x <- c(12, NA, 15, 9, NA, 14)

sum(is.na(x))              # (a)
mean(x, na.rm = TRUE)      # (b)
sum(!is.na(x))             # (c)

Output

[1] 2
[1] 12.5
[1] 4

Python

import numpy as np
import pandas as pd
x = np.array([12, np.nan, 15, 9, np.nan, 14])
s = pd.Series(x)

# NumPy
print(np.isnan(x).sum())       # (a)
print(np.nanmean(x))           # (b)
print((~np.isnan(x)).sum())    # (c)

# pandas
print(s.isna().sum(), s.mean(), s.count())
print(s.mean(skipna=False))    # R-like behaviour

Output

2
12.5
4
2 12.5 4
nan

7 Check yourself

Your answer is correct if

  • 2 values are missing, the mean of the observed values is 12.5, and it is based on 4 values (12 + 15 + 9 + 14 = 50, and 50 / 4 = 12.5);
  • you never used x == NA or x == np.nan to find missing values.

8 Why it matters

The n you report must be the n you used

A summary computed with missing values removed is a complete-case result: it describes only the observed values, and it can be biased if values are not missing at random. R forces you to notice the problem; pandas does not. Code translated from R to pandas (by a person or by an AI tool) can therefore change silently from "stop and think" to "drop and continue". Always report how many values each statistic is based on.
