Exercise 5.3 — Bar Chart Order: Alphabetical, by Frequency, or Meaningful?

A bar chart of Low, Medium and High should read in that order. R puts the bars in alphabetical order, pandas in order of frequency, and neither is what a reader expects.

1 Goal

By the end of this exercise you will be able to:

  1. predict the order of categories in R and pandas frequency tables;
  2. set a meaningful order for ordinal categories;
  3. produce the same table and bar chart in both languages.

2 Predict first

Before running anything: what does each line return?

R

x <- c("Medium", "High", "Low", "Medium", "Medium", "Low")
table(x)

Python

import pandas as pd
x = pd.Series(["Medium", "High", "Low", "Medium", "Medium", "Low"])
print(x.value_counts().to_dict())
Show the answer

R sorts the categories alphabetically:

x
  High    Low Medium 
     1      2      3

pandas sorts them by frequency:

{'Medium': 3, 'Low': 2, 'High': 1}

barplot(table(x)) and x.value_counts().plot.bar() draw the bars in these same orders.

3 The idea

In R, table() uses the levels of a factor, and a character vector is turned into a factor with alphabetical levels. pandas' value_counts() sorts by count, largest first. Both are reasonable defaults for nominal categories (such as cities), but for ordinal categories (Low < Medium < High, or Likert scales) the natural order carries meaning.

Set the order once, where the data are defined: factor(x, levels = c("Low", "Medium", "High")) in R, and pd.Categorical(x, categories=[...], ordered=True) or .reindex([...]) in pandas. Tables and plots then follow it.

5 Hints

Hint 1

R: factor() has a levels argument; table() and barplot() follow it.

Hint 2

pandas: .reindex(["Low", "Medium", "High"]) puts the counts in a given order; a categorical with ordered=True keeps that order everywhere.

6 Solution

Show the solution

R

x <- c("Medium", "High", "Low", "Medium", "Medium", "Low")

x_f <- factor(x, levels = c("Low", "Medium", "High"))
table(x_f)
barplot(table(x_f))

Output

x_f
   Low Medium   High 
     2      3      1

Python

import pandas as pd
x = pd.Series(["Medium", "High", "Low", "Medium", "Medium", "Low"])

counts = x.value_counts().reindex(["Low", "Medium", "High"])
print(counts.to_dict())
# counts.plot.bar()   # bars in the same order

Output

{'Low': 2, 'Medium': 3, 'High': 1}

If a category has no observations, table() on a factor still shows it with a count of 0, and .reindex() shows it as missing (use fill_value=0). Empty categories are information too.

7 Check yourself

Your answer is correct if

  • both tables read Low 2, Medium 3, High 1, in that order;
  • the bar chart shows the bars in the same order.

8 Why it matters

Order is part of the message

Ordinal categories shown in alphabetical order (High, Low, Medium) force the reader to reorder them mentally, and trends across levels become hard to see. Frequency order can be right for nominal categories, but it should be a choice, not an accident of the software.
