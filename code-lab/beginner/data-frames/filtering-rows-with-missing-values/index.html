Exercise 3.1 — Filtering Rows When Some Values Are Missing

Selecting the rows that meet a condition is the most common data-frame operation. When the variable has missing values, R and pandas each do something you might not expect.

1 Goal

By the end of this exercise you will be able to:

  1. predict what row filtering does with missing values in R and pandas;
  2. filter rows safely in both languages;
  3. report how many rows were excluded because the value was missing.

2 Predict first

Before running anything: what does each line return?

R

df <- data.frame(id  = 1:5,
                 age = c(34, NA, 52, 17, 41),
                 sex = c("F", "M", "F", "M", "F"))
df[df$age > 30, ]

Python

import numpy as np
import pandas as pd
df = pd.DataFrame({"id":  [1, 2, 3, 4, 5],
                   "age": [34, np.nan, 52, 17, 41],
                   "sex": ["F", "M", "F", "M", "F"]})
print(len(df[df["age"] > 30]))
Show the answer

R returns four rows. The comparison NA > 30 is NA, and indexing by NA creates a row in which every value is missing:

   id age  sex
1   1  34    F
NA NA  NA <NA>
3   3  52    F
5   5  41    F

pandas returns three rows. NaN > 30 is False, so the person with a missing age is dropped without any message:

3 The idea

A logical condition on a column with missing values has three possible results in R: TRUE, FALSE and NA. Square-bracket indexing keeps the TRUE rows and creates an empty row for every NA, so counts and means computed afterwards are wrong.

Safe ways to filter in R are df[which(df$age > 30), ] (which() keeps only the TRUE positions), subset(df, age > 30), or dplyr::filter(). pandas already treats missing as "not selected". In both cases the person with a missing age is excluded, and that exclusion should be counted and reported.

5 Hints

Hint 1

In R, compare df$age > 30 with which(df$age > 30). Which one contains NA?

Hint 2

The number of people excluded because of missing age is sum(is.na(df$age)) in R and df["age"].isna().sum() in pandas.

6 Solution

Show the solution

R

df <- data.frame(id  = 1:5,
                 age = c(34, NA, 52, 17, 41),
                 sex = c("F", "M", "F", "M", "F"))

over <- df[which(df$age > 30), ]   # or subset(df, age > 30)
over
nrow(over)                          # (a)
mean(over$age)                      # (b)
sum(is.na(df$age))                  # (c)

Output

  id age sex
1  1  34   F
3  3  52   F
5  5  41   F
[1] 3
[1] 42.33333
[1] 1

Python

import numpy as np
import pandas as pd
df = pd.DataFrame({"id":  [1, 2, 3, 4, 5],
                   "age": [34, np.nan, 52, 17, 41],
                   "sex": ["F", "M", "F", "M", "F"]})

over = df[df["age"] > 30]
print(over)
print(len(over), round(over["age"].mean(), 5))   # (a) and (b)
print(df["age"].isna().sum())                     # (c)

Output

   id   age sex
0   1  34.0   F
2   3  52.0   F
4   5  41.0   F
3 42.33333
1

With the unsafe R line, nrow() returns 4 and mean() returns NA: both are wrong.

7 Check yourself

Your answer is correct if

  • 3 people are older than 30, with mean age 42.33 ((34 + 52 + 41) / 3);
  • 1 person was excluded because the age is missing, and your result contains no row of NAs.

8 Why it matters

The excluded person is part of your sample

A row of NAs inflates counts, and a silently dropped row shrinks them. Either way the denominator of every percentage built on the filter changes. A careful report says: 3 of the 4 people with a known age are over 30; age is missing for 1 person.
