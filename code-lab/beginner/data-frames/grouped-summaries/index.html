Exercise 3.2 — Grouped Summaries: Where Did the Missing Group Go?

A count or mean per group is the first table of almost every report. By default, R and pandas both leave out the observations whose group is missing, so the groups no longer add up to the sample.

1 Goal

By the end of this exercise you will be able to:

  1. compute counts and means per group in R and pandas;
  2. predict what happens to observations with a missing group label;
  3. check that the group sizes add up to the sample size.

2 Predict first

Before running anything: what does each line return?

R

group <- c("A", "B", "A", NA, "B", "A")
score <- c(10, 20, 30, 40, 50, 60)
table(group)
tapply(score, group, mean)

Python

import pandas as pd
df = pd.DataFrame({"group": ["A", "B", "A", None, "B", "A"],
                   "score": [10, 20, 30, 40, 50, 60]})
print(df["group"].value_counts().to_dict())
print(df.groupby("group")["score"].mean().round(5).to_dict())
Show the answer

3 The idea

Grouping functions use the distinct non-missing labels as groups. An observation whose label is missing belongs to none of them and is dropped, with no message in either language.

To keep it: in R, table(group, useNA = "ifany") and tapply(score, addNA(group), mean); in pandas, value_counts(dropna=False) and groupby(..., dropna=False). The simplest check is that the group sizes add up to the number of observations.

6 Solution

Show the solution

R

group <- c("A", "B", "A", NA, "B", "A")
score <- c(10, 20, 30, 40, 50, 60)

counts <- table(group, useNA = "ifany")
counts
tapply(score, addNA(group), mean)
sum(counts)

Output

group
   A    B <NA> 
   3    2    1 
       A        B     <NA> 
33.33333 35.00000 40.00000 
[1] 6

Python

import pandas as pd
df = pd.DataFrame({"group": ["A", "B", "A", None, "B", "A"],
                   "score": [10, 20, 30, 40, 50, 60]})

res = df.groupby("group", dropna=False)["score"].agg(["count", "mean"]).round(5)
print(res)
print(res["count"].sum())

Output

       count      mean
group                 
A          3  33.33333
B          2  35.00000
NaN        1  40.00000
6

7 Check yourself

Your answer is correct if

  • the table has three rows: A (3, mean 33.33), B (2, mean 35) and missing (1, mean 40);
  • the counts add up to 6, the number of observations.

8 Why it matters

A table that does not add up

If a report shows group sizes that add up to fewer than the sample, a reader cannot tell whether observations were lost by design or by accident. Showing the missing group, or stating in a footnote how many observations had no group, keeps the table honest. Missing labels may also differ systematically from the rest; here the missing group has the highest mean.

9 Going further

  • R: compute the same table with aggregate(score ~ group, FUN = mean). What happens to the missing group? (Look at the na.action argument.)
  • Python: add a missing score to group A. Does count still equal the group size? Compare with size.
  • Both: add a column with each group's percentage of the whole sample, and check that the percentages add up to 100.
