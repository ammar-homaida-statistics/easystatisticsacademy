1 Goal

By the end of this exercise you will be able to:

  1. count and compute proportions with logical vectors;
  2. combine conditions element by element with & and |;
  3. recognise the errors caused by && in R and and in pandas.

2 Predict first

Before running anything: what does each line return?

R

age <- c(34, 17, 52, 41, 15, 63)
sum(age >= 18)
mean(age >= 18)

Python

import pandas as pd
age = pd.Series([34, 17, 52, 41, 15, 63])
print((age >= 18).sum())
print((age >= 18).mean())
Show the answer

A comparison gives one TRUE/FALSE per value. TRUE counts as 1 and FALSE as 0, so sum() counts the adults and mean() gives their proportion (4 of 6):

[1] 4
[1] 0.6666667

pandas prints the same values: 4 and 0.6666666666666666.

3 The idea

A condition applied to a vector returns a logical vector of the same length. Because TRUE = 1 and FALSE = 0 in arithmetic, sum(condition) is a count and mean(condition) is a proportion.

To combine conditions element by element, use & (and) and | (or) in both R and pandas, with parentheses around each condition in pandas. R's && and || are for a single TRUE/FALSE, such as in if (); since R 4.3 they give an error for longer vectors. Python's and and or likewise cannot be applied to a pandas Series.

4 Your task

Working-age adults

From the ages above, select the people aged 18 to 59 (inclusive of 18, below 60), list their ages, and compute what proportion of the whole group they are. First try && in R and and in Python.

R — starter code

age <- c(34, 17, 52, 41, 15, 63)

age[age >= 18 && age < 60]     # try this first
# Your code: ...

Python — starter code

import pandas as pd
age = pd.Series([34, 17, 52, 41, 15, 63])

age[(age >= 18) and (age < 60)]   # try this first

5 Hints

Hint 1

Both errors say the same thing: the operator expected one TRUE/FALSE and received six.

Hint 2

Use the element-wise operator &. In pandas, keep the parentheses around each condition.

6 Solution

Show the solution

R

age <- c(34, 17, 52, 41, 15, 63)

working <- age >= 18 & age < 60
age[working]
mean(working)

Output

[1] 34 52 41
[1] 0.5

Python

import pandas as pd
age = pd.Series([34, 17, 52, 41, 15, 63])

working = (age >= 18) & (age < 60)
print(age[working].tolist())
print(working.mean())

Output

[34, 52, 41]
0.5

The first attempts fail. In R (4.3 or later): Error in age >= 18 && age < 60 : 'length = 6' in coercion to 'logical(1)'. In pandas: ValueError: The truth value of a Series is ambiguous.

7 Check yourself

Your answer is correct if

  • the selected ages are 34, 52 and 41;
  • the proportion is 0.5 (3 of 6 people).

8 Why it matters

Old code that now fails, and old code that never worked

Before R 4.3, && on a vector silently used only the first element, so older scripts (and AI suggestions trained on them) could select the wrong rows without any error. If you meet && or and applied to a whole column, read it as a bug.
