1 Goal

By the end of this exercise you will be able to:

  1. explain why one text value changes the type of a whole column;
  2. convert a text column to numbers in R and pandas;
  3. count and report the values that could not be converted.

2 Predict first

Before running anything: what does each line return?

R

x <- c("12", "15", "n/a", "9", "14")
class(x)
mean(x)

Python

import pandas as pd
s = pd.Series(["12", "15", "n/a", "9", "14"])
print(s.mean())
Show the answer

R stores the column as text and refuses to average it:

[1] "character"
[1] NA
Warning message:
In mean.default(x) : argument is not numeric or logical: returning NA

pandas raises an error (the exact message depends on the pandas version):

TypeError: Cannot perform reduction 'mean' with string dtype

3 The idea

A vector in R and a column in pandas hold one type. When values of different types are combined, they are converted to the most general type: logical → integer → number → text. A single "n/a", "–" or "3,5" therefore turns the whole column into text.

Converting back is done with as.numeric() in R and pd.to_numeric(..., errors="coerce") in pandas. Entries that are not numbers become missing values. R warns ("NAs introduced by coercion"); pandas with errors="coerce" does not. Either way, count the new missing values.

Hint 1

6 Solution

Show the solution

R

x <- c("12", "15", "n/a", "9", "14")

x_num <- as.numeric(x)          # warning: NAs introduced by coercion
x_num
sum(is.na(x_num)) - sum(is.na(x))   # (a) values lost
mean(x_num, na.rm = TRUE)            # (b) mean
sum(!is.na(x_num))                   #     n used

Output

Warning message:
NAs introduced by coercion 
[1] 12 15 NA  9 14
[1] 1
[1] 12.5
[1] 4

Python

import pandas as pd
s = pd.Series(["12", "15", "n/a", "9", "14"])

x_num = pd.to_numeric(s, errors="coerce")
print(x_num.tolist())
print(x_num.isna().sum() - s.isna().sum())   # (a) values lost
print(x_num.mean(), x_num.count())           # (b) mean and n used

Output

[12.0, 15.0, nan, 9.0, 14.0]
1
12.5 4

Better still, prevent the problem when reading the file: read.csv(..., na.strings = c("", "NA", "n/a")) in R or pd.read_csv(..., na_values=["n/a"]) in pandas.

7 Check yourself

Your answer is correct if

  • exactly 1 value (the "n/a") could not be converted;
  • the mean of the remaining values is 12.5, based on 4 values.

8 Why it matters

Silent data loss

If "3,5" (a decimal comma) appears in a column, errors="coerce" turns it into a missing value without a word, and the analysis continues on fewer observations. Every conversion should be followed by one line that counts what was lost, and that count belongs in your report.

9 Going further
