1 Goal

By the end of this exercise you will be able to:

  1. explain how R stores a factor and how pandas stores a categorical;
  2. predict what converting a factor to numbers returns;
  3. recover the original numbers safely in both languages.

2 Predict first

Before running anything: what does each line return?

R

f <- factor(c("10", "5", "20"))
levels(f)
as.numeric(f)

Python

import pandas as pd
c = pd.Categorical(["10", "5", "20"])
print(list(c.categories))
print(c.codes)
Show the answer

R sorts the levels as text ("10" < "20" < "5"), and as.numeric() returns each value's position among the levels:

[1] "10" "20" "5" 
[1] 1 3 2

pandas does the same, but counts from 0:

['10', '20', '5']
[0 2 1]

Neither result is 10, 5, 20.

3 The idea

A factor (R) or categorical (pandas) stores two things: a list of distinct labels (the levels or categories) and, for each observation, an integer code pointing into that list. This saves memory and is right for groups such as "male/female" or "treatment A/B".

The trap appears when numbers are stored as labels, for example after reading a file in which a numeric column contained a text value. Converting the factor to numbers then returns the integer codes. The labels are sorted as text, so the codes do not even follow the numeric order.

4 Your task

Recover the original doses

A dose column has been read as a factor (R) or categorical (pandas). Convert it back to the numeric doses 10, 5, 20 and compute their mean, which must be 11.6667 (35 / 3).

R — starter code

dose <- factor(c("10", "5", "20"))

# Your code: dose_num <- ...
# mean(dose_num)

Python — starter code

import pandas as pd
dose = pd.Series(["10", "5", "20"], dtype="category")

# Your code: dose_num = ...
# print(dose_num.mean())

5 Hints

Hint 1

Convert the labels, not the codes. In R, what does as.character(dose) return?

Hint 2

pandas: dose.astype(str) gives the labels; pd.to_numeric() turns them into numbers.

6 Solution

Show the solution

R

dose <- factor(c("10", "5", "20"))

as.numeric(dose)                    # wrong: codes
dose_num <- as.numeric(as.character(dose))
dose_num
mean(dose_num)

Output

[1] 1 3 2
[1] 10  5 20
[1] 11.66667

Python

import pandas as pd
dose = pd.Series(["10", "5", "20"], dtype="category")

print(dose.cat.codes.tolist())      # wrong: codes
dose_num = pd.to_numeric(dose.astype(str))
print(dose_num.tolist())
print(round(dose_num.mean(), 5))

Output

[0, 2, 1]
[10, 5, 20]
11.66667

An equivalent, slightly faster R idiom is as.numeric(levels(dose))[dose]: convert each level once, then index by the codes.

7 Check yourself

Your answer is correct if

  • your numeric vector is 10, 5, 20 in the original order;
  • its mean is 11.6667. A mean of 2 (R codes) or 1 (pandas codes) means you converted the codes.

8 Why it matters

A model fitted to the wrong numbers

If a numeric variable is silently a factor, lm() treats it as a set of groups, and a manual as.numeric() gives arbitrary codes. Both produce results that look reasonable and are wrong. After reading any data file, check the type of each column (str(df) in R, df.dtypes in pandas) before analysing it.
