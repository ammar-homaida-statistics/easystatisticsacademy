<section class="section">
  <div class="section-head">
    <h1>Reporting Tables Properly</h1>
    <p class="lead">
      A table is not just numbers.  
      It is a structured communication tool. Poor formatting creates confusion. Proper formatting creates clarity.
    </p>
  </div>

  <hr>

  <h2>1. Every Table Must Have</h2>

  <ul>
    <li><strong>Table number</strong> (Table 1, Table 2, …)</li>
    <li><strong>Clear title</strong> (what variable? what population?)</li>
    <li><strong>Units</strong> (%, $, years, etc.)</li>
    <li><strong>Sample size (n)</strong> if relevant</li>
    <li><strong>Footnotes</strong> for clarifications</li>
  </ul>

  <hr>

  <h2>2. Example — Weak Table Title</h2>

  ❌ Table 1: Results  

  Problem:
  <ul>
    <li>No variable name</li>
    <li>No context</li>
    <li>No population</li>
  </ul>

  Better:

  ✔ Table 1. Descriptive Statistics for Monthly Income (n = 250)

  <hr>

  <h2>3. Denominators Must Be Clear</h2>

  When percentages are shown, specify:

  <ul>
    <li>Row percentages?</li>
    <li>Column percentages?</li>
    <li>Total percentages?</li>
  </ul>

  Ambiguous percentages are one of the most common reporting errors.

  <hr>

  <h2>4. Rounding Rules</h2>

  <ul>
    <li>Use consistent decimal places</li>
    <li>Avoid unnecessary precision</li>
    <li>Percentages should usually sum to 100 (allowing minor rounding differences)</li>
  </ul>

  Example:

  ❌ 33.333333%  
  ✔ 33.3%

  <hr>

  <h2>5. Ordering Matters</h2>

  Categories should be ordered:

  <ul>
    <li>Logically (Low → High)</li>
    <li>Chronologically (2019 → 2023)</li>
    <li>Alphabetically (if no natural order)</li>
  </ul>

  Random ordering reduces interpretability.

  <hr>

  <h2>6. Avoid Visual Clutter</h2>

  <ul>
    <li>No unnecessary grid lines</li>
    <li>Avoid too many decimal places</li>
    <li>Do not mix percentages and counts without labeling</li>
  </ul>

  <hr>

  <h2>7. Interpretation Must Accompany Tables</h2>

  A table should not stand alone without explanation.

  Weak reporting:

  ❌ “See Table 2.”

  Strong reporting:

  ✔ “As shown in Table 2, 64% of respondents preferred online services, indicating a clear majority.”

  <hr>

  <h2>Summary</h2>

  <ul>
    <li>Tables communicate structure.</li>
    <li>Titles, units, and denominators must be explicit.</li>
    <li>Rounding and ordering improve clarity.</li>
    <li>Always accompany tables with interpretation.</li>
  </ul>
