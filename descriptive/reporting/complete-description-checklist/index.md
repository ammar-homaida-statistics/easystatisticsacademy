<section class="section">
  <div class="section-head">
    <h1>Complete Description Checklist</h1>
    <p class="lead">
      A descriptive report is incomplete if even one key component is missing.
      This checklist ensures statistical clarity and professional integrity.
    </p>
  </div>

  <hr>

  <h2>1) Variable Definition</h2>
  <ul>
    <li>What is being measured?</li>
    <li>Unit of measurement?</li>
    <li>Measurement scale (categorical, ordinal, numerical)?</li>
  </ul>

  <hr>

  <h2>2) Context and Population</h2>
  <ul>
    <li>Who/what is observed?</li>
    <li>Where and when was data collected?</li>
    <li>Is this a sample or full population?</li>
  </ul>

  <hr>

  <h2>3) Sample Size and Missing Data</h2>
  <ul>
    <li>Total n</li>
    <li>Number/percentage missing</li>
    <li>How missing values were handled</li>
  </ul>

  <hr>

  <h2>4) Center (Choose Correctly)</h2>
  <ul>
    <li>Mean (if symmetric and no strong outliers)</li>
    <li>Median (if skewed or robust summary needed)</li>
    <li>Mode (for categorical variables)</li>
  </ul>

  <hr>

  <h2>5) Spread (Must Accompany Center)</h2>
  <ul>
    <li>Standard deviation (with mean)</li>
    <li>IQR (with median)</li>
    <li>Range (as supplementary information)</li>
  </ul>

  <hr>

  <h2>6) Shape and Outliers</h2>
  <ul>
    <li>Symmetric or skewed?</li>
    <li>Presence of extreme values?</li>
    <li>Long tails?</li>
  </ul>

  <hr>

  <h2>7) Comparison (If Applicable)</h2>
  <ul>
    <li>Are groups comparable?</li>
    <li>Same measurement scale?</li>
    <li>Same denominator?</li>
  </ul>

  <hr>

  <h2>8) Safe Interpretation Language</h2>
  <ul>
    <li>Describe patterns, not causes</li>
    <li>Avoid generalization beyond data</li>
    <li>Acknowledge limitations</li>
  </ul>

  <hr>

  <h2>Summary</h2>
  <ul>
    <li>Descriptive reporting is structured, not random.</li>
    <li>Center alone is incomplete.</li>
    <li>Context + n + spread + shape are mandatory.</li>
    <li>Statistical honesty builds credibility.</li>
  </ul>
</section>
