<section class="section">
  <div class="section-head">
    <h1>Reporting Graphs Properly</h1>
    <p class="lead">
      A graph is powerful — but power without discipline leads to distortion.
      Good graphs clarify patterns. Bad graphs manipulate perception.
    </p>
  </div>

  <hr>

  <h2>1. Every Graph Must Have</h2>

  <ul>
    <li><strong>Clear title</strong> (What variable? What population?)</li>
    <li><strong>Labeled axes</strong> (with units)</li>
    <li><strong>Source or sample size (n)</strong> when relevant</li>
    <li><strong>Legend</strong> if multiple groups appear</li>
  </ul>

  <hr>

  <h2>2. Axis Scaling Must Be Honest</h2>

  Common distortion:

  ❌ Truncated y-axis exaggerates small differences  
  ❌ Unequal spacing in categorical axes  

  Good practice:

  ✔ Use consistent scales  
  ✔ Start at zero for bar charts (unless clearly justified)

  <hr>

  <h2>3. Avoid Visual Manipulation</h2>

  <ul>
    <li>No 3D effects</li>
    <li>No unnecessary colors</li>
    <li>No decorative distortions</li>
    <li>Avoid misleading aspect ratios</li>
  </ul>

  Visual simplicity increases credibility.

  <hr>

  <h2>4. Match Graph to Variable Type</h2>

  <ul>
    <li>Categorical → Bar chart</li>
    <li>Continuous → Histogram</li>
    <li>Two numeric variables → Scatterplot</li>
    <li>Time variable → Line chart</li>
  </ul>

  Using the wrong graph type weakens interpretation.

  <hr>

  <h2>5. Interpretation Must Accompany the Graph</h2>

  Weak reporting:

  ❌ “See Figure 3.”

  Strong reporting:

  ✔ “Figure 3 shows a right-skewed distribution, with most values concentrated below 50 and a long upper tail.”

  A graph without explanation invites misinterpretation.

  <hr>

  <h2>6. Consistency Across a Report</h2>

  <ul>
    <li>Same color scheme throughout</li>
    <li>Same decimal precision</li>
    <li>Same font style</li>
    <li>Same scaling logic</li>
  </ul>

  Consistency improves professional appearance.

  <hr>

  <h2>7. Ethical Responsibility</h2>

  Graphs should inform — not persuade through distortion.

  <ul>
    <li>No selective zooming</li>
    <li>No hidden data exclusions</li>
    <li>No exaggerating small differences</li>
  </ul>

  Ethical visualization is part of statistical integrity.

  <hr>

  <h2>Summary</h2>

  <ul>
    <li>Graphs must be labeled clearly.</li>
    <li>Scaling decisions affect perception.</li>
    <li>Interpretation is required — never optional.</li>
    <li>Clarity and honesty define professional reporting.</li>
  </ul>
