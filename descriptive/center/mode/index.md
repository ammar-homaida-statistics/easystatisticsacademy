<section class="section">
  <div class="section-head">
    <h1>Mode</h1>
    <p class="lead">
      The mode is the most frequently occurring value in a dataset.
      It represents the most common category or observation.
    </p>
  </div>

  <hr>

  <h2>1. Definition</h2>

  <p>
    The mode is the value (or category) with the highest frequency.
  </p>

  <p>
    Unlike the mean and median, the mode does not depend on magnitude or order —
    only on frequency.
  </p>

  <hr>

  <h2>2. Mode for Categorical Variables</h2>

  <p>
    The mode is especially useful for categorical data.
  </p>

  <p><strong>Example:</strong></p>

  <ul>
    <li>Red</li>
    <li>Blue</li>
    <li>Blue</li>
    <li>Green</li>
    <li>Blue</li>
  </ul>

  <p>
    Mode = Blue
  </p>

  <p>
    This is the only valid measure of center for nominal variables.
  </p>

  <hr>

  <h2>3. Mode for Numerical Data</h2>

  <p><strong>Example:</strong> 3, 5, 5, 7, 9</p>

  <p>
    Mode = 5
  </p>

  <p>
    However, for continuous data, exact repetition is rare.
    In such cases, modal class (in grouped data) is used.
  </p>

  <hr>

  <h2>4. Types of Modal Structure</h2>

  <ul>
    <li><strong>Unimodal:</strong> One mode</li>
    <li><strong>Bimodal:</strong> Two modes</li>
    <li><strong>Multimodal:</strong> More than two modes</li>
    <li><strong>No mode:</strong> All values appear once</li>
  </ul>

  <p>
    Modal structure gives insight into distribution shape.
  </p>

  <hr>

  <h2>5. Mode in Grouped Data</h2>

  <p>
    In grouped frequency tables, the modal class is the class interval
    with the highest frequency.
  </p>

  <p>
    It approximates where the distribution peaks.
  </p>

  <hr>

  <h2>6. Limitations of the Mode</h2>

  <ul>
    <li>May not be unique</li>
    <li>May not exist</li>
    <li>Does not use all data values</li>
    <li>Not stable in small samples</li>
  </ul>

  <hr>

  <h2>7. When Should You Use the Mode?</h2>

  <ul>
    <li>Nominal variables</li>
    <li>Most common preference</li>
    <li>Market research</li>
    <li>Survey results</li>
  </ul>

  <p>
    The mode answers: <strong>“What is most typical?”</strong>
  </p>

  <hr>

  <h2>Conceptual Comparison</h2>

  <ul>
    <li>Mean → balances values</li>
    <li>Median → balances order</li>
    <li>Mode → reflects frequency dominance</li>
  </ul>

  <hr>

  <h2>Summary</h2>

  <ul>
    <li>The mode is the most frequent value.</li>
    <li>It is essential for categorical data.</li>
    <li>It may not be unique.</li>
    <li>It reveals distribution peaks.</li>
  </ul>
